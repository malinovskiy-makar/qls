# Как запустить сайт (Этап 1)

Платформа задач по олимпиадной экономике. Сайт работает локально, у тебя на
компьютере. В интернете его пока не видно — это нормально для старта.

## Запуск в 1 команду

Открой Терминал в этой папке и вставь:

```
./venv/bin/python manage.py runserver
```

Терминал напишет что-то вроде `Starting development server at http://127.0.0.1:8000/`.
Это значит — сайт работает. **Не закрывай это окно**, пока пользуешься сайтом.

## Зайти в админку

1. Открой браузер и зайди на **http://127.0.0.1:8000/**
   (тебя сразу перекинет на страницу входа в админку).
2. Логин: **admin**
   Пароль: **admin12345**
3. Готово — ты внутри. Слева раздел **«Problems»**, в нём:
   - **Задачи** — здесь уже лежат 3 примера. Нажми на любую, чтобы посмотреть.
     Кнопка «Добавить задачу» справа сверху — создать новую.
   - **Темы**, **Теги**, **Источники**, **Файлы**, **Пользователи** — справочники.

## Остановить сайт

Вернись в окно Терминала и нажми **Ctrl + C**.

## Полезное

- **Сменить пароль администратора:** в админке зайди в «Пользователи» → admin →
  внизу ссылка на смену пароля. (Простой пароль годится только потому, что сайт
  локальный.)
- **Добавить ученика:** «Пользователи» → «Добавить», роль выбери «Ученик».
- **Заполнить примеры заново** (если вдруг удалишь): `./venv/bin/python manage.py seed_demo`
  — повторный запуск не создаёт дубликаты.

## Что внутри (для справки)

- `config/` — настройки проекта.
- `problems/models.py` — описание всех «анкет» (Задача, Источник, Тема и т.д.).
- `problems/admin.py` — как это выглядит в админке.
- `db.sqlite3` — сама база данных (один файл со всеми твоими задачами).
- `venv/` — «коробка» с библиотеками. Трогать не нужно.
