# STRATEGY.md — стратегия и бизнес-план

Стратегический контекст проекта ЭкЗадачи: позиционирование, видение продукта,
ИИ-репетитор, экономика, конкуренты, тарифы, дорожная карта запуска.

Это файл для обсуждений и решений, **не для кодовых задач** — Claude Code его читать
не обязан. Техническое состояние, модели, команды и баги — в `CLAUDE.md`.

## Позиционирование

Конкуренты в нише — **курсы** (видео + вебинары + наставник). Мы — **инфраструктура**
для преподавателя и ученика: банк задач с фильтрами, конструктор листков, графический
калькулятор, ИИ-репетитор. Это разные бизнесы.

Образ: **AoPS + Desmos + Gradescope, но для русской олимпиадной экономики.**

Главный дефицитный ресурс — время и последовательность одного человека. Ключ к успеху —
жёсткая очередь и решительный отказ от лишнего, а не добавление фич.

## Пять частей продукта — вердикты (стратегическая сессия 2026-06-25)

Сайт — это по сути 5 отдельных продуктов на общем фундаменте (корпус + эмбеддинги +
ИИ-репетитор + калькулятор).

1. **Каталог + ИИ-обсуждение + поиск «опиши задачу»** — ядро и флагман. Поиск по
   описанию бьёт в реальную боль рынка («не найти ту самую задачу»), строится на готовых
   эмбеддингах, почти бесплатен. Генерация задач «как товар» — НЕ делать (риск битых
   задач); только как поисковый приём (HyDE) или черновик с пометкой «ИИ, не проверено».
2. **Калькулятор** — козырь, единственная часть без конкурентов в нише. Планы не трогать.
3. **Репетитор ↔ ученик ↔ родитель** — основной денежный контур B2T, частично готов.
   Календарь свести к «расписанию» (не строить полноценный). **Не запускать платно до
   решения вопроса данных детей** (152-ФЗ).
4. **Интерактивный учебник** — сильно ужать. «Полный учебник из чужих учебников» —
   кандидат на заморозку (дорого, юридически опасно). Ужать до **оригинальных коротких
   теорий по 21 теме** на готовой модели `TheoryPage` + встроенный график + ИИ-объяснение
   абзаца + проверочные задачи. Ачивки держать лёгкими (бренд «без геймификации»).
5. **Онлайн-режимы (олимпиады + дуэли)** — фазы 2–3. Олимпиады с призами и ручной
   проверкой — операционная машина, отложить дальше всего. **Дуэль** в стиле тактического
   штурма chess.com — вирусный незанятый формат; начинать с версии **против бота** (живой
   PvP требует websockets — отдельный технический скачок).

## ИИ-репетитор — как «обучать» (главный вывод)

**Дообучать модель (fine-tuning) НЕ нужно** — оно меняет стиль, а не вкладывает знания,
дорого и хрупко; у Anthropic его и нет. Правильный путь — **RAG**: доставать из базы
нужную задачу + проверенное решение + теорию → подкладывать модели → она отвечает по
твоему материалу. Фундамент RAG (эмбеддинги, корпус, поиск) уже построен.

«Обучение» = качество поиска + системный промпт + few-shot-примеры. Ожидаемый результат —
полезный сократический помощник на ~5 400 задачах с решением; слабее/рискованнее там,
где решения нет. Требует постоянного замера (A/B, как у Khan Academy), а не «настроил и
забыл».

**Надёжность математики (критично для бренда «precision = trust»).** Сырые языковые
модели непригодны для многошаговой математики — предсказывают правдоподобные числа.
Доказано на Khanmigo: убрали выделенный калькулятор — ошибки удвоились, смена модели не
спасла. Архитектура безопасного репетитора (4 слоя):
1. **Заземление** на проверенных решениях — объясняем известный ответ, не выводим с нуля.
2. **Арифметика через инструмент кода** (Python-песочница Claude API), не «в уме».
3. **Шаг проверки** — сверять и числа, и вердикт «верно/неверно».
4. **Ограничение охвата** — сократические подсказки там, где есть решение; генерация —
   только черновик + ревью.

**Модель `Hint` — ключевой актив:** репетитор раскрывает заранее написанные подсказки и
лишь адаптирует их ИИ — это резко снижает риск «вранья». Наполнять `Hint` для топ-задач —
отдельная кураторская задача.

## Экономика ИИ (цены mid-2026, за 1 млн токенов)

- Haiku 4.5 — $1 / $5; Sonnet 4.6 — $3 / $15; Opus 4.8 — $5 / $25.
- Кэширование промпта — −90% на повторный вход; батч — −50% (офлайн, не для живого чата).
- У Anthropic НЕТ своих эмбеддингов и fine-tuning.
- ⚠️ Русский текст съедает ~1,5–3× больше токенов, чем английский (мерить на своих данных).

Оценки на Sonnet с кэшем: реплика репетитора ~$0,02; сессия ~$0,12–0,24; объяснение
абзаца ~$0,01–0,015; семантический поиск ~$0 базовый (эмбеддинг локально) / ~$0,02 с HyDE
на Haiku. **На активного платящего ученика ~$2–6/мес на Sonnet (~$2 на Haiku).**

**Бизнес-вывод:** ИИ покрывается подпиской ПРИ условии — ИИ только за платным тарифом,
потолки сообщений по тарифу, кэширование, роутинг моделей (Haiku на дешёвое, Sonnet на
репетитора, Opus в резерве). Опасность — безлимит на бесплатном или пара «тяжёлых»
пользователей. Семантический поиск почти бесплатен (локальные эмбеддинги).

## Конкурентный ландшафт

**Русскоязычный рынок** — все курсы: Олмат (olmath.ru — доминирует, 96/173 дипломов
финала ВсОШ 2025, 20 000+ учеников), Олимп (olymp.education), Школково, Фоксфорд.
Сириус.Курсы — 7 направлений, **экономики нет**. У Фоксфорда есть геймифицированный
тренажёр с рейтингом/призами — но это сезонная олимпиада-событие, а не круглогодичная
дуэль; формат дуэли chess.com для экономики свободен.

**Западный рынок (ИИ-проверка, зрелая категория 2025–2026):** Class Companion (Panorama
Education), Fiveable (FRQ по 34 предметам AP), Notie AI (спец-грейдер по экономике
AP/IB/A-Level). Все проверяют **качественные эссе/FRQ**, НЕ многошаговые числовые
олимпиадные задачи — наш тип проверки другой.

**Вывод:** банка-инструмента с фильтрами, конструктором листков, графиком и
ИИ-репетитором — ни у кого. Для русской олимпиадной экономики аналогов нет. Позиционирование
«инфраструктура, а не курс» подтверждено.

## Тарифы (набросок)

- **Фримиум:** бесплатный калькулятор как крючок + просмотр каталога, БЕЗ ИИ.
- **Платный ученик:** полный каталог + ИИ-репетитор (потолок сообщений) + семантический
  поиск + прогресс + дуэли.
- **Платный преподаватель:** конструктор / проверка / группы.
- **Родитель:** в комплекте / довеском за отчёты.

Цени как **SaaS-инструмент** (продаём рычаг + ИИ), не как курс. Готовность платить
высокая: премии за олимпиады до 500 000 ₽ единоразово + до 40 000 ₽/мес в вузе + БВИ.

## Игры как канал привлечения (решение 2026-07-11)

Решение преподавателя: **Econ Rush** — публичная игра на скорость по тестам банка
(`/game/`, без логина) — строится как инструмент набора популярности к
первоначальному запуску платформы. Зафиксированная механика (не прогноз):

- **Продукт:** 60 секунд на таймере, реальные тестовые вопросы банка (пул-кэш
  `GameQuestion`, ~1,1 тыс. русских вопросов после консервативного отбора),
  верный ответ +6 с, неверный −4 с, очки с комбо-множителями. Позиционирование —
  «серьёзная игра на скорость про экономику», тон бренда тот же
  (Ясный · Дружелюбный · Точный); учебные кабинеты остаются без геймификации
  (зафиксировано в PRODUCT.md).
- **Вирусный механизм:** кнопка «Скопировать результат» на финальном экране —
  готовая строка «Econ Rush: N очков · верных/всего · комбо ×N — обгони меня:
  <ссылка>» для вставки в чаты. Рекорд хранится локально; глобального
  лидерборда пока нет (кандидат на усиление механики после запуска).
- **Связь с воронкой:** финальный экран «Разобрать ошибки» ведёт по каждому
  промаху на страницу задачи в каталоге (`/catalog/<id>/`) — из игры в
  контент платформы; игра публична и работает без регистрации, т.е. может
  распространяться до открытия регистрации.
- **Статус:** реализована в ветке `feat/econ-rush` (ночь 2026-07-11), в `main`
  не влита, на прод не деплоилась.

## Пять новых функций (не в текущих планах, на существующих активах)

1. **Импорт «своего архива» для преподавателя.** Загружает PDF/DOCX/TeX → система режет
   на задачи, размечает темы/сложность ИИ → экран проверки → приватный банк. Основа: 13+
   готовых парсеров. Перенёсший архив преподаватель уже не уйдёт (retention).
2. **Автопроверяемые графические задания.** «Постройте рынок, введите налог, закрасьте
   DWL» → ученик строит в калькуляторе → сравнение с эталоном (с допуском) → авто-балл.
   Основа: вся математика равновесий/CS/PS/DWL уже есть. Самая защищённая фича.
3. **Индивидуальные варианты домашки (анти-списывание).** Похожие задачи через эмбеддинги
   + параметрическая рандомизация чисел с автопересчётом ответа. Списывание — боль №1
   групповых домашек.
4. **Telegram-бот как лёгкий клиент.** Задача дня, напоминания, быстрые тесты, пуши
   «проверено» / «N решений ждут». Школьники живут в Telegram; бот дешевле приложения,
   двигатель возвращаемости + вирусность.
5. **Кабинет родителя + автоотчёты.** Только чтение + еженедельный дайджест. Родитель —
   плательщик в B2C; самая дешёвая в разработке, прямой рычаг денег.

## Бизнес-процессы: пять контуров

1. **Контентный конвейер.** Импорт → проверка прав → чистка/таксономия → «золотой фонд»
   → публикация. У каждого `Source` — обязательный статус прав; задача без «зелёного»
   статуса физически не в публичной выдаче. Первый найм — контент-редактор (сильный
   студент-олимпиадник) на сдельной.
2. **Продуктовый цикл.** 10–15 дизайн-партнёров (бесплатно за реальное использование и
   обратную связь). Двухнедельные циклы. North Star — число листков/домашек в неделю.
   Активация — первый листок за ≤15 минут.
3. **Привлечение.** Воронка: бесплатный крючок → канал → регистрация → активация → оплата.
   Крючки: публичный калькулятор, Telegram «задача дня», демо-видео. Первые 50 клиентов —
   личные продажи руками. Амбассадоры: год бесплатно за три публичных кейса.
4. **Удержание.** Онбординг через готовые сценарии, Telegram-чат с ответом в тот же день,
   ежемесячный дайджест «что нового», оформленные кейсы. Метрика — удержание платящих
   через 3 месяца.
5. **Операционный фундамент (до денег, а не после).** (а) Данные: с первого дня
   логировать каждое решение ученика — сырьё для рекомендаций и отчётов. (б)
   Инфраструктура: PostgreSQL, бэкапы, мониторинг. (в) Юрисдикция и данные — см. правовой
   контур ниже.

## Пять больших шагов (дорожная карта запуска)

1. **Юридический фундамент и чистое ядро (1–2 мес).** Статусы прав на все источники;
   3–5 тыс. юридически чистых вычищенных задач; договорённости с 2–3 авторами. Гейт: ни
   одна задача без зелёного статуса не видна публично.
2. **Закрытая бета с дизайн-партнёрами (2–3 мес).** 10–15 преподавателей на реальных
   занятиях. Цель — факт «собирают домашки быстрее», не «нравится». Гейт: 8/15 собрали
   3+ листка + три письменных кейса.
3. **Коммерческий запуск B2T (3–6 мес).** Боевой сервер, тариф преподавателя, онбординг,
   личные продажи. Цель: 30–50 платящих преподавателей. До этого B2C и ученический
   кабинет заморожены.
4. **Маркетинговая машина на бесплатных крючках.** Публичный калькулятор-визитка, «задача
   дня», демо-видео, амбассадоры. Гейт: 100+ регистраций/мес из самостоятельных каналов.
   Цель: 100–200 платящих.
5. **Ученический контур и вход в данные.** Полный цикл: домашка ссылкой → решение →
   проверка → прогресс. Первые B2C-треки («МОШ за 60 дней»). Здесь включаются новые
   функции 1–5 (питаются данными этого шага). Международное расширение (IEO/IB на
   английском) — шаг шесть, только после.

## Правовой контур (152-ФЗ) — кратко

Владелец/оператор — **в России** (прежняя запись про Финляндию неверна; трансграничный
риск ЕС↔РФ снят). Действует **152-ФЗ**: персданные граждан РФ нельзя хранить в базах за
пределами России; за данные несовершеннолетних — в т.ч. уголовная ответственность.
Текущий Render (США) — несоответствие при живых пользователях. **До запуска** перенести
базу на российскую инфраструктуру (Яндекс Облако / SberCloud / VK Cloud), оформить
политику конфиденциальности и согласия, российский приём платежей (ЮKassa). Подробности —
в `CLAUDE.md` (раздел «Правовой контур»). Нужна сверка с юристом.
