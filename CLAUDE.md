# CLAUDE.md — точка входа

Платформа задач по олимпиадной экономике. Владелец — преподаватель, не
программист: он ведёт проект и принимает решения, код пишет Claude Code.
Объяснять простыми словами, комментарии в коде — по-русски.

**Этот файл короткий и таким остаётся.** Он говорит, что запрещено, как
запустить, где границы приложений и куда идти за подробностями. Всё остальное —
в профильных документах ниже.

## P0 — запрещено всегда

- **`git push --force`** и **`git rebase`** на общих ветках.
- **`migrate --fake`** без явного разрешения владельца.
- **Массовая правка `statement` / `answer` / `solution` моделью.** ИИ дописывает
  НОВЫЕ поля, существующие не трогает. Причина: свип Батча 2 испортил 233 поля в
  195 задачах — [ADR 0005](docs/adr/0005-ai-writes-new-fields-only.md).
- **Пуш в `main` без явного «да» владельца.** Пуш в `main` = выкатка на прод.
- **Две параллельные сессии Claude Code в одной папке** — только через
  `git worktree`.
- **Отправка полей профиля пользователя в модель.** Наружу уходит только текст
  задачи, текст решения и рубрика; список разрешённых полей — в `problems/ai/`.
- **Установка чужих skills пачкой.** Только собственный проверенный список.
- **`makemigrations game` на `main`** — файлы миграций `game` **0007–0012** лежат
  в ветке `feat/econ-rush-figure`, на `main` их нет. Автодетектор сочинит свою 0007
  под тем же номером, и при слиянии ветки получится неразрешимый конфликт номеров.
  [game/CLAUDE.md](game/CLAUDE.md) · [ADR 0004](docs/adr/0004-game-migrations-split.md).

## Как запустить

```bash
venv313/Scripts/python.exe manage.py runserver   # Windows
./venv313/bin/python manage.py runserver         # macOS
```

Стек — **Python 3.13 + Django 5.2 LTS**. Окружение `venv313/`; `venv/` (3.9) и
`venv312/` оставлены как страховка перехода.

Сайт: http://127.0.0.1:8000/ · Админка: `/admin/` · Демо-данные: `manage.py seed_demo`

⚠️ **Тестовые пароли публично известны** (`admin12345` и подобные). Перед показом
кому-либо — `manage.py lockdown_dev_accounts --apply`.

### Проверки перед сдачей работы

```bash
manage.py check                              # 0 ошибок
manage.py makemigrations --check --dry-run   # ничего не предлагает создать
manage.py test                               # 2 558 тестов на SQLite, ~26 мин

docker compose -f docker-compose.dev.yml up -d        # PostgreSQL 17 + Redis 7
manage.py test --settings=config.settings_test_pg     # то же на PostgreSQL, ~23 мин
```

**Зелёный прогон на SQLite больше не считается доказательством** — прод живёт
на PostgreSQL. Подробности и найденные расхождения — [docs/TESTING.md](docs/TESTING.md).

Плюс визуальная проверка человеком того, что менялось на экране. «Тесты зелёные»
доказывает математику и разметку, а не то, что красиво.

### Часто нужные команды

```bash
build_embeddings --limit N        # эмбеддинги для задач без вектора
night_embeddings --ids-file F     # пересчёт по списку id (⚠️ ловушка done-файла)
cache_similar                     # залить «похожие» в M2M — этим живёт прод
quality_gate --apply / --revert   # шлюз качества, обратимый
find_duplicates --threshold 0.95  # заполнить DuplicateCandidate
lockdown_dev_accounts [--apply]   # погасить дев-аккаунты
```

Подробности — в [docs/EMBEDDINGS.md](docs/EMBEDDINGS.md) и [docs/DATA.md](docs/DATA.md).

## Границы приложений

| Приложение | За что отвечает |
|---|---|
| `problems` | Ядро: **все** модели, импорт, движки, слой ИИ |
| `catalog` | Публичный каталог, подборки, экспорт, семантический поиск |
| `student` | Кабинет ученика |
| `teacher` | Панель преподавателя, группы, конструктор работ |
| `game` | Econ Rush — игра на скорость |
| `calc2` | Графический калькулятор — единственный |
| `calendar_stub` | Календарь занятий |

**Модели живут только в `problems`.** Приложению нужна новая сущность — заводит
её в `problems/models*.py`, а не у себя. Исключение — `game.GameQuestion`:
игровой пул намеренно отделён от банка, чтобы удаление задачи не ломало журнал.

Локальные правила слоёв (читаются вместе с кодом, который правите):
[`problems/ai/`](problems/ai/CLAUDE.md) ·
[`problems/management/commands/`](problems/management/commands/CLAUDE.md) ·
[`catalog/`](catalog/CLAUDE.md) · [`calc2/`](calc2/CLAUDE.md) ·
[`game/`](game/CLAUDE.md)
