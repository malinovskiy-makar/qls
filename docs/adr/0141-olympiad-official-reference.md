# ADR 0141 — Официальный эталон олимпиад: source_site=official, правило близнецов «PDF с PDF», импорт после привязок

* **Дата:** 2026-10-09
* **Статус:** принято владельцем (стоп-гейты 1 и 2 сессии 3 пилота ВП), ветка `feat/olympiad-vp-write`, в `main` не влито.

## Контекст

Аудит олимпиад (решение 08.10: «полный исторический банк») сверяет банк с
официальными PDF организатора. Привязки `OlympiadRef` до этого умели
указывать только на агрегаторы (`source_site` = `solvehub` / `ile`), номер
агрегатора оказался позицией в их списке (123 из 573 строк ВП с неверным
номером), а 21 задание эталона числилось недостающим.

## Решение

1. **`source_site='official'`** — отдельное значение (миграция 0079), а не
   «правда в `raw_meta`»: модель нужна для всех олимпиад списка, и строка
   по официальному PDF не должна притворяться агрегатором. Старые ссылка,
   номер и класс агрегатора при правке не теряются — уходят в `raw_meta`.
2. **Запись только командой с журналом** (`apply_olympiad_audit`): сухой
   прогон по умолчанию, запись — `--apply --yes-i-have-owner-approval`,
   откат по журналу до единицы.
3. **Правило близнецов — «PDF с PDF».** Строка, чей текст ведёт в комплект
   соседнего класса, остаётся на своём классе, если в своём комплекте есть
   то же задание: текст банка ≥ 0,90 к нему ИЛИ найденное задание соседнего
   класса ≥ 0,90 к нему (два PDF между собой). Буквальное правило «только
   текст банка» не дотянуло в 19 из 59 случаев — шапка «(20 баллов)» против
   «(25 баллов)», вёрстка — и в одном случае поставило бы неверный класс.
4. **Импорт недостающих — последним и со сверкой.** Задание не
   импортируется, если к нему уже привязана задача банка — официальной
   строкой или строкой агрегатора, переведённой на официальный комплект
   (`raw_meta['official_event_id']` + номер). В пилоте это сократило импорт
   с 21 до 6: остальные 15 уже были в банке.
5. **Новые задачи — скрытые до глаз владельца** (`draft` +
   `hidden_pending_review`), формат `markdown` — как у копий Школково той
   же олимпиады; рисунки вырезаются из PDF в `ProblemFigure`.

## Отвергнуто

* **Буквальное правило близнецов** — см. п. 3.
* **Импорт всех 21 из очереди сессии 2** — создал бы 15 дублей: очередь
  составлялась до записи привязок.
* **Номер агрегатора как официальный** — неверен в 21 % строк ВП.

## Последствия

* Блок «Олимпиада» входит в отпечаток эмбеддинга: после записи привязок
  нужен `build_embeddings --stale` (в пилоте 437 задач).
* `import_olympiads_data --wipe` сносит карточки `vp-fingram` / `vp-ob` —
  после него `olympiad_official_sources --apply`.
* Подробности, формат файлов и ловушки — [docs/OLYMPIAD_AUDIT.md](../OLYMPIAD_AUDIT.md).
