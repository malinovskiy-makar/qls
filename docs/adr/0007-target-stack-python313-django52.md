# ADR 0007. Целевой стек: Python 3.13 + Django 5.2 LTS + PostgreSQL 17

**Источник:** разбор архитектуры под запуск в РФ (18.08.2026) + решение владельца.

## Контекст

Python 3.9 без обновлений с 31.10.2025. Django 4.2 LTS без патчей безопасности
с 07.04.2026. **Прод сейчас живёт без патчей.**

Почему мы вообще на 3.9 — в [ADR 0001](0001-python39-django42.md).

## Решение

Переходим на **Python 3.13 + Django 5.2 LTS + PostgreSQL 17**.

## Почему не 6.x

- Django 6.0 и 6.1 — **не LTS**; следующий LTS только 6.2 в апреле 2027.
- Django Channels официально не поддерживает 6.1.
- 6.1 отказался от PostgreSQL 14.

Django 5.2 LTS поддерживается до апреля 2028 — это два года вперёд и
единственный вариант, не ломающий планы по игре.

## Побочные выгоды

- **Снимается запрет на `int | None`** (union-синтаксис появился в 3.10).
  Оговорка про `Optional` уходит из корневого `CLAUDE.md` — но только после
  фактического перехода, не раньше.
- Исчезает проблема `urllib3` v2 на LibreSSL, из-за которой локально падал
  подбор домашки.
- **Возвращается PDF-экспорт**: на своём сервере TeX Live ставится штатно.

## Что НЕ меняем

Шаблоны Django вместо SPA. D3 + Math.js в `calc2`. numpy для векторного поиска —
31 500 × 1024 считается за **2,81 мс**, векторная база не нужна.
