# ADR 0006. Документация разложена по темам, история отделена от справочника

**Дата:** 2026-08-18

## Контекст

`CLAUDE.md` вырос до 4 435 строк и смешивал три разных жанра:

- справочник (стек, модели, команды, ловушки) — читается при каждой задаче;
- история сессий («Сессия 9», «Ревью 16.08», разборы прошлых багов) — читается
  раз в жизни, чтобы понять «как это было»;
- планы и статус — которые вообще-то живут в Notion.

Последствия были предсказуемые: важный запрет тонул в потоке, а устаревшая
инструкция из истории побеждала актуальную, потому что лежала ниже и выглядела
свежее.

## Решение

Один документ — одна тема и один владелец.

```
CLAUDE.md              ≤250 строк: команды, границы, P0-запреты, карта истины
CLAUDE_ARCHIVE.md      история сессий целиком
docs/ARCHITECTURE.md   стек, приложения, деплой, ограничения хостинга
docs/SECURITY.md       границы доверия, секреты, известные дыры
docs/RUNBOOK.md        эксплуатация: выкатка, заливка данных, инциденты
docs/EMBEDDINGS.md     поиск: устройство, промахи, порядок работ
docs/TESTING.md        слои проверок и их ловушки
docs/DATA.md           банк задач: цифры, конвейеры, брак
docs/DESIGN.md         дизайн-система (переехала из корня)
docs/adr/              решения с обоснованием
<приложение>/CLAUDE.md локальные правила слоя
```

У каждого файла шапка: владелец, дата обновления, статус
(актуален / заморожен / заменён).

## Почему именно так

- **Порог входа.** Сессия читает 200 строк корневого файла и идёт в нужный
  раздел, а не пролистывает 4 000 строк в поисках одного запрета.
- **Локальные `CLAUDE.md`** попадают в контекст вместе с кодом слоя, который
  правят. Правило про импорт лежит рядом с импортом, а не в общей куче.
- **P0-запреты вынесены наверх** отдельным коротким блоком. Запрет, который надо
  искать, не работает.
- **История никуда не делась.** Всё перенесено в архив, ничего не удалено:
  разбор старого бага — единственный способ не повторить его.

## Отвергнутые варианты

- **Оставить один файл, но сократить.** Уже пробовали; файл снова разрастается,
  потому что каждой сессии есть что дописать, а места для этого нет нигде больше.
- **Перенести всё в Notion.** Notion не попадает в контекст сессии автоматически
  и недоступен в headless-прогонах. Техническая правда должна лежать рядом с кодом
  и версионироваться вместе с ним.

## Как этим пользоваться

Изменилась техника — правьте профильный файл в `docs/`, а не корневой.
Приняли решение — заводите ADR и карточку в Notion «Решения».
Закончили сессию — история идёт в `CLAUDE_ARCHIVE.md`, а не в `CLAUDE.md`.
