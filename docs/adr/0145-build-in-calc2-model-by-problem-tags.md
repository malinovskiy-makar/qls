# ADR 0145 — «Построить в «Графиках»»: модель по тегам задачи, без поля у задачи

* **Дата:** 2026-10-10
* **Статус:** принято, ветка `feat/calc2-redesign`; меняет раздел 12 и 18 Б.2 спецификации редизайна
  (`claude/CALC2_REDESIGN_SPEC_20260927.md`): поля `calc2_preset` у задачи нет, разметки задач нет, чисел из условия нет
* **Автор:** Claude Code
* **Решения владельца в Notion:** «Графики, вторая очередь: «Построить в Графиках» открывает модель по теме задачи,
  без чисел из условия; делаем сразу в ветке редизайна» (10.10); «Построить в Графиках»: строим без замера покрытия
  дома; точный замер — перед выкаткой на dev командой calc2_link_coverage, кнопку выкатываем при покрытии ≥ 10 %»
  (10.10). Журнал — `claude/PROGRESS_CALC2_FROM_PROBLEM_20261010.md`.

## Контекст

Спецификация редизайна предлагала у задачи новое поле `calc2_preset` (модель и числа из условия) и разметку
31 694 задач моделью или руками. Это миграция в `problems` (миграция в `problems` уронила прод 18.09), бюджет на
разметку и риск неверных чисел в условии. При этом у задач на бою уже есть канонические темы (29) и теги (344).

## Решение

1. **Кнопка на странице задачи** «Стола» (`catalog/stol/_calc_link.html`, подключён в `_stol_center.html` сразу под
   `section.stm`, до вариантов теста и «Как прошло?»): пилюля «Построить в «Графиках»» и подпись «Откроется модель
   «…». Числа из условия впишите сами.»; при второй модели — «Или:» и ссылка. Ведёт на
   `/calc2/?m=<ключ модели>&from=<id задачи>` в той же вкладке. Та же разметка уходит в `center_html` ответа `?pane=1`.
2. **Модель — по каноническим тегам задачи, в коде** (`catalog/calc2_link.py`): таблица `TAG_TO_MODEL` (119 строк) и
   запасная `TOPIC_TO_MODEL` (10 тем) утверждены владельцем 10.10. Берутся только теги `kind='canonical'` и темы
   `is_canonical=True`, уже загруженные `_problem_context` (+0 запросов). Тема в счёт только у задачи без единого
   канонического тега; есть теги, но ни один не в таблице — кнопки нет. Порядок: частные модели, общие (`GENERAL`),
   базовые (`BASE = {sd, m-graph}`); внутри уровня — больше тегов за модель, дальше порядок таблицы; показываем две.
3. **Вход в «Графики» живёт как открытая ссылка «Поделиться»** (`openFromProblem`, `91-session.js`): модель в
   стартовом виде, автосохранение этой модели не поднимается и не затирается до первой правки (`_fromLink`); с
   первой правки это состояние человека, а `from` уходит из адреса (`history.replaceState`) — перезагрузка не вернёт
   старт. `from` — только `^[0-9]{1,9}$`, иначе обычный вход по `?m=`. Над холстом строка «← Вернуться к задаче»,
   номер задачи на экране не пишется (правило каталога); смена модели строку убирает.
4. **Покрытие меряется командой** `manage.py calc2_link_coverage` (только чтение). Обязательный шаг выкатки: запуск на
   dev.weconomics.ai, когда ветка в `main` и площадка её подхватила; кнопку выкатываем на бой при покрытии от 10 %
   видимых задач:
   ```bash
   cd /srv/weconomics/dev/app && docker compose -f deploy/docker-compose.dev-site.yml exec web-dev python manage.py calc2_link_coverage
   ```
5. **Заодно (та же сессия):** подпись отрезка площади «на отрезке [0; 100]»; мерка канона `label_shake` считает отрыв
   подписи от её кривой, а не сдвиг по экрану (подпись, едущая вслед за кривой, не скачок).

## Отвергнуто

* Поле `calc2_preset` у задачи и миграция — ради чисел из условия, от которых отказались.
* Разметка модели и чисел ИИ — бюджет и риск неверных чисел; ручная разметка небольшого набора — не масштабируется.
* Запасной путь по теме при любых тегах — задача про олигополию с темой рынка получила бы чужую модель.
* Открывать из задачи сохранённое состояние модели — человек пришёл решать эту задачу, а не продолжать прошлую.

## Последствия

* Таблица — код, а не данные: новая модель в Графиках или новый тег таксономии — правка `calc2_link.py`; сторож
  `catalog/tests/test_calc2_link.py` (строки есть в `data/taxonomy.json`, ключи и имена = `SCENE_NAMES`).
* Дома кнопки не видно: в `db.sqlite3` владельца канонических тегов нет (база старая). Снимки — на `db_check.sqlite3`.
* Приборы: `calc2/tests/from_problem_probe.mjs` (вход, автосохранение, чужой `from`, 390 px, подпись отрезка).
