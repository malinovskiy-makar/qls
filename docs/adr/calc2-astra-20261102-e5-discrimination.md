# Э5 — сравнение дискриминации и единой цены

Принятое решение 29.10 исполнено локально 02.11.2026. На проверке у Макара.

Существующее поле затрат третьей степени принимает явное TC=…, прежняя
запись остаётся MC. Общие TC считаются от суммарного выпуска. Постоянные
затраты вычитаются в обоих режимах. Сравнительная таблица всегда показана,
кроме скрытого ответа в «Сначала сам»; нулевая продажа не получает фиктивной цены.
Единая цена выбирается глобально среди стационарных точек, изломов и границ.
Для нелинейных групп решаем по цене: вложенное обращение суммарного спроса
блокировало интерфейс. Производные символьные, интегралы уточняются.

Для первой степени TC остаётся доступной ролью функции. Её производная MC
рисуется на ценовой оси; FC входят в прибыль, а не в площадь излишка фирмы.

Проверки: 6.25 и6.27, независимый перебор цены, линейные/нелинейные/
горизонтальные группы, выпадение группы, нулевой выпуск, большие FC,
общие TC, ссылка/история/TeX/самопроверка, два браузера×две темы×две ширины.
Исторические базовые снимки не переписаны: новый вычисляемый раздел
проверяется аналитически, прежние поля — по снимку с точностью1e-6.
Мутации проверяют неверный выбор первого корня, потерюFC в обоих сценах.
