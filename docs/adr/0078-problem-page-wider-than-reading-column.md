# ADR 0078. Страница задачи шире общей полосы чтения — под постоянную карточку справа

**Нумерация:** файл перенумерован из 0070 при синхронизации веток 05.09.2026 (номер был занят)

**Дата:** 2026-09-04 · **Статус:** принято · **Ветка:** `feat/catalog-redesign`
**Нумерация:** 0066–0069 заняты веткой `feat/olympiads-screens`, которой нет в
`main`; чтобы не повторить историю двух ADR с одним номером, эта ветка
начинает с 0070.

## Контекст

Канон (`DESIGN.md` §1.9) задаёт две ширины полосы содержания: `--w-page`
960 px для обычной страницы и `--w-read` 860 px для страниц, где основное —
длинный текст с формулами. Страница задачи — страница чтения, и жила в 860.

Решение владельца 04.09.2026 (Notion «Решения»): ИИ-чат на странице задачи —
**постоянно видимая карточка справа от задачи**, не выдвижная панель. Рядом с
условием шириной 860 карточке места нет: либо условие сжимается до ~500 px,
либо карточка уезжает под условие и перестаёт быть «постоянно видимой».

## Решение

Страница задачи получает свою полосу **1120 px** (`.pd-wrap`) и сетку из двух
колонок `minmax(0, 1fr) 328px` (`.pd-grid`): слева условие и решение в
привычной ширине чтения (около 760 px), справа липкая колонка (`.pd-side`,
`top: 72px`) с карточкой чата. Ниже 980 px сетка складывается в одну колонку,
карточка идёт под задачей.

Технически: `catalog/base.html` печатает `<main class="{% block main_class %}page-wrap{% endblock %}">`;
страница задачи переопределяет блок на `pd-wrap`. Остальные экраны каталога
блок не трогают и остаются на 860.

Исключение записано в `DESIGN.md` §1.9 рядом с правилом, а не спрятано в
шаблоне.

## Отвергнуто

- **Оставить 860 и убрать чат под условие** — противоречит решению владельца
  о постоянно видимой карточке.
- **Выдвижная панель чата** — отвергнуто тем же решением: панель, которую
  надо открыть, не «постоянно видна».
- **1120 везде** — решение «Полировка к бете» 04.09 закрепило 960/860 для
  остальных экранов; расширять всё ради одной страницы незачем.

## Последствия

- Колонка чтения на странице задачи ≈ 760 px — короче 860, читается не хуже.
- Правило §1.9 получает одно записанное исключение; следующее исключение —
  повод переписать правило, а не приписать вторую оговорку.
