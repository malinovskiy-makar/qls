# ADR 0147 — Форма КПВ — только после проверки на всём отрезке; КТВ не хуже правила наибольшей ценности

* **Дата:** 2026-10-13
* **Статус:** принято, ветка `feat/calc2-redesign` (ошибка есть и на `main`, на бой правка уходит со слиянием
  редизайна)
* **Автор:** Claude Code
* **Карточки Notion:** «calc2 «КТВ. Одна страна»: кусочная КПВ принимается за прямую (проба в 4 точках)» (13.10,
  блокер); «КТВ по кусочной КПВ выбирал заведомо худшую точку производства» (24.08); «Внутренняя цена X (наклон
  КПВ) показывает NaN при кусочной КПВ» (21.08). Журнал — `claude/PROGRESS_CALC2_FIXES_20261013.md`, фаза 1.

## Контекст

`classifyPpf` (`54-scenes-ppf.js`) подгонял форму КПВ по четырём пробным точкам: 20, 40, 60 и 80 % от Xmax. У КПВ
владельца 500 − X² (X < 4), 516 − 8X (4 ≤ X < 54), 100 − (X − 50)² (X ≥ 54), конец X = 60, все четыре пробы легли
на прямой участок, и форма вышла «прямая, a = 500, b = 8» (у такой прямой свободный член 516). `recomputePpfTrade`
пошёл веткой прямой: Pw 7,39 < 8 → угол (0; 500), КТВ Y = 500 − 7,39X шла НИЖЕ КПВ. Общее правило `bestByValue`
(максимум Y + Pw·X, введено 24.08 для кусочных) дало бы верное касание (3,695; 486,347), но до него дело не дошло.
Та же классификация кормит «КТВ. Две страны» и сложение КПВ.

## Решение

1. **Форма принимается только после проверки на сетке** (`ppfFitsOnGrid`): 201 узел [0; Xmax] с обоими краями,
   расхождение с КПВ не больше 10⁻⁶·Ymax; у прямой вдобавок свободный член подгонки совпадает с f(0). Проверку
   проходит каждое семейство (прямая, дуга, парабола, выпуклая, poly2, power); не прошла ни одна — `unknown`, и
   точка ищется общим правилом. Порядок распознавателей (ADR 0049) не менялся.
2. **Точка производства «КТВ. Одна страна» не хуже общего правила**: что бы ни выбрала ветка по форме, ценность
   Y + Pw·X в ней сверяется с `bestByValue`; меньше (больше чем на 10⁻⁷ относительно) — берётся точка общего правила.
   Ветка «нет торговли» у прямой (Pw ровно равна наклону) сохранена.
3. **«Внутренняя цена X (наклон КПВ)» у нелинейной КПВ — диапазон альтернативных издержек «от … до …»**
   (`ppfOcRange`): у опознанного семейства формулой (`ocAt0/ocAtMax`, у дуги и выпуклой на краю ∞), у
   неопознанной — численно. У прямой — одно число, как раньше. «Разбор» сравнивает мировую цену с диапазоном,
   у излома говорит про излом, у угла нелинейной КПВ — про ценность выпуска, а не «КПВ прямая».
4. **«КТВ. Две страны» не переписывалась** (автаркическая цена нелинейной КПВ — среднее Ymax/Xmax, производство в
   углах); найденная там ошибка — отдельная карточка «Надо».

## Отвергнуто

* **Больше пробных точек без проверки на сетке:** любой конечный набор проб можно положить на один участок
  кусочной КПВ.
* **Всегда только общее правило `bestByValue`:** у прямой нужна точная ветка «нет торговли» (Pw ровно равна
  наклону), у дуги и параболы касание по формуле точнее сетки; контрольные числа приняты на этих ветках.
* **Наклон КПВ в точке производства числом:** у касания он по построению равен мировой цене, и «Разбор» говорил
  «она совпала с внутренней, поэтому торговать нечем» (так было и у параболы).

## Проверка

`calc2/tests/ktv_probe.mjs` (55 проверок): случай владельца (3,695; 486,347), касание, КТВ 513,653 − 7,39X, предел
69,507, на холсте КТВ нигде не ниже КПВ; свойство на 33 парах КПВ × цена (КТВ ≥ КПВ на 1 000 узлах, касание в
точке, ценность выпуска = максимум по сетке); кусочная 24.08 при Pw = 1 — излом (40; 80); формы 100 − X, 100 − X²,
√(100 − X²) прежние; страховка при подменённой старой пробе. `control_numbers.mjs` 515/515 до и после, вывод
побайтно тот же; `calc2_math.mjs` зелёный. Зубастость: возврат пробы по четырём точкам — 3 провала; снятие сверки
с общим правилом — 3 провала (КТВ ниже КПВ на 13,65).
