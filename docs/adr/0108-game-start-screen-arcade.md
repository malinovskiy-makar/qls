# ADR 0108 — Главная Wecon Rush: «стартовый экран аркады»

* **Дата:** 2026-09-17
* **Статус:** действует

## Контекст

Прежняя `/game/`: четыре карточки-кнопки режимов без призыва к действию, плитки с разным
поведением, пустоты, прокрутка на десктопе. Владелец: «нейрослоп, нужна структурность».
Неверный код набора уводил на общий 404 сайта, карточка набора лежала под сгибом.

## Решение

Решение владельца 17.09.2026 (Notion → «Решения»). Игра — автомат: выбрал режим →
«Играть» → итог → ещё. Экран делится на три зоны:

* **Забег** — переключатель из четырёх режимов (клик только выбирает), панель выбранного
  режима (суть, время, бонус за верный, жизни, число вопросов под фильтром, рекорд, один
  пример вопроса), строка фильтров чипами и одна большая кнопка «Играть · <режим>».
* **Таблица / Статистика** — лидерборд всегда в режиме, выбранном слева (своего ряда
  режимов у таблицы нет), медали у мест 1–3; вкладка «Статистика» заменила плитку
  «Мои рекорды»: вошедшему — «Моя статистика» и вход в панель рекордов, анониму —
  рекорды этого устройства и приглашение войти.
* **Другие способы играть** — четыре ячейки одной анатомии: бесконечные тесты, вызов дня
  (живая строка: сыграно N из 4, серия дней, остаток до московской полуночи), дуэль,
  игра по коду.

Клавиши на старте: 1–4 выбирают режим, Enter стартует, F открывает фильтры.
Код набора проверяется без ухода со страницы: `GET /game/api/set_check/?code=` →
`{exists, url}`. Адрес `/game/?mode=<режим>` выбирает режим, `/game/?duel=<режим>` ещё и
открывает окно создания дуэли — их зовёт публичная страница результата.

Инвариант: на окне 1440×800 у документа нет вертикальной прокрутки (аноним и вошедший).

## Что убрано и почему

* Большой логотип с лозунгом и строка «N вопросов из реальных олимпиад» — занимали первый
  экран, не давая действия; суть режима теперь в панели выбранного режима.
* Три из четырёх декоративных макетов ответа — остался один, у выбранного режима.
* Ряд режимов внутри лидерборда — таблица следует за выбором слева, второй выбор режима
  на одном экране путал.
* Ссылки-дубли «Вызов дня · Дуэль с другом» под счётчиком и кнопка «Войти» в таблице —
  дублировали нижнюю полосу и шапку сайта.
* Кнопка «Добавить фильтры» и старый ряд чипов — заменены строкой «Что решаем» с тремя
  чипами, каждый открывает то же окно фильтров.
* Старт раунда цифрой — цифра теперь выбирает режим (принято владельцем): случайное
  нажатие больше не запускает раунд.

Отвергнуто: точечные правки прежней вёрстки.

## Цена

* Прежние пользователи, привыкшие стартовать цифрой, первым нажатием только выберут режим.
* Проверка кода — лишний запрос перед переходом; неверный код больше не открывает 404.

## Следствия

* Разметка стартового экрана — `game/templates/game/_start.html`; стили и код старта —
  отдельными блоками в `game/templates/game/game.html`.
* `game/views.py`: `api_set_check`, данные ячейки «Вызов дня» и рекорды вошедшего в
  контексте страницы; `game/daily.py`: `streak_for` (серия дней, наполняет фаза P4).
* Описание — `docs/GAME.md`, раздел «Стартовый экран».
