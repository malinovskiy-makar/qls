# ADR 0142 — Эталон олимпиад v2: оцифровка зрячей моделью, мерило по словам, реестр олимпиад

* **Дата:** 2026-10-09
* **Статус:** принято владельцем (решение 09.10 в Notion «Решения»; стоп-гейты 1 и 2 сессии «МОШ, сессия 2»), ветка `feat/olympiad-mosh-write`, в `main` не влито.

## Контекст

Цель аудита олимпиад — полный исторический банк идеального качества (ADR
0141). Эталон v1 — текст, вытащенный из PDF программно: формулы
рассыпаются («2 ( ) = TC Q Q» вместо TC(Q) = Q²), таблицы идут в столбик,
35 отборочных МОШ 2020/21–2024/25 — сканы без текстового слоя. OCR на
русском с формулами даёт мусор. Команды аудита были зашиты под ВП.

## Решение

1. **Эталон v2 — зрячей моделью** (`olympiad_digitize`): страница PDF →
   PNG 200 dpi → GLM-5.3-Flash через `core.run(images=…)` → JSON-блоки
   (шапка, задание, продолжение, рисунок, решение, критерии) → сборка
   заданий с решениями, критериями и вырезанными рисунками. Все PDF ВП и
   МОШ, единое качество. В базу оцифровка не пишет; v2 — источник правды
   для импорта, v1 не используется.
2. **Текстовый слой — мерило, не источник.** `layer_ratio` — совпадение
   СЛОВ расшифровки и слоя в обе стороны (F1 по словам от трёх букв):
   ловит пропуск абзаца и лишний текст и не зависит от рассыпанных в слое
   формул. Плюс совпадение множеств чисел. Посимвольное сходство пишется
   рядом (`layer_fuzz`).
3. **Реестр олимпиад** (`problems/olympiad_audit/registry.py`) и
   обязательный `--olympiad` во всех командах аудита.

## Отвергнуто

* **OCR сканов** — мусор на русском с формулами; решение «35 сканов — OCR»
  заменено в части способа (Notion 09.10).
* **Посимвольное сходство как главное мерило** — на пилоте 20 страниц
  среднее 0,89 при расшифровках, дословных на глаз (5 страниц проверены
  картинкой): страница критериев с формулами Cambria Math давала 0,78.
  Мерило по словам — 0,978; оно же поймало настоящий пропуск строки.
* **Умолчание «ВП» в командах** — МОШ легла бы под чужим названием и в
  чужой `Source`.

## Последствия

* Цена: ≈ $0,0013 за вызов, ≈ $0,002 за страницу с повторами и судьёй
  (пилот 09.10); весь эталон ВП + МОШ (~4 000 страниц) — около $8–12.
* Импорт следующей сессии берёт задания из `reference_problems_v2.jsonl`
  с пометкой `needs_eyes`; ранние ВП 2006/07–2010/11 — копии файлов ВШЭ с
  SolveHub, `official=false`.
* Подробности — [docs/OLYMPIAD_AUDIT.md](../OLYMPIAD_AUDIT.md), раздел
  «Оцифровка зрячей моделью».
