# ADR 0163 — Двигатель импорта эталона v2: разметка пар, судья-модель, замена текста официальным, обновление из новой версии

* **Дата:** 2026-10-28 (ночная сессия P1 «Банк», 28→29.10)
* **Статус:** принято по решениям владельца в Notion (28.10 «…заменяем текст банка официальным; решает думающая модель, старое — в историю версий»; 15.10 о заголовках и теме 30; 14.10 о слаге МОШ-предпринимательства) и по его заранее данным ответам на вопросы гейта 1 И3. Ветка `feat/olympiad-import`, в `main` не влито.
* **Номер:** на ветках origin максимум был 0159; 0160–0162 оставлены трём параллельным ночным сессиям (P2–P4), чтобы номера не столкнулись при сведении.
* **Связано:** ADR 0005 (ИИ пишет только новые поля) — **частично пересмотрен** для пар с официальным эталоном; ADR 0149 (импорт из эталона и автопубликация).

## Контекст

Часть 1 импорта (14.10) показала: 34 пары «на проверку» решает человек, а копии задач в банке часто хуже официальных — пропущена таблица, урезаны пункты. ADR 0005 разрешал только дописывать пустые поля. Впереди — тысячи заданий (экономика ВП + МОШ v6, финграм и предпринимательство МОШ v2), и следующей ночью эталон обновится (v7 / v3).

## Решение

1. **Разметка пар — файлом** (`import_olympiad_reference --decisions`, формат `link_review_decisions.json`): `link` → привязать к `bank_id` даже вопреки двигателю (пустые поля — по правилам части 1), `new` → завести новой, `skip` → пропустить; `unsure` и пусто — как решил двигатель. Пара (задача, тур) уникальна: если задача банка уже привязана к этому туру другим заданием, номер дописывается в `raw_meta.kit_numbers` её строки (журнал — старое `raw_meta`).
2. **Судья-модель** (`problems/olympiad_audit/text_judge.py`, команда `olympiad_text_judge`, Claude `claude-sonnet-5-5`, temperature 0):
   * **замена** — по каждой паре `link` (кроме «комплекта одной задачей»): официальный текст, картинки страниц PDF и текст банка → JSON `{replace, missing, reasons, evidence, confidence}`. Меняем при `replace`, уверенности ≥ 0,8 и цитатах; задачу, одобренную человеком, — только при структурной потере (таблица, варианты, пункты, рисунок). Запись — `apply_official_text`: снимок в `ProblemVersion` «замена официальным эталоном: <причины>», условие → официальное, подпункты — на месте (ни один не удаляется), `content_format` → markdown; журнал, откат;
   * **сомнительная пара** — «то же / другое / не уверен» с цитатами → строка разметки `decided_by = claude:<модель>`, порог 0,85; «не уверен» — человеку.
   Без `--yes` судья только считает план и смету; `--max-usd` обязателен, на 90 % потолка стоп.
3. **Обновление из новой версии эталона** (`update_olympiad_reference`): только задачи, созданные импортом (по журналам), только поля, изменившиеся в эталоне, и только если в базе поле ещё равно старой сборке — иначе конфликт. Снимок в `ProblemVersion`, журнал, откат.
4. **Заголовки** (`title_rule.py`, `import_reference_titles`): официальное название остаётся; заглушка импорта → `title_candidate` обогащения; «начало текста» короче 80 — остаётся. Только у задач журналов импорта.
5. **Строка олимпиады** под заголовком задачи (`catalog/olympiad_line.py`): привязки `official` и ILE, SolveHub — нет (его номера — позиции в списке).
6. **Тема 30 «Бизнес и предпринимательство»** — данными, без миграции: `data/taxonomy.json` v1.2 (30 тем / 350 тегов; теги темы — предложение на сверку канона), дерево карты, блок «Прочее».
7. **Мелкие правила двигателя:** `--as-slug` (МОШ-предпринимательство → `mosh-fingram`, исходная олимпиада — в `raw_meta.original_olympiad` и заметке `SourceReference`, `Source` — свой); `needs_eyes` не пишется; видимость строк v6 без готового флага — `reference_import.auto_publish_of`; тест-вопросы `тест-N.M` — вид теста и варианты в подпункты по обычаю `test_options_from_statement`, ключ в ответ; одинаковые задания двух вариантов одного файла — одна задача, вариант в `raw_meta.also_variants`; адреса файлов — `download_plan.csv`, `raw/fetch_log.jsonl` или имя файла `хост__путь`; числовой отпечаток склеивает разряды с `\ ` в пробелах и переносом строки между группами по 3.

## Почему так

* Разметка файлом — одна дорога и для человека, и для модели: двигатель не знает, кто решил, а журнал помнит (`decided_by`).
* Замена только по решению модели с цитатами и со снимком: слепая замена ломала бы намеренные адаптации, а запрет оставлял бы в банке урезанные копии.
* Обновление «только если поле равно старой сборке» не перетирает правку человека и обогащение.

Отвергнуто: заменять всегда; только дописывать пустые (прежний ADR 0005 для этих пар); удалять лишние подпункты банка при замене (к подпунктам привязаны подсказки и попытки); общий `Source` МОШ финграма для предпринимательства (у него свой официальный архив в реестре).

## Последствия

* Поле «одобрено человеком» по-прежнему включает автоодобрение импорта (ADR 0149); правило «человеку — только структурные потери» отличает людей по `ReviewVerdict.reviewer` без префикса `auto:`.
* Ключ Anthropic без рабочего пространства требует `ANTHROPIC_WORKSPACE_ID` (заголовок `anthropic-workspace-id`); без него судья не работает (ночь 28.10 — так).
