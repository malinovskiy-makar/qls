# Короткая текущая ставка при удержании — 05.11.2026

Владелец подтвердил короткую числовую обратную связь одновременно слева и
на графике. Раньше `CalcNumber.collect` выдавал многоточие для нового
сложного значения, но точную дробь для дешёвого или кэшированного значения.
Поэтому две подписи в пределах одного удержания вели себя по-разному.

Пока точные результаты ожидают завершения жеста, отдельный форматтер
ставки показывает до трёх десятичных знаков; у ненулевых значений меньше
0,001 — три значащие цифры. При сокращении используется ≈. Оба места
получают текущее значение модели, включая прямое перетаскивание клина.
Второе вмешательство и проценты подчиняются тому же правилу.

Форматтер не классифицирует дроби и корни и не меняет STATE. При завершении
возвращается точная запись CalcNumber. Автошаг на отпускании, точный ручной
ввод, скрытие меняющихся координат и анимация верхних результатов сохраняются.

Регрессионная проверка отдельно сравнивает холодный и заполненный кэш,
удержание с паузой, два способа перетаскивания, проценты и ручной ввод.

Дополнительная гонка: `mousedown` клина начинал новый жест до `blur`
прежнего ползунка. Его обработчик ошибочно освобождал удержание нового
жеста. Пока InputSnap активен, blur старого поля не завершает TaxMotion;
окончание остаётся у InputSnap/отпускания. Проверка выдерживает паузу с
зажатой мышью после перехода с ползунка на клин.
