# ADR 0107 — Синхронизация банка с боем обновлением, а не перезаписью

* **Дата:** 2026-09-17
* **Статус:** действует
* **Связан с:** [ADR 0005](0005-ai-writes-new-fields-only.md) — синхронизация
  не пишет тексты сама, она переносит уже принятые дома значения.

## Контекст

Рабочая база дома (`db.sqlite3`) — источник истины банка задач: там идёт
обогащение, ревью, чистка, правка заголовков и таксономии. На бой задачи
заливались переносом корпуса через `bulk_load_fixtures`, а он умеет только
вставлять новые строки (`bulk_create(ignore_conflicts=True)`). Любая правка
в уже существующей на бою задаче туда не доезжала. На 16.09 темы на бою были у
11 139 из 14 087 задач, а при ввозе векторов у 10 411 из 14 082 строк
разошёлся отпечаток текста — ввозить пришлось с `--ignore-text-check`.

## Решение

Две команды на общем движке `problems/bank_sync.py`:

* **`bank_sync_export` (дома)** пишет пакет `bank_sync_<время>/`:
  `problems.jsonl` (задача на строку), `refs.json` (справочники целиком),
  `manifest.json` (формат, HEAD, число задач, хеши файлов). Охват —
  `--scope catalog` (видимый каталог) или `--ids-file`; `--fields` сужает.
* **`bank_sync_apply` (на бою)** сверяет пакет с базой и меняет только
  отличающееся: справочники — обновить или создать по естественному ключу (не
  удаляются); поля задач — `bulk_update` там, где значение другое; связи и
  дочерние строки — множество на бою становится равным пакету. Сухой прогон по
  умолчанию, `--apply` одной транзакцией, снимок внутри неё, `--revert`.

Белый список (утверждён владельцем 17.09): тексты, поля обогащения и шесть
флагов видимости; связи с темами (по slug), тегами (по имени), понятиями и
особенностями; подпункты (по `order`), привязки к источникам (по источнику),
подсказки, олимпиадные привязки (по `event_id`), рисунки (по хешу).
Справочник источников ключуется по id: имена переименовываются, id дома и на
бою совпадают. Не везём: владельца, векторы (свой ввоз), «похожие» (их
пересобирает `cache_similar`), файлы, даты, пользовательские данные, вердикты
ревью, рубрики, пометки копий.

Правила движка:

* задачи, которых на бою нет, не создаются (это работа переноса); задачи боя
  вне пакета не трогаются;
* таблица, которой нет в строке пакета, — «не везли», а не «пусто»;
* подпункт, на который что-то ссылается (ответ ученика, черновик, подсказка),
  не удаляется, а называется в отчёте;
* даты сравниваются до миллисекунд — с той точностью, с какой их записали
  фикстуры переноса;
* снимок хранит старое И новое значение; откат возвращает старое только там,
  где лежит записанное синхронизацией, чужую правку после неё не затирает;
* после записи сбрасываются версии корпуса умного поиска и смыслового индекса.

Те же план, запись, снимок и откат используют команды правок банка дома
(`sources_tidy`, `titles_from_candidates`, `tags_merge_legacy`,
`parts_relabel_letters`, общая основа `_bank_edit.py`).

## Почему так

* Обновление по ключам переносит ровно разницу: на копии боя 17.09 — 7 303
  задачи с изменениями из 14 082 в пакете, запись 33 с, повторная — 0.
* Перезапись задач целиком стёрла бы то, что есть только на бою (попытки
  учеников ссылаются на подпункты), и сменила бы первичные ключи.
* Один движок и для боя, и для правок дома: у всех одинаково проверенные
  сухой прогон, снимок и откат.

## Отвергнуто

* **Перезаливка задач фикстурами с удалением старых** — рвёт внешние ключи
  пользовательских данных и не обратима без полного бэкапа.
* **Ручной SQL на бою** — не проверяется тестами и не откатывается.
* **Расширить `update_prod_problems`** — он читает фикстуры переноса и
  пересобирает подпункты целиком (удалить и создать), связей и справочников не
  знает.

## Цена

* Пакет каталога весит ~200 МБ (картинки в base64): на бой везти сжатым.
* Задачи, скрытые дома, но видимые на бою, пакет каталога не покрывает — их
  везут отдельным пакетом по списку id (`--ids-file`).

## Следствия

* Штатный путь любой правки банка на бой: правка дома → `bank_sync_export` →
  пакет на сервер → `bank_sync_apply` (сухой, отчёт, `--apply`) → снимок наружу.
  Команды — `docs/SERVER.md`, раздел «Синхронизация банка на бою».
* После синхронизации векторы ввозятся без `--ignore-text-check` (репетиция
  17.09: «пропущено, текст изменился» — 0 из 13 931).
