# Э6 — глобальное сложение заводов

Решение29.10 реализовано и проверено локально в отдельной ветке Codex Astra. Приёмка Макара впереди.

Предыдущая таблица строилась по уровням MC и интерполировала раздел выпуска.
Для10Q иQ² приQ12 она давала6.9825/5.0175 и интеграл96.75 вместо95.
Она также предполагала растущие MC и искусственно ограничивала завод100единицами.

Новый45-plants последовательно складывает затраты. Для каждой пары квадратичных
кусков сравнивает граничные разделы и внутренний стационарный раздел, если
он может быть минимумом; затем выбирает нижнюю огибающую всех кандидатов.
Куски несут не толькоTC, но и распределение выпуска. Поэтому результат точен
для линейных/квадратичных TC, в том числе вогнутых, мощностейK и закрытия
завода с квазипостоянными затратами. На изломе/скачке единственнаяMC не объявляется.
ИнтегралMC не выдаётся заTC−FC там, где есть скачки затрат: они показаны отдельно.

Для произвольных формул используется динамический перебор сеточных разделов
с последующим уточнением по парам; результат явно помечается приближённым.
Общую явную формулу для произвольных нелинейных затрат алгоритм не обещает.
Это тот же принцип честной численной ветки, который уже есть у сложения КПВ.

Первым двум формулам сохранены pl1/pl2. Дополнительные строки и параметры
хранятся в plCount/plMore/plCaps/plKinds, пустаяK означает отсутствие предела.
История, ссылка и пересборка строк используют общий слой состояния. Формула
итога показана общим setFinalFunctions: разворот и копирование. Куски графика
экспортируются точными формулами; осьTC илиMC соответствует выбранному виду.

Независимые доказательства: 4.18г7/5/95/10, угловой0/12/72/6, 4.19аQ²/2.
Для трёх заводов Q²+5,K4; .5Q²+12,квазипостоянные; 3Q,K6 приQ12 раздел2/4/6,
TC47; приQ8 —2/0/6,TC27. Полный Python-перебор40наборов2–5заводов с шагом.02
не использует производные и огибающую. Есть нелинейныйQ³+Q³ и большойFC1e14.

Старые снимки не переписаны. Прежние числовые ожидания сохранены; случаи,
которые подразумевали мощность100, теперь задают её явно. ОсьP заменена на
принятуюTC, точная суммарная кривая теперь тоже экспортируется формулой.
Канонические входы сверяются со снимком, новая вычисляемая таблица — с
аналитическим решением20/10,MC40,TC600 приQ30. ОсьTC разрешена только уplants.

Проверка: собственные44/44, края88/88, вид96/96 в Chromium/WebKit;
контроль734/734, паритет1953/1953, математика249/249, оси156/156,
TeX44старта/42превью. История/ссылка и44старта без новых расхождений.
Три намеренных дефекта обнаружены, исходные байты восстановлены по SHA256.
