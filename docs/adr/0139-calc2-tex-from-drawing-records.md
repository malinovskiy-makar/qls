# ADR 0139 — «Графики»: файл .tex из записи, оставленной при рисовании

* **Дата:** 2026-10-08
* **Статус:** принято, ветка `feat/calc2-redesign`; **заменяет ADR 0030**
* **Автор:** Claude Code
* **Решения владельца в Notion:** «Способ выгрузки .tex: запись при рисовании» (07.10) и уточнение (08.10,
  ответ «А»): запись обязательна для кривых и закрашенных областей; точки, линии, подписи, деления и легенду
  выгрузка читает с холста на белом листе постоянного размера. Файл повторяет экран целиком.
* **Задание и спецификация:** `claude/mockups/calc2_tex_20261007/` (`PROMPT.md`, `SPEC.md`, `RECON.md`);
  журнал — `claude/PROGRESS_CALC2_TEX_20261007.md`.

## Контекст

До этой работы в коде жили два сборщика. `buildTexLegacy` обходил нарисованный SVG и переводил пиксели в
списки координат: 9 044 пары на 44 стартах, срезанные углы областей, слитые панели, 40 стартовых файлов из 44
собирались. `buildTexFromState` (ADR 0030) строил файл из `STATE.curves`, но у 22 сцен из 44 кривые живут не
там, и файл выходил пустым — поэтому он был выключен и включался `?texState=1`.

## Решение

1. **Сцена оставляет запись при рисовании.** Словарь — `30-curves.js`: `markExpr` (формула и буква; `axis: 'y'`
   — запись «по вертикали» x = g(y), как её вводит человек; свой отрезок), `markArea` (нижняя и верхняя граница
   на отрезке, прижатие к нулю), `markCurve` (путь по кривой списка), `markNumeric` (узлы, посчитанные моделью,
   с названной причиной), `markPoly` (ломаная по вершинам). Запись ставится атрибутами на ГОТОВЫЙ узел: рисунок
   не меняется (отпечаток атрибута `d` по 177 состояниям — тот же, что на нетронутом коде).
2. **Выгрузка — три шага** (`72-export-tex.js`): бумажный прогон (белый лист постоянного размера, светлая тема,
   без переходов на `#chart`, свой замерщик подписей, история молчит) → опись по панелям реестра → сборка
   чистой функцией. Поэтому файл побайтно один при любом окне браузера и любой теме.
3. **Записи не верят на слово.** Каждая сверяется с нарисованным путём (узлы на формуле с допуском 2·10⁻⁵
   размаха оси, между узлами не дальше 2·10⁻³, у области ещё площадь до 5·10⁻³). Не сошлась — путь уходит
   точной ломаной своих узлов, как на экране, и это дефект, который считает прибор. Запасной путь остаётся
   навсегда.
4. **Неверно нарисовано на экране, а запись верна** — состояние идёт в именной список
   `calc2/tests/tex/scene_defects.json` с причиной; экран этой работой не чинится.
5. **Кириллица — вне математики** (`$33{,}33$\textsubscript{м}`): сервер собирает PDF без домашней папки, и
   шрифта T2A в 5 pt для `\text{м}` в индексе там нет (замер: PDF «Двусторонней монополии» падал с 500).
6. **«Сначала сам»**: `selfMaskText` меняет вместе с текстом и `data-raw`, из которого выгрузка берёт подпись.
7. **Новая сцена обязана пометить свои пути.** Статическая перепись `calc2/tests/tex/sites.mjs` +
   `sites.json`: у каждого места `append('path')` есть судьба — запись, помощник с выражением проверки или
   «в файл не идёт» с причиной; место без судьбы краснит прибор.
8. **Проверка в CI** — `calc2/tests/test_calc2_tex.py` (`tex/ci_quick.mjs`): 44 старта, проверка текста без
   TeX, дефектов записи ноль, два окна у пяти моделей, сборка `pdflatex` там, где он есть. Полный набор (1 025
   состояний, листы, `pgfmath`) — ручные приборы `calc2/tests/tex/`.

## Что отвергнуто

* **Строить файл от состояния модели** (ADR 0030). Половина сцен рисует мимо `STATE.curves`; объявлять кривые
  второй раз значило бы держать две правды о картинке. Запись ставится в том же месте, где рисуется путь.
* **Восстанавливать формулы по пикселям** (подгонкой, распознаванием прямых). Подгонка врёт на изломах и
  дробях; запись у сцены точная.
* **Выдумывать формулу там, где её честно нет**: линия уровня, численное обращение, сумма по Минковскому без
  закрытой формы, кривая Лаффера при нелинейных D и S. Такие кривые уходят узлами расчёта с причиной.
* **Чинить сцены по дороге** (`money@nl`, пути с `NaN`): экран эта работа не меняет — дефекты названы в
  именном списке и в карточках Notion.
* **`\text{кириллица}` в индексах** (первая редакция `SPEC.md`, раздел 7): в окружении сервера не собирается.

## Последствия

* Удалены `buildTexLegacy`, `buildTexFromState`, `texWantState` и переключатель `?texState=1` с помощниками,
  нужными только им; проверки прежнего вида файла перенацелены (журнал, раздел «Перенацеленные проверки»).
* ADR 0030 помечен заменённым; ADR 0136 и 0137 упоминают переключатель как было и не правятся.
* Правило для `calc2/CLAUDE.md`: новая сцена помечает свои пути; формулу без честной записи — `markNumeric`.
