# ADR 0178 — Пункты задач пакета олимпиад чинятся механически; задание чужого тура — признак позиции, а не удаление

* **Дата:** 2026-10-30
* **Статус:** принято дневной сессией 30.10; подтверждение владельцем — по журналу дня.
* **Ветка:** `feat/olympiads-screens-20261031`; код `olympiads/bank_fix.py`,
  `olympiads/parts_fix.py`, команды `dedupe_problem_parts`,
  `split_statement_parts`, `strip_part_points`, `extract_marked_answers`,
  `exclude_foreign_tour_items`, миграция `olympiads/0016_variant_item_excluded`,
  тесты `olympiads/tests/test_day_D.py`. Продолжение ADR 0172 (чистка S6).

## Решение

1. **Четыре починки пунктов (Д1–Д4) — по образцу чистки S6:** сухой прогон по
   умолчанию, отчёт в `reports/`, снимок базы перед `--apply`, одна транзакция,
   повторный прогон — 0. Правится только задача S4 (`bank_fix.editable_ids`:
   id ≥ 53709, черновик, скрыта до ревью, ревью пустое); отпечаток прежнего
   банка сверяется после записи, расхождение откатывает транзакцию.
   Сомнительное текст не меняет, а ставит «под вопросом» на позициях.
2. **Д1 — копия пункта:** та же метка, текст без пробелов, баллы, ответ и
   решение. Остаётся первый по порядку; все внешние ключи на `ProblemPart`
   переносятся на оставленный (иначе каскад унёс бы рисунки и черновики).
3. **Д2 — условие = общая часть до первого пункта,** только если хвост
   условия — ровно пункты по порядку (без учёта пробелов, разметки меток и
   «(N балла)» при баллах N). Каждое укорочение сверяется второй, независимой
   проверкой; знак, которого нет в пункте, — несовпадение (ни одного символа
   не теряем). Режется до неподвижной точки (пункты бывают в условии дважды).
4. **Д3 — «(N балла)» в начале пункта** убирается при `points = N`; пусто —
   ставится N; иначе «под вопросом». Д1–Д3 — одна цепочка до неподвижной точки.
5. **Д4 — ключ из «(отмечено)» в формате теста банка:** тип из
   `problems/problem_types.py`, варианты — пункты с неповторяющимися метками,
   `Problem.answer` («2, 4») и `ProblemPart.answer` («верно»/«неверно»).
   Только в пустые поля; непустой ответ не перезаписывается никогда.
   Варианты только текстом в условии — «под вопросом», пункты не сочиняем.
6. **Д5 — `OlympiadVariantItem.excluded` + `excluded_reason`.** Позиция не
   удаляется (на ней могут висеть попытки); навигатор (`_annotated`,
   `problems_count`, главная), тренировка (`package_items`, `variant_items`) её
   не видят. Правило карточки Notion: задание в обоих туровых комплектах
   (номер + начало условия ≥ 0,6) остаётся там, где у позиции есть балл.
   Второй признак, когда балл в обоих или ни в одном: позиция, взятая только из
   файла, общего для двух комплектов (общие «Решения N класс.pdf»), — чужая.
   Иначе «под вопросом».

## Почему

Владелец увидел на экране пункты дважды, «(4 балла)» в тексте, ключ теста и
«8 заданий · из 88». Всё это — грязь склейки источников; чинится механически
и обратимо. Удалять позицию нельзя — на неё ссылаются попытки; пятый признак
скрытия задачи заводить нельзя (CLAUDE.md) — поэтому признак у позиции.

## Отвергнуто

- Не трогать задачу целиком при любом конфликте меток (Д1) — 251 задача
  осталась бы с повторами при полностью совпадающих копиях.
- Терять «;» в конце вариантов (Д2) — +514 условий, но символы теряются.
- Переводить строки условия в пункты (Д4) — сочинение данных, а не починка.
- Только правило балла (Д5) — у 24 пар чужая позиция несёт мелкий балл
  одного пункта (2 из 12), и туры остались бы по 5–6 заданий.
- Скрыть копии задач из банка (дополнение карточки) — задачи и так скрыты до
  ревью, а «Заданий у нас» их уже не считает.
