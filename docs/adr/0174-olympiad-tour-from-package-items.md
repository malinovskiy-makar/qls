# ADR 0174 — Тур олимпиады решается по позициям пакета; развёрнутое решение без ответа не ноль

* **Дата:** 2026-10-30
* **Статус:** принято ночной сессией; подтверждение владельцем — утром 31.10.
* **Ветка:** `feat/olympiads-screens-20261031`; код `olympiads/training_engine.py`,
  `olympiads/uploads.py`, `olympiads/views_training.py`, модель `TrainingUpload`
  (миграция `olympiads/0013_training_upload`), тесты `olympiads/tests/test_night_E5.py`.
* **Продолжает:** [ADR 0066](0066-olympiad-training-throwaway-submission.md) (одноразовое
  решение), [ADR 0170](0170-olympiad-package-tasks-into-bank.md), [ADR 0173](0173-olympiads-navigator-single-place-for-numbers.md).

## Контекст

Движок тренировки искал задачи комплекта через `problems.OlympiadRef.event_id`.
У всех 624 основных комплектов пакета совпадений там ноль — задачи пакета
привязаны позициями `OlympiadVariantItem`. Время тура движок брал из
`OlympiadVariant.duration_minutes`, а у комплектов пакета оно пустое: время
задаёт этап (ВсОШ, заключительный — 210 минут). Экран по макету даёт
открытому заданию только «Решение» (фото или текст), без полей краткого
ответа, а проверка ставила ноль «ответа не было».

## Решение

1. Задачи тура — из позиций пакета (`package_items`, без `absent_in_last_import`),
   иначе по-старому через `OlympiadRef`. Балл позиции пакета переносится в
   `AssignmentItem.points` служебного задания.
2. Время тура — `navigator.tour_minutes` (своё у комплекта, иначе этапа) и на
   входе, и на таймере. Считает сервер, клиентские поля игнорируются.
3. Развёрнутое решение (текст «Моё решение» или листы) без краткого ответа —
   «ждёт проверки», не ноль. Его оценит ИИ по критериям (Э7) или ученик сам
   по разбору.
4. Режим «Без времени»: «Сдать задание» проверяет одну задачу
   (`grade_item`); сданное больше не правится (автосохранение и загрузка
   отвечают 409). Сдача тура не перепроверяет уже сданные задачи.
5. Листы решения — `TrainingUpload` у попытки. Проверка файла — та же, что у
   вложений «Стола» (`catalog.attachments.validate_upload`), EXIF снимается
   пересохранением, не больше 10 листов на задание. Файл отдаёт только
   `training_sheet` и только хозяину попытки (пятая файловая вьюха к четырём
   из ADR 0118). Уборка гостей удаляет и файлы.

## Отвергнуто

- **Записать задачи пакета в `OlympiadRef`.** Раздел олимпиад в `problems` не
  пишет (ADR 0063), а `unique(problem, event_id)` не вмещает ключи пакета.
- **Показать поля краткого ответа у каждого открытого задания.** Их нет на
  макете, а без эталона их всё равно некому проверить; поля оставлены только
  у заданий с эталоном ответа (`has_answer`).
- **Своя проверка файла для тура.** Две копии правил разойдутся.
