# ADR 0103 — Аналитика беты: своя таблица событий в Django, без внешних сервисов

* **Дата:** 2026-09-15
* **Статус:** действует

## Контекст

Закрытая бета для друзей. Нужно понять, как участники ходят по сайту: клики,
экраны, время на экране, пути. Своих событий у сайта не было — только журналы
сервера, по которым путь человека не восстановить.

## Решение

Решение владельца 15.09.2026: события пишутся в свою таблицу `Event`
(`problems/models_platform.py`, миграция `problems/0067_event`).

* **Скрипт `static/track.js`** на девяти шаблонах (семь базовых, вход,
  регистрация): `page_view`, `page_leave` с активным временем на экране, клики
  по кнопкам и ссылкам в фазе перехвата, поиск (`q_len` — длина, без текста
  запроса), явные события страниц (`game_start`, `game_answer`, `duel_create`,
  `duel_start`, `practice_start`, `chat_send`, `test_answer` и другие). Очередь
  сбрасывается раз в 5 с, на уходе — `sendBeacon`.
* **`POST /api/track/`** без CSRF-токена, но с проверкой `Origin` (или `Referer`)
  на свой хост; cookie посетителя `weco_vid` обязательна; не больше 50 событий
  за раз и 600 за 10 минут на посетителя; `props` режутся до 2 КБ; `user` —
  только из сессии; путь пишется без строки запроса.
* **Выгрузка** `analytics_export --since [--until] --out` в CSV (ячейки,
  похожие на формулы, нейтрализуются); просмотр — админка «События», только
  чтение.

## Почему так

**Сырые события и данные у нас.** Для разбора после беты нужны события целиком,
а не готовые отчёты чужого сервиса. Отклонены Яндекс.Метрика и PostHog: внешняя
зависимость, и данные участников оказываются не у нас.

**`csrf_exempt` — следствие `sendBeacon`, а не ослабление.** `sendBeacon` не
ставит заголовков, а без него событие ухода со страницы теряется. Подделку с
чужого сайта отсекает проверка `Origin`, поток мусора — лимиты пачки и окна
(`docs/SECURITY.md`).

**Из профиля ничего сверх `user` и cookie посетителя.** Согласие участников беты
есть; текст поиска не пишется — только длина.

## Цена

* **Срока хранения нет.** Таблица растёт, чистка не сделана: при открытии сайта
  шире беты нужны решение о сроке и согласие.
* **Лимит окна считается по cookie посетителя:** очистив cookie, его можно
  обойти; остаются проверка `Origin` и лимит пачки.
* **Качество поисковых запросов по аналитике не разобрать** — в событиях только
  длина запроса.
