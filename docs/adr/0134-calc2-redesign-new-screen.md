# ADR 0134 — «Графики»: новый экран по утверждённому макету, ничего не теряя

* **Дата:** 2026-10-06
* **Статус:** принято владельцем (макет 04.10, задание `claude/mockups/calc2_redesign_20261004/PROMPT.md`), ветка `feat/calc2-redesign`, в `main` не влито

## Контекст

Владелец утвердил макет вкладки «Графики» (`/calc2/`): шапка модели, три колонки
«Условие» · холст · «Ответ», экран выбора одним экраном, «Сначала сам», выгрузка на
белом листе. Условие владельца — «функции не теряются»: всё, что калькулятор умеет
сейчас, остаётся, а числа движка не меняются.

## Решение

1. **Разметка та же, раскладка новая.** Узлы сцен и их id переехали в колонки
   как есть; вид меняют стили и тонкие слои (`92-ui-kit.js`, `93-shell.js`,
   `94-answer.js`, `95-picker-screen.js`, `96-self.js`). Движок (`10-math-core`,
   файлы сцен) не правился.
2. **Закрытый список замен (COVERAGE, раздел 0, п. 2).** Орган старого экрана
   либо на месте, либо заменён по пунктам (а)–(к), либо убран только по (л), (м):
   «Построить» → живое применение; переключатели подрежимов → переключатель
   модели; сворачивание колонок → «Развернуть график»; двухуровневое окно выбора
   → один экран; сворачивание карточек → всегда раскрыты; общая галочка излишков
   → CS и PS; галочка видимости → глаз; перенос регуляторов → «Условие»;
   «Вернуть исходный вид» → «Сбросить», гаечный ключ → «Вид графика»; три кнопки
   экспорта → формат и одна кнопка. Судьба каждого органа — в
   `calc2/tests/redesign/PARITY.md`.
3. **Ширина ничего не отнимает.** 1240–1399 — колонки 304 и 316; 760–1239 —
   «Ответ» выезжает, главные числа строкой над холстом; < 760 — вкладки
   «Условие» / «Ответ» / «Разбор», цели 44, окна листами. Колонки прячутся
   классом, не `hidden` (поля MathLive иначе считаются мёртвыми).
4. **Канон и макет** — DESIGN.md 5.1, раздел «Редизайн 10.2026».

## Отвергнуто

- Переписать экран с нуля новой разметкой: 3250 органов старого экрана пришлось
  бы переносить по одному, а 500+ проверок и приборов, привязанных к id, —
  переписывать. Паритет было бы нечем доказать.
- Оставить двухуровневое окно выбора рядом с новым: два входа в одну модель.

## Последствия

Перенацеленные проверки раскладки (было → стало → почему) — в журнале сессии
`claude/PROGRESS_CALC2_REDESIGN_20261004.md`. Сознательные отличия от картинок
макета — COVERAGE, раздел 7.
