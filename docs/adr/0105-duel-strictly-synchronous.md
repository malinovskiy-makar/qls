# ADR 0105 — Дуэль строго синхронна: лобби, общий момент старта от сервера, только с аккаунтом

* **Дата:** 2026-09-15
* **Статус:** действует
* **Уточняет:** [ADR 0062](0062-game-realtime-duel-implemented.md) (дуэль в реальном
  времени): путь «сыграть набор дуэли позже, одному» закрыт.

## Контекст

Дуэль была асинхронной. Автор собирал набор в окне «Бросить вызов», видел ссылку
и мог играть сразу; соперник приходил по ссылке позже. Когда оба оказывались на
месте, сокет присылал `start` с `in: 3`, и каждый клиент отсчитывал три секунды
своим `setTimeout`, а автор в этот момент сидел в модальном окне и только потом
переходил на страницу набора. Одновременно не стартовал никто.

Гость получал на `fetch` к `duel_new` (под `@login_required`) страницу входа
вместо JSON и читал «Не удалось создать вызов».

## Решение

Решение владельца 15.09.2026: пока соперник не зашёл, играть нельзя; оба
стартуют по одному отсчёту от пяти со звуком; гость видит окно регистрации.

* **Только с аккаунтом.** Окну вызова `duel_new` отвечает JSON 403
  `{'ok': False, 'error': 'login'}`, клиент показывает окно «Дуэль только с
  аккаунтом» со ссылками на регистрацию и вход. Адресная строка по-прежнему ведёт
  на вход.
* **Лобби вместо кнопки «Играть».** Окно вызова сразу уводит автора на страницу
  набора; кнопки «Играть» у дуэли нет ни у автора, ни у соперника. В лобби —
  код комнаты, «Скопировать ссылку», строка «кто на месте» и «Отменить».
  Соперник попадает туда через «Принять вызов» на странице дуэли.
* **Момент старта назначает сервер.** Когда в комнате двое разных пользователей,
  консьюмер записывает `started_at = сейчас + 5 с` в словарь комнаты ОДИН раз
  (`game/state.py::duel_start_at`) и шлёт `start {at, now, in}`; повторный вход и
  `hello` получают тот же момент. Клиент считает разницу своих часов с `now`,
  ведёт отсчёт к `at` и сам запускает раунд; цифры и «Поехали!» звучат
  (`rushSound.countdown`).
* **Табло — одна строка на сторону** (имя, счёт, верных, время). Точность и
  комбо ушли в таблицу итога на странице дуэли; в ней только поля `GameResult`.

## Почему так

**Момент, а не число секунд.** `in: 3` каждый досчитывал своими часами: фоновая
вкладка и медленный телефон расходились на секунды, перезагрузка начинала отсчёт
заново. Момент от сервера один на двоих и переживает перезагрузку лобби.

**Момент лежит в комнате, а не только в сообщении.** Без записи второй сокет того
же игрока или переподключение назначили бы новый старт, и игроки разошлись бы на
длину отсчёта.

**Отклонено «оставить асинхронный путь рядом».** Пока у дуэли есть «Играть»,
автор уходит играть один, и живого табло не видит никто — это уже случилось до
08.09 (ADR 0062, раздел «Дуэли» в `docs/GAME.md`).

**Отклонено «запускать раунд по сокету».** Вопросы и ответы остаются обычным
HTTP: обрыв связи посреди раунда не ломает раунд, пропадает только табло.

## Цена

1. **Без WebSocket дуэль не начнётся.** Кнопки «Играть» нет; лобби честно пишет
   «Нет связи с комнатой, пробуем снова…». Контейнер `ws` для дуэлей обязателен.
2. **Запрет играть без соперника стоит в интерфейсе, а не на сервере.**
   `api_session_start_set` проверяет только вход и попытку: раунд дуэли можно
   начать запросом руками. Серверный замок не сделан.
3. **Звук отсчёта у пришедшего по ссылке может молчать:** браузер не включает звук
   страницы без касания.
4. **Опоздавший больше чем на длительность режима** раунд этой дуэли уже не
   начнёт: лобби говорит «Раунд этой дуэли уже прошёл».
