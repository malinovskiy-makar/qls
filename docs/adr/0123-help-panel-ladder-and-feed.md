# ADR 0123 – Панель помощи – лестница и одна лента по времени

* **Дата:** 2026-09-19
* **Статус:** действует

## Контекст

На старой странице задачи помощь была разбросана: подсказки кнопкой в центре, решение отдельной
карточкой, чат справа, попытка решения полем под условием. README §4 (решение владельца 17.09):
панель справа – «берите столько помощи, сколько нужно, и не больше».

## Решение

* **Пустое состояние – лестница** ступеней, каждая только при данных (правило нуля): подсказка
  N из M, спросить ИИ (при ключе чата), ответ к пункту (при ответах подпунктов), полное решение
  (у теста – «Показать ответ»). В банке ничего – строка «остаётся ИИ».
* **После первого действия – одна лента по времени:** подсказки, ответы ИИ, попытки, решение.
  Лента переживает перезагрузку: открытые подсказки и решение сервер рисует из
  `ProblemProgress` (ADR 0119), история чата догружается.
* **Попытка – режим «Проверь решение» поля помощи**, файлы уходят при отправке. Полное решение –
  через подтверждение текстом README.
* Подсказка из API и при перезагрузке – одна форма (`views._hint_view`).
* На телефоне помощь – шторка снизу от 120 px (README §8).

## Отвергнуто

* **Вкладки «Подсказки / ИИ / Решение»** – прячут, что уже открыто, и не показывают порядок.
* **Точное время открытия подсказок** – новое поле в `ProblemProgress` ради порядка ленты после
  перезагрузки; порядок «подсказки → попытка → решение → чат» приближённый, миграцию не заводили.
