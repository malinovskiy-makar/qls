# ADR 0121 – Каталог, задача и карта – один экран и один шаблон

* **Дата:** 2026-09-19
* **Статус:** действует; заменяет подход ADR 0120 («Стол» первым шагом поверх старой страницы)

## Контекст

Решения владельца 17.09: каталог и страница задачи – один экран «Стол» (вход с поиском в центре,
лента · задача · помощь, карта тем на том же экране). ADR 0120 ночью 18.09 сделал первый шаг
поверх старой страницы задачи: три адреса рисовали три разных шаблона (`problem_list.html`,
`problem_detail.html`, `topic_map.html`), смена задачи перезагружала страницу. Спецификация –
`claude/mockups/catalog_stol_20260917/README.md` §1–§9.

## Решение

* **Один шаблон** `catalog/stol.html` рисует три адреса, вид задаёт `view`:
  `/catalog/` – `entry`, `/catalog/problem/<id>/` – `stol`, `/catalog/map/` – `map` (вход под
  картой). Каждый адрес сервер отдаёт целиком: прямая ссылка работает без скрипта.
* **Партиалы** `catalog/stol/`: `_stol_entry`, `_stol_desk`, `_stol_rail`, `_stol_center`,
  `_stol_help`, `_stol_map`, `_stol_basket` (репетитору), строка ленты `_rail_row` – одна на
  широкую и узкую ленту. Стили – один файл `catalog/css/stol.css`, цвета – токены.
* **Задача без перезагрузки:** `?pane=1` отдаёт JSON `{center_html, help_html, similar_html,
  meta}` теми же партиалами; `stol.js` подменяет центр и помощь и ведёт адрес `pushState`,
  «назад» – `popstate`. Всё внутри задачи – `stol_task.js` с идемпотентным `init(root)`.
* **Скрипты:** `stol.js` (вид, адреса, панели, лента, вход), `stol_task.js` (задача и помощь),
  `stol_map.js` (карта, грузится при наведении на «Карта тем»), `stol_basket.js` (только
  репетитору). Пространство имён `weco.stol`.
* Старые шаблоны и скрипты удалены (стоп-лист S7.1, «да» владельца 19.09.2026).

## Почему так

Один экран в трёх адресах – один набор партиалов: ответ `?pane=1` и прямая ссылка рисуют задачу
одним кодом, расхождения «страница и подмена показывают разное» не бывает. Прямая ссылка без
скрипта – требование сайта (ученик по ссылке из домашки).

## Отвергнуто

* **SPA с клиентским рендером** – второй способ рисовать задачу (TeX, санитайзер, картинки
  живут на сервере в `_math_text.html`), и прямая ссылка без скрипта перестаёт работать.
* **Оставить три шаблона и связать ссылками** – смена задачи перезагружает страницу, лента,
  фильтры и помощь теряются; это ровно то, от чего владелец уходил.
