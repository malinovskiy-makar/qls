# ADR 0143 — «Графики», «Математика»: ответ на отрезке ответа, окно по функции, «Сначала сам» списком и точками

* **Дата:** 2026-10-09
* **Статус:** принято, ветка `feat/calc2-redesign`; уточняет ADR 0020 («область поиска — свойство модели») для
  «Математики» и «Построения графиков», ADR 0087 (окно растёт, но не сжимается) — для режима `graph`
* **Автор:** Claude Code
* **Решение владельца в Notion:** «Графики, математика и «Сначала сам»: ответ не зависит от масштаба, отрезок поиска
  задаёт человек; несколько ответов одним полем через «;», экстремум точкой (x; y), координаты ключевых точек
  «(?; ?)» до верного ответа» (09.10). Задача — «… сессия 2». Журнал — `claude/PROGRESS_CALC2_MATH_20261009.md`.

## Контекст

В «Построении графиков» нули, вершины и пересечения искались в ВИДИМОМ окне (`mx.domain()`), в остальных моделях
«Математики» — в окне `STATE.mathXmin…mathXmax`. Приближение к вершине x² − 4 меняло «−2; 2» на «в окне не
пересекает», колонка «Ответ» дёргалась от колеса. «Построение графиков» открывалось с экономическим окном
(запас 100 от нуля вправо-вверх) — парабола у левого края. Локальных максимума и минимума среди главных величин не
было. «Сначала сам» прятал только ячейку с одним числом («−2; 2» было видно сразу), а подпись ключевой точки,
собранная при наведении после прохода режима, показывала настоящие координаты.

## Решение

1. **Отрезок ответа — вход модели.** `STATE.ansA / ansB / ansHand` (`00-config.js`): входит в историю,
   автосохранение и «Поделиться», НЕ входит в ключи вида; масштаб, сдвиг и «Вписать» его не трогают. Задаётся
   строкой «Ответ ищем на отрезке x от [ ] до [ ]» под полями функций (`#ans-seg-row`, один узел переезжает между
   сюжетами); пустое поле или «от ≥ до» — назад к формуле с подсказкой; применяется при уходе из строки или Enter.
2. **По умолчанию — по формуле** (`autoAnswerSeg`): ключевые точки на [−100; 100] (нули, локальные экстремумы,
   f(0), пересечения кривых); ≤ 12 — [min; max] с запасом max(1; 25 % размаха), не уже [−5; 5], края 1-2-5 наружу;
   > 12 (периодические) — [−10; 10]. Пока человек не правил, отрезок идёт за формулой; поправил — его, рядом
   «Вернуть по формуле».
3. **Ответ на отрезке.** Нули, экстремумы, пересечения, смены ветви min/max, наибольшее и наименьшее — на отрезке
   (`ansAnalyse`, кэш по подписи функции и отрезку); шаг производной — доля отрезка. Экстремум — смена знака f′
   внутри отрезка (концы не считаются, излом считается, плато нет); полюса и совпадения кривых отсеиваются.
   «в окне не пересекает» → «нет». Числа — тремя знаками («−1,732»). У «С ограничением» строки отрезка нет: две
   переменные, область — размах самого ограничения (`consFit`), без окна.
4. **Окно по функции** (`graphFitWindow`): «Построение графиков» на старте, по «Вписать» и «Вернуть исходный вид» —
   по x отрезок ответа, по y ключевые точки, ноль и 5–95 % значений, запас 10 % (у ключевой точки ≥ 8 %). Рост окна
   в `graph` — до окна функции, без сжатия, окно человека не трогается. Пресеты «Математики» остались; «Вписать»
   раздвигает их до ключевых точек ответа.
5. **Локальные максимум и минимум — главные величины** во всех моделях вида y = f(x): точка «(x; y)», несколько через
   «; », нет — «нет». `HERO` «Математики» — строки табло с пометкой `.ans-main`.
6. **«Сначала сам»:** ответ — число, список через «;», точка, список точек или «нет»; порядок не важен, число значений
   обязано совпасть, допуск прежний; неразобранное — подсказка формата без вердикта. Без поля открыта только ячейка,
   значение которой не ответ. Ключевая точка при наведении — «(?; ?)», пока её ненулевые координаты не совпали с
   открытыми (верными или «Показать») числами своей оси или с открытой точкой ответа; закрепка до того недоступна.
   Вердикт снимается, только когда меняется ответ его ячейки.

## Отвергнуто

* Широкий автоматический отрезок без строки в «Условии» — невидимо, где ищем; у sin x бесконечно много корней.
* Поле на каждый корень — число полей подсказывает число корней.
* Экстремум только абсциссой или двумя полями — в задачах его пишут точкой.
* Подогнать отрезок под окно пресета (например, [−3; 3] у «Оптимума») — второе правило рядом с «по формуле».
  Следствие принято: у x³ − 3x «Наибольшее на отрезке» теперь (5; 110) на отрезке [−5; 5].
* Снимать все вердикты любой правкой модели — закрепка открытой точки стирала бы только что заслуженное «✓».
