# ADR 0173 — Навигатор раздела «Олимпиады»: одно место, где считаются числа экранов

* **Дата:** 2026-10-30
* **Статус:** принято ночной сессией; подтверждение владельцем — утром 31.10.
* **Ветка:** `feat/olympiads-screens-20261031`; код `olympiads/navigator.py`, модель
  `OlympiadFollow` (миграция `olympiads/0012_olympiad_follow`), тесты
  `olympiads/tests/test_night_E1.py`.
* **Продолжает:** [ADR 0171](0171-olympiad-kit-duplicates-marked-not-deleted.md),
  [ADR 0172](0172-olympiad-package-tasks-cleaning.md).

## Контекст

Макеты раздела (15 досок, утверждены 30.10) показывают одни и те же числа на
трёх экранах: «материалов на платформе» на главной, «заданий у нас» и «сезонов»
на странице олимпиады, «4 задания · максимум 48» в панели тура. В Notion уже
есть карточка о том, что числа «у нас» и числа тура спорят на разных экранах:
их считали по месту.

## Решение

1. Все числа раздела считает `olympiads/navigator.py`. Вьюхи и шаблоны получают
   готовые словари и ничего не складывают сами.
2. «Основной комплект» определён один раз — `base_variants()`: опубликован, не
   повтор, не демонстрационный, есть в последнем пакете.
3. Максимум тура — сумма баллов позиций, только если балл есть у каждой; иначе
   максимум этапа. Неполная сумма — не максимум.
4. Сетка строится по `OlympiadVariantGrade`: комплект «10-11» — одна широкая
   клетка; при пересечении классов — клетка на колонку, общий вариант в каждой.
5. «Мои олимпиады» — модель `OlympiadFollow` в `olympiads` (исключение ADR 0063
   уже покрывает модели раздела); пишет только вошедший.

## Отвергнуто

- **Счётчики комплекта из пакета (`tasks_total`) вместо позиций.** Они не
  знают про повторы и скрытые позиции, а «у нас» — это то, что реально лежит
  в банке.
- **Сумма баллов позиций всегда.** У тура 2025/26 ВсОШ лежат позиции чужого
  тура без балла; частичная сумма выдала бы случайное число за максимум.
- **Ломоносов в основной список правкой `display_group`.** Ночь базу не правит;
  раздел главной выбирается списком в навигаторе.

## Следствия

- Новый экран раздела берёт числа отсюда; второй подсчёт — ошибка ревью.
- После чистки данных (задания чужого тура) числа на экранах пересчитаются сами.
