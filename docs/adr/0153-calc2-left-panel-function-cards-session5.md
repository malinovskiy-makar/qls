# ADR 0153 — Левая панель: карточки функций для КПВ, торговли, фирмы, монополии и труда

* **Дата:** 2026-10-14
* **Статус:** принято, ветка `feat/calc2-redesign` (на бой уходит со слиянием редизайна)
* **Автор:** Claude Code
* **Решение владельца:** Notion «Графики: левая панель одна во всех моделях и только про условие задачи; всё, что
  меняет одну картинку, — в «Вид»» (…8142…, 13.10); шрифт A (…81d6…). Пакет `claude/mockups/calc2_panels_20261014/`
  (README 1, 3, 4, 8; макеты `05_left_Ppfsum`, `05_left_Costs`, `05_left_Mono`, `06_left_taxes`). Журнал —
  `claude/PROGRESS_CALC2_PANELS_5_20261014.md`, этапы Б–Г.

## Контекст

До сессии у левой панели было две системы: карточки функций (список кривых `STATE.curves`, 16 моделей) и «голые»
поля сцен с подписью над полем (26 моделей): КПВ, торговля, фирма, дискриминация, составной спрос. Ползунки сцен —
строкой «Цена P = 15» набором KaTeX, пары подписей с тумблером, «Сколько кривых» полем числа.

## Решение

1. **Карточка функции для голого поля — тот же узел.** `wrapFieldInCard` (92-ui-kit.js) превращает существующий
   `.field` в карточку (`fc-card sc-card`): верхний ряд (точка цвета, обозначение KaTeX 19 px, имя 14 / 500 с
   переносом, «⋯»), ниже прежний ряд поля `.f-row` в строке с приставкой («Q =», «TC =»). Поле, его `id`,
   обработчики, оснастка MathLive и подгонка кегля, живая запись, видимость от сцен — прежние; новых `id` нет.
   Подпись над полем: её текст пишет сцена — узел остаётся спрятанным (`sc-old-label`), иначе убирается.
2. **Только то, что что-то делает.** Глаз — только у кривой с видимостью (у полей сцен её нет: видимость кривых,
   которые модель строит сама, — в «Виде»); «⋯» — только если в меню есть пункты (подпись на графике, «Стандартные
   издержки»); точка-кнопка — только при своём выборе цвета (ppfsum), иначе простой значок цвета роли.
3. **Строки параметров (README 4).** Ползунок — слова слева, «обозначение = значение» справа (KaTeX 17 px), дорожка
   во всю ширину, пределы под ней (`sc-prow`, обозначение — `SC_PROWS` через `shortRegulatorName`); число — подпись
   слева, поле справа (`sc-nrow`); раздел «Параметры» (`sc-sec`, прячется правилом пустых заголовков); сегменты вместо
   пары подписей с тумблером — показывается полоса-источник с кнопками и `id` (`display: flex !important` поверх
   инлайнового `none`: сам инлайновый стиль в форме и в старых ссылках не трогаем), тумблер прячется классом
   обёртки; степпер «Сколько КПВ» вокруг прежнего поля; «Сравнить с другой КПВ» — пунктирной «Добавить …».
4. **Модели — списком `SC_ON`**, по одной, у каждой свой коммит: ppf, ppfsum, trade, tradeprice, prod, costs, plants,
   isoquant, mono-d3 (и monoexport), mono-kink, mono-nat, труд (4 модели), smallopen. mono и mono-d1 — карточки списка
   кривых, сверены с компонентом. Смысл карточек «Внешнего рынка» (те же поля, что у дискриминации 3-й степени) —
   по состоянию на каждой перерисовке (`paintCard`).
5. **Карточки списка кривых** — те же обозначение 19 px и имя без обрезки: правило лесенки этапа В сужено
   исключением, без новых `!important` для шрифтов.

## Отвергнуто

* Новые поля с новыми `id` вместо старых (ломает историю, ссылки, автосохранения, паритет).
* Глаз на карточках TC, КПВ, заводов (на макете есть): видимости у этих кривых в «Условии» нет, глаз был бы мёртвой
  кнопкой либо вторым органом галочки «Вида» (решение …8142…).
* Ползунок «Мировая цена» у «Монополиста и внешнего рынка»: мировая цена там — поле формулы; ползунок был бы новой
  функцией. Сделана карточка «Pw — Мировая цена».
* Класс на кнопках с `id` (сегменты, «Сравнить…»): `formNodes` пишет класс кнопки в форму модели, и старая ссылка
  снимала бы вид. Вид — через родителя или атрибут `data-*`.
* Ползунки букв из формул сцен (a в КПВ, «Макс X / Макс Y») под карточку: буквы общие на модель, остаются в
  «Параметрах» (README 8).
