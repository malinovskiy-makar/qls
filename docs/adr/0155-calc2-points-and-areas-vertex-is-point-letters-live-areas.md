# ADR 0155 — Точки и площади: вершина — точка списка, имена буквами, живые площади

  (README 1, 9, 10, 12–14; макет `04_screen_points`). Задание — `PROMPT_7.md`; журнал —
  `claude/PROGRESS_CALC2_PANELS_7_20261015.md`. **Пересматривает** пункт «Отвергнуто» ADR 0148 про имена-буквы.

## Контекст

До сессии 7 своя точка и вершина площади жили раздельно: площадь «Между точками» набиралась щелчками заново (копии
координат в `STATE.areaVerts`), даже если нужные точки уже стоят; обход и число площади замерзали в момент расчёта,
у площади под кривой заливка шла по живой кривой, а число — нет. Точки звались «Точка 1, 2…» (ADR 0148 отверг буквы:
они сдвинули бы выгрузку). Строка точки несла всё сразу (цвет, имя, ✕, «Q = …», «P = …», две галочки), «на чём
стоит» — словами («на спросе»). Площади называлась по длине списка (убрали S₁, добавили — второй S₂).

## Решение

1. **Вершина площади — точка списка.** Запись многоугольника хранит `ids` — id точек `STATE.marks` (а не объекты и
   не копии: `plainCopy`, JSON и «Отменить» рвут тождество объектов). Обход и число считает одна функция
   `areaLive(r)` по правилу П43 (`bestAreaRing`) перед каждым чтением — отрисовкой, строкой панели, «Ответом», его
   подписью, границами нарисованного; `ring`, `order`, `value` обновляются на месте. Площадь под кривой — интеграл
   по текущей кривой на её [a; b]. Запись старой ссылки без `ids` — как была (замороженный контур и число, в строке
   «по координатам»).
2. **Площадь по точкам.** Галочки строк точек (вид, `CANVAS.ptsSel`) → при ≥ 3 плашка «Выбрано N · Площадь по
   точкам». «+ По точкам» (бывшее «+ Между точками») — набор на холсте: щелчок по свободному месту ставит новую
   точку списка и берёт её вершиной, по точке — берёт / снимает, по первой при ≥ 3 — площадь; «Готово» в полосе
   режима; Esc — площади нет, точки остаются. Набор — `CANVAS.buildIds`. Отдельного списка вершин нет;
   `STATE.areaVerts` всегда пуст (старое непустое отбрасывается).
3. **Каскад.** Убрали точку — уходят площади на ней (одно действие, один шаг, одно «Отменить» возвращает обе);
   убрали площадь — точки остаются; «Убрать все точки и площади» — один шаг.
4. **Имена — буквы.** Новая точка — первая свободная буква A … Z, потом A₁ …; свободная — не занята своей точкой и
   обозначением на холсте модели (буква кривой, ключевой точки, области, оси). Не счётчиком. Старые имена («Точка 1»)
   сохраняются. В `.tex` — `$A$`, `$A_{1}$` (`labelTex`). Площадь — первый свободный индекс S₁, S₂ …
5. **Панель по макету.** Шапка — «Точки и площади» и «Готово» («← Условие» убран, закрытый список 10.5). Строка
   точки — галочка, буква, «(40; 60)», «на D» / «точка Q₁ и P_b» обозначениями, «⋯» (меню всплывающим окном в body:
   Переименовать, Изменить координаты, Цвет, Пунктир к осям, Координаты на графике, Убрать). Строка площади —
   образец цвета, S₁, «ABC» / «D, [0; 100]», число, «⋯» (Переименовать, Цвет, Убрать).
6. **Вид, а не модель.** Выбор, набор, открытое построение (`areaCalcMode`, кнопки и панели «+ Под кривой» /
   «+ По точкам»), правка строки — не история, не автосохранение, не ссылка (`CANVAS`, `MODEL_STATE_SKIP`,
   `FORM_SKIP_IDS`). `applyModelState` не применяет ключи `MODEL_STATE_SKIP`. Версия состояния прежняя (1): старые
   ссылки и сохранения открываются.

## Отвергнуто

- Вершины в порядке отметки (README 9 до 15.10): неудачный порядок даёт самопересекающуюся фигуру; П43 — решение
  владельца …81be….
- Повысить версию состояния ради новой записи площади — убило бы все сохранённые ссылки и автосохранения.
- Меню строки внутри строки — список точек пересобирается на каждом шаге перетаскивания, площади — на каждой
  перерисовке; меню гибло бы вместе со строкой.
- Имя по счётчику `markCounter` — он съедает номера черновиков и откатывается «Отменить» (пропуски и повторы).
