# ADR 0177 — Результат тура: «Как решали другие» только от 20 учеников; «Оспорить оценку» — чат «Стола», балл не меняется

* **Дата:** 2026-10-30
* **Статус:** принято ночной сессией; подтверждение владельцем — утром 31.10.
* **Ветка:** `feat/olympiads-screens-20261031`; код `olympiads/navigator.py`
  (`others_stats`), `olympiads/dispute.py`, `catalog/chat.py` (режим `dispute`),
  `problems/ai/prompts.py` (`CATALOG_CHAT_MODES['dispute']`), тесты
  `olympiads/tests/test_night_E8.py`.

## Решение

1. «Как решали другие» и медианы по заданиям — только из настоящих сданных
   попыток ВОШЕДШИХ учеников на время по этому комплекту, по последней
   попытке ученика, без самого решающего, и только если учеников не меньше
   20 (`OTHERS_MIN`). Меньше — блока и медиан нет. Гости не входят: их
   попытка ни за кем не числится и повторяется.
2. «Оспорить оценку» — тот же чат «Стола» (`catalog.chat.answer`) с новым
   режимом `dispute`: модель получает условие (чат собирает сам), решение и
   итог проверки (как «последнюю попытку»), критерии с баллами и пояснениями
   (дополнительный системный блок) и строку спорного критерия цитатой
   (`quote_source='criterion'`). Реплики пишутся в `ChatTurn`, как в «Столе».
3. Чат балл не меняет. «Отправить на проверку человеку» ставит итогу задания
   `is_pending` (балл остаётся виден) и `TrainingCheck.human_review`.
4. `dispute` не вписан в `ChatTurn.Mode.choices`: значение помещается в поле,
   а правка choices завела бы миграцию в `problems`, где номера делят ветки.

## Отвергнуто

- **Медиана «от первого решившего».** На трёх учениках «выше, чем у 67 %» —
  шум, который школьник прочтёт как факт; макет показывает 214 решавших.
- **Свой чат для оспаривания.** Второй чат разошёлся бы с «Столом» в журнале,
  лимитах и потолке денег; режим — один блок промпта и один аргумент.
- **Пересчёт балла моделью по итогам спора.** Модель уже поставила балл по
  критериям; второй раунд по просьбе ученика поощрял бы торг, а не довод.
