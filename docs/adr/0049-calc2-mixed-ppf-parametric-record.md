# ADR 0049. Параметрическая запись суммарной КПВ через альтернативные издержки

- **Дата:** 2026-08-31
- **Статус:** принято
- **Автор:** Claude Code
- **Ветка:** `feat/calc2-priyomka-31aug`
- **Решение владельца в Notion:** «Суммарная КПВ: если явного Y(X) нет,
  печатаем параметрическую запись через альтернативные издержки»
- **Источник:** чат с владельцем 31.08 + учебник Бахарева, с. 185–191

## Контекст

Набор из двух КПВ, где у одной кривой альтернативные издержки растут, а у
другой убывают, получал честный отказ: «построена численно, у одних полей
оптимум внутри, у других в углу». Требование владельца: «неважно, какое
смешение, всё равно нужно показывать аналитический вид».

## Решение

Для ДВУХ кривых смешанный случай решается полностью. Кандидатов ровно пять, и
каждый — закрытая форма:

    (1) x₁ = 0      → Y = Ymax₁ + f₂(X),   X ∈ [0; Xmax₂]
    (2) x₂ = 0      → Y = Ymax₂ + f₁(X),   X ∈ [0; Xmax₁]
    (3) x₁ = Xmax₁  → Y = f₂(X − Xmax₁),   X ∈ [Xmax₁; Xtot]
    (4) x₂ = Xmax₂  → Y = f₁(X − Xmax₂),   X ∈ [Xmax₂; Xtot]
    (5) равные издержки: x₁(λ), x₂(λ) при общем λ

Ответ — верхняя огибающая пяти. Участок равных издержек печатается
ПАРАМЕТРИЧЕСКИ:

    X(λ) = x₁(λ) + x₂(λ),   Y(λ) = f₁(x₁(λ)) + f₂(x₂(λ)),   λ ∈ [λ₁; λ₂]

Обе x(λ) — закрытые формы из нового поля `xOfTex` таблицы `PPF_FAMILIES`.
Рядом с записью словами: λ это альтернативные издержки единицы X, выраженные
в Y. Слова стоят ПРИПИСКОЙ под записью, а не внутри неё: участок обязан
остаться одной строкой (ADR 0048).

Следствие: аналитический вид есть ВСЕГДА, пока обе кривые отнесены к известным
семействам. Отказ остаётся только для нераспознанных форм и для трёх и более
кривых смешанного набора — там перебор кандидатов растёт как n·2ⁿ⁻¹.

## Что здесь численно, и это надо называть честно

- **Границы участков** ищутся численно: бисекция по разности соседних
  кандидатов. Сами участки остаются формулами.
- **Подстановка при отрисовке**: чтобы нарисовать точку по заданному X, надо
  решить X(λ) = X. Печатается при этом закрытая запись.
- Сверка с численным Минковским в 200 точках обязательна и здесь: расхождение
  больше 1e-6 — записи на экране нет.

Полностью символьным решением это не является, и выдавать его за такое нельзя.

## Почему кандидата (5) нельзя выбросить

«В смешанном случае оптимум всегда в углу» — неправда. Вторая производная
суммы равна f₁'' + f₂'' и при вогнутой f₁ с выпуклой f₂ бывает отрицательной:
внутренний максимум там существует.

Контрольное число: `100 - x^2` (Xmax 10, издержки растут) и `20 - 10*sqrt(x)`
(Xmax 4, издержки убывают). При X = 5 верный ответ 99,0746 (внутреннее решение
x₁ ≈ 1,300, x₂ ≈ 3,700), а огибающая по одним углам даёт ровно 99,00. Разница
0,07 стережётся постоянной проверкой, которая считает ОБА числа.

## Что отвергли

- **Решать кубическое по Кардано и печатать явный ответ.** Формула выходит на
  полэкрана и ничего не объясняет школьнику.
- **Оставить численный ответ с объяснением.** Не отвечает требованию владельца.
- **Тянуть тот же перебор на три и более кривых.** n·2ⁿ⁻¹ кандидатов — это
  отдельная задача, а не довесок к этой.

## Цена, которую надо помнить

У параметрической записи НЕТ формы для поля ввода: λ поле формул не понимает.
Кнопка «копировать» у такой записи не показывается — подсунуть вместо неё
численную подгонку значило бы отдать человеку не ту функцию. Кнопка
«развернуть» остаётся.
