# ADR 0048. Компактная запись итоговой функции и кнопка «развернуть»

- **Дата:** 2026-08-31
- **Статус:** принято
- **Автор:** Claude Code
- **Ветка:** `feat/calc2-priyomka-31aug`
- **Решение владельца в Notion:** «Блок "Итоговая функция" — компактная запись
  без слова "если" плюс кнопка "развернуть"»
- **Уточнение владельца того же дня:** одна строка на участок, без исключений;
  двухстрочная форма запрещена во всех видах и не может быть запасным путём

## Контекст

Приёмка 31.08. Запись в блоке «Итоговая функция» набиралась ВТОРОЙ формой,
заведённой 26.08: условие уезжало на свою строку под формулу, окружением
`gathered`. Владелец назвал причину прямо: «запись участка и её условие стоят
на разных строчках, это нечитаемо». Центрирование строк, которое давало то же
окружение, только добивало: `gathered` центрирует, и «100 − Q» висело по центру
над «если 0 ≤ Q < 40».

Замер 31.08 при панели 191 px: переполнения не было вовсе (182,6 px внутри
`.katex`), то есть вторая форма включалась не от нехватки места, а потому что
однострочная запись не укладывалась ПРИ ПОЛНОМ КЕГЛЕ. Ломало её одно слово:
311,5 px со словом «если» против 271,6 px без него.

## Решение

Кусочная запись собирается КОМПАКТНО: один участок — одна строка. Формула
слева, кегль 15 px, по левому краю; условие — вторая колонка справа, кегль
11 px, цвет `var(--text3)`, БЕЗ слова «если». Фигурная скобка остаётся, `P =`
стоит слева от неё по вертикали по центру.

Кнопка «развернуть» появляется ТОЛЬКО у кусочной записи и открывает окно
поверх страницы: запись во всю ширину окна, кегль 20 px, СО словом «если», по
левому краю, та же единственная кнопка копирования в синтаксисе Math.js.

Порядок отступления при нехватке ширины, строго в этом порядке:
слова «если» нет всегда → кегль условия 11 → 10 px → усечение условия
многоточием → кегль формулы 15 → 13 px → горизонтальная прокрутка с затуханием.
Возврата к двум строкам нет ни на одном шаге.

## Почему разметкой, а не одним KaTeX на всю запись

Внутри окружения `cases` колонке условий не задать ни кегль 11 px (KaTeX умеет
только доли 0,5 / 0,7 / 0,8 / 0,9 от основного — из 15 px это 10,5), ни цвет
токеном, ни усечение многоточием.

Задавать кегль колонке СНАРУЖИ, обычным стилем, нельзя. Замер 31.08: строки
второй колонки разъезжаются с первой (10,9 / 73,3 против 11,2 / 27 / 64,8),
потому что KaTeX ставит строки внутри колонки в `em` от кегля самой колонки.
Поэтому участок — это две ячейки сетки, и каждая набирается своим KaTeX.

## Что отвергли

- **Оставить двухстрочную форму запасным путём.** Прямо запрещено уточнением
  владельца: окружение `gathered` удалено из кода целиком, в том числе из
  плашки подсказки на холсте («во всех видах», а не только в панели).
- **Уменьшать кегль ниже 13 px.** Отвергнуто ещё 26.08 и остаётся отвергнутым.
- **Горизонтальную прокрутку как ОСНОВНОЙ путь.** Формула, которую надо
  мотать, не читается как формула; прокрутка остаётся последней ступенью.

## Следствие, которое владельцу надо знать

Полная компактная запись ШИРЕ панели. Замер 31.08: она просит 215 px, панель
даёт 191, и панель фиксированной ширины — окно 1920 px не помогает. Условия у
кусочных записей усекаются многоточием на всех рабочих ширинах, полное условие
читается кнопкой «развернуть». Число 246 px из решения владельца — это ширина
САМОЙ записи, а не контейнера.
