# ADR 0141 — «Графики»: экран выбора вкладками блоков, превью моделей из записи при рисовании

* **Дата:** 2026-10-09
* **Статус:** принято, ветка `feat/calc2-redesign`; заменяет в фазе 8 редизайна 10.2026 (ADR 0134–0138,
  README макета 04.10, раздел 4) только вид списка моделей и превью при наведении
* **Автор:** Claude Code
* **Решение владельца в Notion:** «Графики: экран выбора — вкладки блоков и сетка карточек с настоящими превью
  из калькулятора» (09.10). Задача — «Графики: экран выбора по варианту 2 (вкладки блоков) и настоящие превью
  моделей — сессия 1».
* **Макет:** `claude/mockups/calc2_picker_20261009/Вариант_2_вкладки_блоков.png`;
  журнал — `claude/PROGRESS_CALC2_PICKER_20261009.md`.

## Контекст

Экран выбора после редизайна 27.09 — поиск, «Продолжить», «Недавние» строкой чипов и пять колонок текста по
блокам; схема модели всплывала при наведении. Схемы (56 штук `.scard-spec`) были нарисованы в шаблоне руками:
неровные, местами не про то, что открывается, и устаревали молча при смене старта модели. Владельцу нравились
только поиск, «Продолжить» и «Недавние».

## Решение

1. **Экран.** Сверху «Графики» и поиск; один ряд карточек «Продолжить · <когда>» и до трёх недавних с превью;
   ряд вкладок из десяти блоков с числом рабочих моделей; под ним сетка карточек выбранного блока (превью,
   название, две строки описания); «скоро» — приглушённые карточки в конце блока, без превью. Во время поиска
   вкладки прячутся, находки всех блоков встают одной сеткой с именем блока над названием.
2. **Карточки — те же кнопки `.scard` шаблона.** Их слушает `88-params.js`, по ним открывают модели приборы;
   `95-picker-screen.js` меняет только раскладку и вид. Видимый блок — панель `.picker-group` с классом `.open`
   (тот же класс открывают приборы, которым нужна карточка чужого блока).
3. **Превью — настоящие графики стандартного старта.** Скрипт `calc2/tests/previews/make_previews.mjs`
   открывает каждую рабочую модель с канонического старта, делает бумажный прогон и опись выгрузки .tex
   (ADR 0139) и оставляет из описи кривые, закраски, сплошные отрезки и оси; подписи, числа, точки, пунктиры
   проекций, сетку, деления и легенду выбрасывает. Итог — один файл `calc2/static/calc2/previews.json`
   (≈ 31 КБ на 42 модели).
4. **Цвета — именами токенов, а не числами.** Светлое значение бумажного прогона сопоставляется с таблицей
   `--curve-*`, `--cost-*`, `--c-*`, `--sum-g*`, `--ink`, `--ink-soft` из `calc2.css`; несопоставленный цвет —
   дефект, скрипт завершается с кодом 1. Страница вставляет превью ВСТРОЕННЫМ SVG (через `<img>` переменные
   темы не работают), поэтому превью перекрашивается при смене темы.
5. **Толщина — в пикселях экрана** (`vector-effect: non-scaling-stroke`): кривая 2 px при любом размере превью.
   Толстая полупрозрачная полоса холста (дефицит на оси, импорт) идёт закраской своей толщины.
6. **Колодец превью — цвет холста `--canvas`.** Контраст кривой к нему тот же, что на настоящем графике
   (≥ 3 : 1 в обеих темах, ADR 0022 и контрольные числа калькулятора).
7. **Сторожа.** Свежесть: `tex/ci_quick.mjs` (идёт в CI через `test_calc2_tex`) сверяет отпечаток описи
   каждого старта с полем `fp` в `previews.json` — не сошлось, красный «превью устарело: <модель>,
   пересоберите командой …». Состав: `test_calc2_previews.py` без браузера — ключи файла ровно 42 рабочие
   карточки шаблона, у «скоро» превью нет, ручных схем нет. Экран: `calc2/tests/picker_probe.mjs`.
8. **Отпечаток — в единицах модели, а не в пикселях.** Пиксели листа зависят от ширины подписей, то есть от
   шрифтов машины, а сторож бежит в CI на другой системе. Отпечаток берёт окно панели, вид предмета, цвет,
   толщину и узлы с шагом 0,1 % размаха окна; генератор сам проверяет, что он один при 1440 × 760 светлой и
   390 × 844 тёмной.

## Отвергнуто

* Все 42 модели сеткой по блокам сразу (страница в пять экранов, семь заглушек против двух моделей в «Выборе
  потребителя»); строки с миниатюрой; ручные схемы; снимки картинкой (не меняют цвет с темой).
* Сборка превью в браузере посетителя при открытии экрана: 42 бумажных прогона — секунды работы на телефоне.
* Хранить в `previews.json` пиксельный отпечаток: на машине CI он разошёлся бы с машиной сборки без единой
  правки старта.

## Последствия

* Поменяли старт модели (формулу, цвет, окно) — пересобрать `node calc2/tests/previews/make_previews.mjs`
  (сервер на 8099), иначе CI красный.
* Новая рабочая модель на экране выбора — без пересборки красный `test_calc2_previews`.
* Кегли и скругления макета сведены к канону `/calc2/` (DESIGN.md 1.2, 1.5, «Редизайн 10.2026»):
  30/700 → 32/600, 18/600 → 17/600, 15,5/600 → 16/600, 12,5 → 13; радиус 14 → 12.
