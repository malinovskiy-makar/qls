# ADR 0051. Токен считается введённым, только когда его кто-то читает

**Дата:** 2026-09-01
**Статус:** действует
**Повод:** экраны новой палитры выглядели одноцветными при полностью
верных значениях токенов.

## Контекст

31.08 палитра Weconomics была заведена в `templates/_tokens.html`. Значения
подобраны замером, обоснования записаны, проверки зелёные, потолок долга
канона опущен. Владелец открыл сайт и сказал: «экраны выглядят
одноцветными».

Пересчёт обращений по проекту 01.09:

| Токен | Заведён | Обращений `var(--…)` |
|---|---|---|
| `--surface-tool` | 31.08 | **0** |
| `--surface-info` | 31.08 | **0** |
| `--brand-amber` | 31.08 | **0** |
| `--brand-amber-ink` | 31.08 | **0** |
| `--accent-ink` | 31.08 | **0** |
| `--fs-hero … --fs-meta`, `--lh-…` | 31.08 | **0** (девять токенов) |

При этом `color: var(--accent)` — **137** мест, хотя `--accent` заведён для
заливок, а для текста рядом лежал неиспользуемый `--accent-ink`.

Дизайнер дала семь цветов; на экран выходил один, потому что все семь
шаблонов продолжали спрашивать старые имена.

## Почему этого никто не заметил

Ни одна из существовавших проверок не могла заметить в принципе:

- проверки палитры (`test_palette_tokens`) читают **файл токенов** и
  считают контраст пар, **которые в нём объявлены**. Пара «объявлена, но
  никем не читается» для них неотличима от работающей;
- проверки канона ходят по страницам, но сравнивают то, что нарисовано, с
  порогами. Одноцветный экран порогов не нарушает: он идеально контрастен;
- ревью диффа видит добавленные строки в `_tokens.html` — и они верные.

Дыра ровно там, где кончается файл токенов и начинается остальной проект.

## Решение

**Токен считается введённым только вместе с местом, которое его читает.**
Сессия, заводящая токен, обязана в том же коммите подключить его хотя бы на
одном экране, а если роль новая — показать её на `/teacher/styleguide/`.
Живой стайлгайд — полигон приёмки: роль, не показанная там, не будет
замечена и на экранах.

Следствие для приёмки: вопрос «сколько мест читает новый токен» задаётся
до слов «готово», и ответ «ноль» означает «не сделано».

## Что сделано по этому решению 01.09

- рельс фильтров каталога и форма умного поиска → `--surface-tool`;
- плитки тем, карточки найденных задач, найденное умным поиском,
  карточки разделов лендинга → `--surface-info` + рамка `--brand-amber`;
- 137 мест `color: var(--accent)` → `--accent-ink`;
- три раздела стайлгайда показывают панель инструмента.

## Чего это решение НЕ закрывает

Шкала кеглей `--fs-…` по-прежнему не читается никем: кегли стоят числами
прямо в экранах (717 объявлений). 01.09 числа сведены к трём ступеням
16 / 14 / 13, но источником правды остались они, а не токены. Перевод
экранов на токены — отдельная работа, заведена карточкой.

## Сторож

Прямого сторожа «токен кем-то читается» не заведено намеренно: у палитры
законно есть значения про запас (например `--pending-*` для будущих
состояний), и красный тест на них был бы шумом. Вместо сторожа — правило
приёмки выше и явный пересчёт обращений в отчёте сессии.
