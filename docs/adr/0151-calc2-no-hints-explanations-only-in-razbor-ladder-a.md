# ADR 0151 — Графики без подсказок: пояснения только в «Разборе»; шрифт панелей — лесенка A

* **Дата:** 2026-10-14
* **Статус:** принято, ветка `feat/calc2-redesign` (на бой уходит со слиянием редизайна)
* **Автор:** Claude Code
* **Решения владельца:** Notion «Графики: никаких подсказок — ни всплывающих при наведении, ни поясняющих строк;
  объяснения только в «Разборе»» (…81eb…, 13.10); «Графики: шрифт панелей — вариант A: Montserrat везде, четыре
  кегля…» (…81d6…, 13.10). Карточки «Сдвиг MC» (…8169…) и комментарий к …81ec… (перенос названий без словаря).
  Пакет `claude/mockups/calc2_panels_20261014/` (README 3, 4, 6, 10). Журнал —
  `claude/PROGRESS_CALC2_PANELS_NIGHT_20261014.md`, этап В.

## Контекст

На 42 моделях было 1 214 подсказок по наведению, 59 поясняющих строк в «Условии», «?» у заголовков и в строках,
кнопка «Как писать формулы» в шапке «Условия», заметка в «Виде графика». Владелец: панель должна быть понятна с
первого взгляда, без чтения; если элемент непонятен без пояснения — чинить элемент; учебный текст об экономике —
в одном месте, в «Разборе». В левой панели было 18 сочетаний кегля и веса, подписи 11–12 px, моноширинный шрифт в
«Сложении спросов», синий выпадающий список в тёмной теме.

## Решение

1. **Плашка `#hint-tip` не показывается** ни по наведению, ни по фокусу, ни по касанию (`HINT_TIP_OFF`,
   86-workspace.js). `data-tip` → `aria-label` у КАЖДОГО узла (`syncTipLabels`; новые узлы — наблюдатель на кадр
   позже): невидимая подпись для экранного диктора. `title` у узлов холста остаётся.
2. **Кнопок «?» нет**: `.hint-btn` и `.hint-pop`, «?» у заголовков (`hintsToDots` больше не заводит знак,
   `HINT_DOTS_OFF`). Строки «Как строить график ?» и подобные уходят целиком; подпись поля «Ответ ищем на отрезке» и
   «Метка для перекрёстной ссылки» остаются (классы `.seg-lab-row`, `.lab-row`). Паритет: буква «п» закрытого списка
   `fates.mjs`.
3. **«Как писать формулы» в шапке уходит**: таблица `HOW_TO_ROWS` и примеры по роли поля — четвёртым разделом
   «Как писать» окна клавиатуры каждого поля формулы (`addHowToTab`, 82-input.js). Общий модуль клавиатуры
   `static/mathkbd` не тронут (им живут домашки). Пример записи — моноширинным только там: это образец набора.
4. **Поясняющие строки «Условия», окон и панели точек уходят с экрана** (`.hint`, `.fc-menu-note`, `.crow-auto`,
   `.wrench-note`, `.pts-hint`, `.cv-esc`, `.f-pal-lead`, `.howto-foot`, `.side-reset__why`). Экономика и математика
   модели — копией в «Разбор» (`conditionNotesToExplain`, 86-workspace.js: абзацы `.hint` «Условия», видимые сценой,
   и абзацы плашек «?» с пометкой `data-explain`), после вступления и перед вопросами, без повторов. Как пользоваться
   интерфейсом — убирается (закрытый список README 10). Сомнение — в «Разбор». Таблица судеб — в журнале.
5. **Лесенка A** блоком в конце `calc2.css` для `#tools-panel`, `#pts-panel`, `#wrench-pop`, меню карточек:
   18 / 600 заголовок колонки, 14 / 600 разделы, 14 / 500 подписи и имена, 13 / 600 кнопки и сегменты, 12 / 500
   мелочь; Montserrat; подпись → поле не ближе 6 px. Кегль и вес — с `!important` (в «Условии» правила разной силы
   копились годами); KaTeX и MathLive не трогаются. Только вид: разметка «Условия» прежняя (карточки — сессии 5–6).
6. `--input-bg` тёмной темы → `#232019` (= `--surface-2`), синий убран.
7. `texifyName` (88-params.js): заглавные сокращения в 2–4 буквы (MC, ATC, DWL, MSB…) — одним обозначением
   `\mathrm{…}`, как на холсте; Pw, Wmin — с индексом.
8. Экран выбора: `overflow-wrap: break-word` рядом с `hyphens: auto` у заголовков карточек — без словаря переносов
   длинное слово не режется краем карточки.

## Отвергнуто

* Короткие подсказки при наведении (владелец отверг в решении).
* Переносить тексты плашек «?» целиком в «Разбор»: инструкции интерфейса там ничего не объясняют об экономике.
* Добавить раздел «Как писать» в общий модуль клавиатуры: он общий с домашками.
* Перебивать кегли по одному правилу без `!important`: десятки правил разной специфичности.
