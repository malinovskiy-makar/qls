# ADR 0144 — «Графики»: колонка «Ответ» строками по группам; выбор кривой кнопками

* **Дата:** 2026-10-10
* **Статус:** принято, ветка `feat/calc2-redesign`; заменяет в ADR 0137 вид главных чисел (плитки 2×2 кеглем
  28/24/20) — сборка «поверх табло» остаётся; уточняет ADR 0143 (подписи главных строк математики)
* **Автор:** Claude Code
* **Решение владельца в Notion:** «Графики: колонка «Ответ» во всех моделях — строками «название — значение» по группам,
  а не крупными плитками; выбор кривой кнопками» (09.10). Задача — «Графики: вид колонки «Ответ» … — сессия 3, после
  макета». Макеты — `claude/mockups/calc2_answer_20261009/`. Журнал — `claude/PROGRESS_CALC2_ANSWER_20261009.md`.

## Контекст

После редизайна 27.09 главные числа «Ответа» шли крупными плитками в две колонки (28/24/20 px по длине числа), ниже —
строки табло мелким шрифтом. В математике подписи переносились («Пересекает ось / x =»), крупная цифра соседствовала с
мелким «x =», у двух кривых каждая плитка несла хвост «, кривая f». Выбор кривой для площади — свой выпадающий список
поверх системного, «Под кривой | Между точками» — тумблер. Заодно три бага: заголовок окна «Скачать» от прошлой
модели (файл «КТВ. Одна страна» уходил под именем «Построение графиков.tex»), «Отменить» сразу после включения
«Сначала сам» гасила кнопку при включённом режиме, подсказка TeX обещала «код TikZ», а выгружался целый документ,
который под XeLaTeX молча терял кириллицу.

## Решение

1. **«Ответ» — группы строк во всех моделях** (`94-answer.js`). У группы заголовок `.ans-ghead`, в группе одна
   величина на строку `.ans-cell`: подпись слева (13,5/400 `--text2`), значение справа (16/400 шрифтом KaTeX_Main,
   цифры одной ширины), линия между строками, высота от 44 px; «было · Δ» — мелко под значением по правому краю.
   Классы строки и `data-src` прежние — паритет и «Сначала сам» читают их как раньше. Не влезает значение рядом
   с подписью — строка в два этажа (подпись не уже 11em); значение посередине не рвётся (число и точка — целым
   куском, длинный список — только между значениями). Тем же видом и кеглями идут остальные строки табло.
2. **Группы.** У математики их задают строки (`data-ans-group`, 70-scenes-math.js): у «Построения графиков» — по
   группе на кривую с заголовком «точка цвета + запись f(x) = …» (строка «Кривая» — источник заголовка
   `data-ans-head`, в колонке не повторяется; хвост «, кривая f» — `.ans-ctx`, его видят табло и печать) и
   «Пересечения кривых» по строке на пару («f и g», пара без общих точек — «нет»); у прочих моделей математики —
   заголовки по смыслу. У экономики группа — блок табло (`#sec-eq` — его заголовок, прочие — `ANSWER_GROUP`).
   У математики обозначение не выносится в значение («Пересекает ось x» → «−2; 2»), у экономики — «Q* = 50».
3. **Состав главных величин прежний**, кроме `sd`: группа «Излишки» (CS, PS, SW словами). Блок табло, все строки
   которого ушли в «Ответ», не показывается; та же величина второй строкой в другом блоке — тоже.
4. **«Сначала сам» в столбик:** подпись строкой, поле на всю ширину и «Проверить» справа, ниже вердикт и «Показать»;
   место под вердикт стоит всегда. Режим — **вид, а не вход модели**: `#btn-self` не входит в форму
   (`FORM_SKIP_IDS`, 89-model-state.js), ссылка несёт режим отдельно (`&self=1`).
5. **Выбор кривой — кнопками** с цветной точкой (`buildAreaCurveButtons`, радио-группа, стрелки); скрытый
   `select#ac-pick` остаётся источником правды. «Под кривой | Между точками» — сегмент. Кнопка расчёта называет, что
   посчитает: «Сначала выберите кривую» → «Посчитать площадь под f».
6. **Окно «Скачать»:** заголовок при каждом открытии — правка человека в этой модели или название модели; правки
   помнятся по моделям в памяти страницы. Подсказка TeX честная; в начале `.tex` две строки о сборке и проверка
   движка (`iftex`, `\ifPDFTeX … \errmessage{Соберите этот файл через pdfLaTeX …}\stop`).

## Отступление от канона, вынесенное владельцу

Канон 1.2.2 (и DESIGN.md 5.1) требовал у числа в строке таблицы «Ответа» вес 700. Решение 09.10 и одобренный макет —
один формульный шрифт и один кегль у ВСЕХ значений колонки; главные числа и раньше шли формулой обычного веса.
Два начертания (700 у табличных и обычное у главных) нарушили бы решение, а жирная формула у всех — макет. Принят
обычный вес у всех значений; число отличается от подписи кеглем (16 против 13,5), шрифтом и цветом. Проверка
`calc2_ui.mjs` перенацелена на это правило. Нужно подтверждение владельца.

## Отвергнуто

* Строки только в математике, плитки в экономике — две системы на одном экране (решение владельца).
* Свой выпадающий список кривых в стиле сайта — тоже решение владельца: кнопки видны сразу и набирают обозначения.
* Убрать строку «Кривая» и хвост «, кривая f» из табло — номера строк табло держит паритет со старым экраном, а
  хвост нужен печати; в колонке их снимает вид (`data-ans-head`, `.ans-ctx`).
* Свой отрезок [−3; 3] у «Максимумов и минимумов» — отвергнут владельцем (одно правило для всех): отрезок по
  формуле [−5; 5], «Наибольшее на отрезке» (5; 110), код не менялся.
* Стрелка «→» в комментарии `.tex` — `tex/lint.mjs` пускает в файл только знаки набора T2A; в файле «>».
