# ADR 0001. Python 3.9 и Django 4.2 LTS

**Дата:** зафиксировано задним числом 2026-08-18 (решение принято в начале проекта)

## Контекст

Проект начинался на машине, где системный Python был **3.9**. Django 5.x требует
Python 3.10+, поэтому выбор версии фреймворка был предрешён версией языка.

## Решение

Python **3.9** + Django **4.2 LTS**.

## Последствия

- ⚠️ **Синтаксис `int | None` запрещён.** Union через `|` появился в 3.10 и роняет
  импорт с `TypeError`. Пишем `Optional[int]` из `typing`. Это не стилистическое
  предпочтение — код с `|` просто не запустится.
- Django 4.2 поддерживается до апреля 2026 года. После этого проект остаётся без
  security-обновлений фреймворка.
- На проде (Render) стоит Python **3.11** — то есть рантайм разработки и рантайм
  боя уже разные. Расхождение работает, потому что 3.11 обратно совместим с 3.9,
  но это не повод считать его нормой.
