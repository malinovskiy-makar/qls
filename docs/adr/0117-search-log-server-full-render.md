# ADR 0117 — Журнал поисковых запросов пишет сервер при полном рендере, склейка 30 секунд

* **Дата:** 2026-09-18
* **Статус:** действует

## Контекст

До беты текст поискового запроса каталога не сохранялся нигде: в событиях беты (`Event`, ADR 0103)
поиск лежал только длиной (`q_len`), а сервер нарочно вырезал строку запроса из адреса. Без текста,
статуса умного поиска, времени и выданных задач качество поиска после беты не разобрать, а оценке
человека («Нашли, что искали?») не к чему привязаться. Решение владельца 17.09 «собирать текст
поисковых запросов» в коде не было.

Ловушка: контекст каталога собирается одной функцией `_catalog_context` и для полной страницы
(`problem_list`), и для живого обновления фильтров (`api_filter_state`). Писать журнал в ней — один
запрос человека дал бы по строке на каждое нажатие фильтра.

## Решение

* Модель `SearchLog` в `problems/models_platform.py` (модели живут в `problems`): кто (`user`,
  `visitor` — кука `weco_vid`, `session_key`), `query` (до 300), `status`, `ms`, `total`,
  `degraded`, `top_ids` (первые 10 карточек — уже прошедшие шлюз качества), оценка `rating`
  (`yes`/`no`), `rated_at`, `rating_text` (до 300).
* **Пишет сервер**, модуль `catalog/search_log.py::log_search`, — только из `problem_list` после
  сборки контекста. `api_filter_state` пишет лишь по явному `log=1` (его будет слать «Стол» на
  нажатие Enter; нынешний каталог не шлёт). Клиентское событие теряется у части браузеров.
* **Склейка:** тот же посетитель (для вошедшего — пользователь) и та же строка
  (`strip().lower()`) моложе 30 секунд — новая строка не заводится, возвращается номер прежней
  (перезагрузка, «назад», «показать ещё»). Сравнение в Python: `iexact` на SQLite не понимает
  кириллицу.
* Номер строки уходит в разметку `#ct-results[data-search-log]`; оценка —
  `POST /api/search-rating/` (CSRF), своя строка сверяется по куке или пользователю, чужая и
  несуществующая одинаково 404; повторная оценка перезаписывает.
* Выгрузка — staff-командой `search_export`. Текст запроса в модель ИИ не уходит.

## Отвергнуто

* **Писать в `_catalog_context`** — строка на каждый щелчок фильтра.
* **Писать клиентом через `/api/track/`** — теряется у части браузеров, а текст запроса в `Event`
  по ADR 0103 не пишется вовсе.
* **Склейка по сессии Django** — у гостя без входа сессии может не быть.
