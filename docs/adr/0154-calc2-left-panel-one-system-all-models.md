# ADR 0154 — Левая панель одной системой во всех моделях

* **Дата:** 2026-10-15 (сессия 6 «тихих панелей», ночь 14 → 15.10)
* **Статус:** принято, ветка `feat/calc2-redesign` (на бой уходит со слиянием редизайна)
* **Автор:** Claude Code
* **Решение владельца:** Notion «Графики: левая панель одна во всех моделях и только про условие задачи; всё, что
  меняет одну картинку, — в «Вид»» (…8142…, 13.10); «никаких подсказок» (…81eb…); шрифт A (…81d6…). Пакет
  `claude/mockups/calc2_panels_20261014/` (README 1, 3, 4, 8, 10, 12, 13; макеты `05_left_Consumer`, `05_left_Adas`,
  `05_left_Mono`, `06_left_taxes`). Задание — `PROMPT_6.md`; журнал — `claude/PROGRESS_CALC2_PANELS_6_20261014.md`.
  Продолжение ADR 0153 (сессия 5).

## Контекст

После сессии 5 карточки были у 16 семейств моделей, но потребитель, макро, неравенство и «Математика» оставались с
голыми полями, а во всех моделях — ползунки прежнего вида (строка «Сдвиг D = 0», пределы «-50» с дефисом, дорожка
цвета кривой), тумблеры пар подписей, полоса вмешательства в одну строку и сегмент из одной кнопки. Проверка сессии 5
глазами нашла два вида карточки (запись 18 и 16 px, точка 20 и 16 px), числа пунктиром вместо плашки и пять старых
багов (КТВ 1,42 / 1,41, вопрос «Разбора» про AFC, «МРОТ W_min» в «Ответе», «КПВ 2» без формулы, повтор вопроса в
«Денежном рынке»).

## Решение

1. **Один вид карточки (А1).** Запись — база 18 px у всех карточек; запись, которая не помещается, ужимается до 16 px,
   не меньше. Отступление от README 3 («`fitFormulaField` не трогать»): в нём новая ветка ТОЛЬКО для некусочных
   записей и ТОЛЬКО для полей в `.fc-card` (`CARD_MIN_PX = 16`); кусочные идут прежней веткой побайтно, прочие поля
   `FORMULA_FIELDS` не задеты. Запись, которая не помещается и в 16 px (TC «Издержек» в колонке 305 px: нужно 163 px
   при 137), — приставка «TC =» уходит (класс `fc-pre-off` на строке поля, без id — вид), обозначение TC стоит в
   верхнем ряду, запись встаёт заново. Отложенная подгонка — через 200 мс после ПОСЛЕДНЕГО вызова и после догрузки
   шрифтов (иначе в WebKit записи MC, ATC «Задаю кривые» оставались 18 px и резались). Точка цвета — 16 px с кольцом
   у значка и у кнопки, у кнопки размер нажатия 26 px (подкладка `::after`).
2. **Числа — плашкой (А2):** 76 × 36, фон `--surface-2`, рамка `--border`, радиус 6, цифры справа шрифтом формул.
3. **Строка ползунка пишет значение модели (А3):** `sl._modelValue`, если дорожка стоит на нём с точностью до шага.
4. **Карточки для всех моделей с полями формул**: потребитель (карточка U «Полезность» — новый узел без id, органы
   `cons-*` переезжают в неё узлами; список вида через `upgradeSelect`), макро (вариант «число» у `wrapFieldInCard`
   для LRAS — тот же узел `ma-lras`), неравенство (карточка L), «Математика» (f, f₁ …, f и g, строки «Построения
   графиков» — сама строка становится карточкой в обоих путях рождения). Модели без функций («Кривая Филлипса») —
   заголовок карточки ввода «Параметры».
5. **Строки параметров везде (этап Д):** сдвиг под карточкой — «Сдвиг» слева, число справа, пределы «−50 … 50» под
   дорожкой с настоящим минусом (`boundText`, только в подписи предела — `fmt` не тронут), цвет дорожки `--accent`
   (не цвет кривой); буквы — «Параметр» и «a = 1», крестик тихой кнопкой 26 px; ползунки без меню границ — подписи
   пределов текстом, меню и `boundsByHand` им не добавлены (новая функция и новое состояние, ADR 0153).
6. **Вмешательство государства:** полоса вида из пяти видимых кнопок — 3 + 2, из одной — не показывается; подписи
   каскада «Вид налога:», «Налог платит:» — вне потока и невидимы (их инлайновые `display` и кегль у узлов с `id` —
   в форме модели, их не трогаем); «Платит / Получает» + сегмент «Продавец | Покупатель».
7. **Ни одного тумблера:** оставшиеся тумблеры пар подписей (`mm-mode`, `tsb-*`, `plv-*`, `ineq-rd-*`, `mc-*`) —
   сегментами в «Условии» и в «Виде» (полоса-источник видна `!important` поверх инлайнового `none` от `segToToggle`:
   единственное разрешённое исключение). Степперы — общий `scStepper` («Сколько КПВ / функций / групп»).
8. **Мёртвая буква не получает ползунок:** буква, которая является переменной оси модели макро (r у «Заёмных
   средств»), — без ползунка (`scAxisLetter` в `buildPultExtra`); `STATE.params` не трогаем (старт, ссылки и
   автосохранения прежние). Сначала прибор доказал, что ползунок мёртв (`claude/panels_s6/dead_axis_probe.mjs`:
   «Ответ», все 83 узла холста со всеми атрибутами и `.tex` при r = 7, −5, 3,3, 0 — те же).
9. **«Разбор»:** вопрос про AFC переименован, повтор в «Денежном рынке» убран; сторожа `razbor_check` — закрытый
   список неверных утверждений и «вопросы одной модели не повторяют друг друга».

**Новые виды «ухода» органа с экрана — расширение закрытого списка README 10** (README 13):
* системный `select` под `upgradeSelect` (`cons-type`): орган — кнопка-список перед ним (паритет
  `findUpgradedSelect`; сверка — `allow` с причиной);
* мёртвый орган: ползунок буквы — переменной оси модели (loanable r, буква «т» паритета) и кнопка цвета ПУСТОЙ строки
  «Построения графиков» (до первой записи цвет ничего не делает, буква «ф»); судьба — по модели (`FATES_MODEL`);
* полоса сегментов из одной кнопки («Квота» у «Квот», буква «м» — была и раньше; сверка — `allow`).

## Отвергнуто

* Ужимать запись ниже 16 px или прокручивать поле (TC «Издержек» на 1 280): задание — 16 px не меньше и без обрезки.
* Переименовать «Какую функцию ищем» в «Что ищем» (задание Г4): подпись стерегут контрольные числа (решение 01.09).
* Таблица «до / после» для блока МРОТ (А5): потребовала бы новых строк табло и сдвинула бы паритет; раздел «С МРОТ»
  ложится в механизм разделов «Ответа».
* Свои дорожки ползунков (полоса 4 px `--track`, бегунок с кольцом) вместо системной с `accent-color`: строки
  параметров сессии 5 — системные; один вид на все ползунки важнее, переделка дорожки — отдельной задачей.
* Убрать `r` из `STATE.params` у «Заёмных средств»: ломает старые ссылки и автосохранения.
* Класс на кнопках с `id`: попадает в форму модели (`captureForm`) — вид через родителя (`data-n` полосы) или узлы без id.
