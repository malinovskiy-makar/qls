# ADR 0120 — «Стол»: первый шаг на странице задачи, без переписывания каталога целиком

* **Дата:** 2026-09-18
* **Статус:** действует (первый шаг; следующие — в журнале ночи и карточке Notion)

## Контекст

Решения владельца 17.09: каталог и страница задачи — один экран «Стол» (лента · задача · помощь),
свёрнутая панель — полоска 52 px (S1), «Фокус», первое открытие — лента свёрнута, помощь открыта,
теги свёрнуты у всех, «Как прошло?», вход с поиском в центре (E3), карта = фильтры, корзина
учителя. Спецификация — `claude/mockups/catalog_stol_20260917/README.md`. Ночью 18.09 после
части A оставалось около трёх часов: переписать каталог, страницу задачи, карту, учителя и
телефон целиком за это время значило оставить в ветке полуработающий главный экран.

## Решение

Первый шаг — на странице задачи `/catalog/problem/<id>/`, поверх нынешней разметки, без потери
функций (подсказки, решение с подтверждением, тест, чат с режимами и файлами, проверка, домашка):

* сетка «Стола»: лента 316 · колонка условия 680 по центру свободного места · помощь 392;
  свёрнутые панели — полоски 52 px; 1100–1399 лента выезжает поверх задачи; уже 1100 — прежняя
  одна колонка;
* лента «Похожие» рисуется сервером (прямая ссылка работает без скрипта), «Мои ★» догружается
  (`/catalog/api/rail/saved/`); строка ленты — один партиал `catalog/stol/_rail_row.html` со
  статусом из `ProblemProgress` (ADR 0119);
* состояние панелей — `localStorage` (`catalog/static/catalog/js/stol.js`), «Фокус» (F, Esc),
  клавиши `[`, `]`, J/K, стрелки, Enter;
* теги свёрнуты в `<details>` (раскрываются без скрипта), «Как прошло?» под условием;
* серверная основа следующих шагов уже есть: прогресс, ленты, живые числа карты с ключами
  справочника (`catalog/map_numbers.py`), история чата.

## Не сделано (следующие шаги)

Вход E3 и чипы (P3), смена задачи без перезагрузки и панель одним ответом (P1.2), лента
«Выдача», соседи и «Дальше» (P4), лестница помощи и единая лента помощи (P5), новый вид теста
(P6), карта-фильтр с анимацией (P7), корзина учителя (P8), телефонный вид (P9), зачистка
старых блоков — «Похожие задачи» под условием пока остаются (P10).

## Отвергнуто

* **Новый шаблон `stol.html` сразу на три адреса** — без P3/P5/P7 он заменил бы рабочий каталог
  недоделанным.
