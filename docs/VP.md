# Тренажёр «Высшая проба, 1 тур» (`vp`)

Технический файл приложения. Решения и причины — [ADR 0124](adr/0124-vp-app-separate-from-bank.md)
(отдельное приложение), [ADR 0125](adr/0125-vp-take-access-time-and-saving.md) (доступ, время,
сохранение) и [ADR 0126](adr/0126-vp-review-public-result-percentile.md) (разбор, свой и чужой
взгляд, процентиль, перенос гостевых попыток). Планы и статус — в Notion-штабе.

## Маршруты (`/vp/`, вход не требуется нигде)

| Адрес | View | Что |
|---|---|---|
| `` | `index` | опубликованные варианты по классам |
| `<slug>/` | `intro` | вход: разбалловка из данных варианта, правила, режим |
| `<slug>/start/` | `start` | POST `with_timer=1|0`; несданная попытка не дублируется |
| `a/<code>/` | `take` | все 44 задания одной страницей |
| `a/<code>/save/` | `save` | POST, пачка `{"answers": [{"item": N, "raw": …}]}` |
| `a/<code>/time/` | `time_left` | GET `{"expired", "seconds_remaining"}` |
| `a/<code>/finish/` | `finish` | POST, идемпотентная сдача |
| `a/<code>/practice-check/` | `practice_check` | POST `{"item", "raw"}` → `{"is_correct", "right"}`; только владелец, только сданная; **ничего не пишет** |
| `r/<code>/` | `result` | адрес публичен, содержимое по владельцу: владельцу полный разбор, чужому — балл, блоки, время, процентиль, ник |

Порядок в `urls.py` важен: `a/` и `r/` раньше `<slug>/`.

## Правила, которые нельзя ломать

* **Доступ — только `views._owns` / `_get_attempt`.** Чужой код — 404. Не проверять владельца в других местах.
* **Результат: два набора данных.** Чужому в контекст не попадают `chain`, `tests`, `practice_url` — в его
  HTML нет эталонов. Стилями прятать нельзя. Слово «эталон» на странице чужого не появляется.
* **Разбор ничего не считает** (`vp/review.py`): баллы — из `VPAnswer`, доли — `scoring.explain_item`
  (через общий `_multi_parts`), буквы змейки — `loader.chain_letters`.
* **У неотвеченного задания в разборе нет эталона, верных вариантов и решения:** их отдаёт только
  `practice_check`. Он пишет в базу ровно ничего.
* **Процентиль — `review.percentile`:** один человек — одна самая ранняя попытка, только `full` и
  `with_timer`, меньше 20 человек — `None` и блока нет, кэш `vp:pct:<id>` 300 с.
* **Перенос гостевых попыток — `vp/signals.py`,** по кодам из сессии, НЕ по `session_key`: `login()` меняет ключ до сигнала.
* **Баллы — только `vp/scoring.py`.** Пустой ответ — `(0.00, None)`. Сдача — `views._finalize`.
* **Время — `problems.exam_engine`** (`seconds_remaining`, `can_accept`); своей арифметики остатка нет.
* **Ответов на странице нет:** в шаблон идут строки `views._row`, не сами `VPItem`
  (`test_take_hides_answers`). Буква-связка не подсказывается.
* **`save` пишет только `raw`.** Стереть ответ можно только им; `finish` пустым ничего не стирает.

## Разбор (`vp/review.py`, `templates/vp/result.html`)

`chain_review(attempt)` — строки змейки (`broke_chain` стоит на строке, ПОСЛЕ которой цепь порвалась; сравнение
со следующим ЭТАЛОНОМ, не с моим следующим ответом). `tests_review(attempt)` — задания 31–44: выбранное,
верное, `explain`, решение. `comparison(attempt)` — процентиль, медиана, размер когорты или `None`.
Шаблон собирает строку арифметики из структуры `explain_item`; отрицательный итог поднят до нуля и
показан как «−3,00 → 0,00». `static/vp/js/result.js` — «Поделиться» (буфер обмена, без внешних
сервисов) и «Дорешать вне зачёта» (`textContent`, не разметка).

## Клиент (`static/vp/js/take.js`)

Один файл, разделы по порядку: ответы → «сейчас здесь» → клавиатура (Enter ведёт по змейке и не
сдаёт) → шапка и тема → автосохранение → время → сдача. Часы — `platform/exam_timer.js` без копии.
Имена узлов задают шаблоны `take.html` / `_take_item.html` (`#vp-item-<n>`, `name="item-<n>"`).

## Тесты и как их гонять

```bash
./venv313/bin/python manage.py test vp                       # SQLite; браузерный тест пропускается
DATABASE_URL='postgres://makarmalinovskiy@/qls_ci?host=/tmp' TEST_DATABASE_NAME=test_vp \
  VP_SHOT_DIR=/tmp/vp ./venv313/bin/python manage.py test vp --settings=config.settings_test_pg
```

`test_review.py` — сессия 3: разбор, процентиль, свой и чужой результат, перенос гостевых попыток,
`practice_check` (нумерация `test_NN_…` — сценарии задания). `test_take.py` — сценарии сессии 2 (нумерация `test_NN_…`), время двигается патчем
`django.utils.timezone.now` (`tests.helpers.at`), пауз нет. `test_browser.py` +
`browser_take.mjs` — настоящий Chromium (Playwright), гость проходит пять сценариев владельца,
таймер, «время вышло», офлайн, телефон 390 px; `VP_SHOT_DIR` складывает скриншоты. Идёт на
PostgreSQL: на SQLite в памяти живой сервер делит с тестом одно соединение и ловит ложные 500.

## Ловушки

* Слова эталонов в тестах разбора — бессмыслица (`…фъщ`): настоящее слово вроде «стало» находится в шапке сайта
  и даёт ложный «утёк эталон». Маркеры разметки для проверки утечки — `class="vp-crow`, `id="vp-chain"`, а не имена
  классов: определения CSS лежат в общем `<style>` каждой страницы.
* Плашки-теги разбора (`.vp-tag`) не ставить на заливку с заливкой (неверный вариант в тонированной строке): контраст
  падает ниже 4,5. У неверного варианта — рамка `--error-border`.

* `sendBeacon` доезжает **после** отрисовки перезагруженной страницы — поэтому несохранённое
  откладывается в `sessionStorage` (ADR 0125). Не убирать «ради простоты».
* `started_at` ставит база (`auto_now_add`) на доли секунды позже `expires_at`: длительность
  округлять ВВЕРХ (`views._time_text`), иначе «29:59 из 30:00».
* Тема переключается на экране прохождения через скрытый `#theme-toggle` шапки сайта: шапка на
  этом экране спрятана, реализация темы одна.
* Переходы темы (0,2 с) дают ложный контраст при замере — в браузерном тесте они выключены.
