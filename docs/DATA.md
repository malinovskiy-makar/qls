## Правило номер один

> **ИИ дописывает НОВЫЕ поля. Существующие `statement` / `answer` / `solution`
> модель не переписывает.**

Это не осторожность, а вывод из происшествия: свип Батча 2 испортил **233 поля
в 195 задачах** (13,2% затронутого). Замер — `reports/batch2_sweep/applied_revert_audit.md`.

Следствие: любая массовая правка корпуса идёт по конвейеру
`--dry-run` → предпросмотр → стоп-гейт владельца → бэкап → применение →
проверка идемпотентности. Ни один шаг не пропускается.

## Шлюз качества

`quality_gate --apply` / `--revert` — **обратимый**. Детекторы читаются из
`reports/quality_audit/gate_*.txt` и смежных файлов. Зафлагованные задачи
(`needs_quality_review`) исчезают из публичной выдачи: каталог, страница задачи,
случайная, блок похожих, конструктор подборок, экспорт, публичный API.

Отдельный флаг `solution_needs_review` прячет только кнопку решения — задача
остаётся видимой. Это осознанное разделение: плохое решение не повод прятать
хорошее условие.

**Домашки ученика шлюзом НЕ фильтруются** — уже выданное должно оставаться
решаемым.

## Состояние чистки текстов

⚠️ **Глобальный `white-space: pre-line` включать нельзя до склейки строк.**

- подпункты адресуются **по pk**, а не по метке: метки не уникальны (в выборке

### Провенанс эмбеддингов: пустой хеш — это НЕ поломка

Соблазн «проставить `embedding_source_hash` всем, чтобы `--stale` заработал»
надо гасить сразу — причина записана в
[`problems/embedding_provenance.py`](../problems/embedding_provenance.py).

- У **легаси** хеш пуст **намеренно**. Исторического текста, по которому вектор
  считали 04.07.2026, нет. Хеш сегодняшнего текста утверждал бы «вектор
  соответствует этому тексту» и врал бы ровно про те задачи, чей текст правили
  ПОСЛЕ пересчёта. Пустая строка означает «провенанс неизвестен» и оставляет
  вектор устаревшим — это честная сторона ошибки.
- У всего, что считает `build_embeddings`, провенанс **правдивый и полный**:
  команда пишет `embedding_version`, `embedding_model_build`,
  `embedding_source_hash` и `embedding_built_at` тем же `bulk_update`, что и
  сам вектор.

Отсюда практическое правило: **`--stale` на легаси не инструмент точности.**
Он честно отвечает «не знаю» про все 31 694 сразу. Сузить ответ можно только
полным пересчётом легаси — отдельное решение с отдельным бюджетом.

таблице `docs/CORPUS_FORMAT_ATLAS_20260825.md` они записаны как
«0; 118 битых упоминаний», где `0` и есть явная разметка. Тот детектор
нигде не сохранён и дословно не воспроизводится.

**Метка.** Скрытые помечены тегом `missing-figure` («нет картинки») —
481 задача. Найти одним запросом:

```python
Problem.objects.filter(tags__slug='missing-figure')
```

Тег стоит и на тех, чей статус не менялся (`draft`/`duplicate`/`archived`,
134 задачи) — иначе они потерялись бы для фазы подбора файлов. Статус
меняется только у `published`.

**Это ЧЕТВЁРТАЯ причина невидимости**, и с тремя из раздела «Ручное ревью»
её смешивать нельзя: `status='hidden'` тут означает «убрано руками по
конкретному поводу — нет вложения», а не оценку качества и не «человек не
смотрел».

## Состояние текста: `content_status` (чистка корпуса 03.09.2026)

**Это ПЯТАЯ причина невидимости.** Поле `Problem.content_status`
(миграция `problems/0050`) отвечает на вопрос «пригоден ли ТЕКСТ к показу»,
а не «хорошая ли это задача» и не «смотрел ли человек» — обоснование в
[ADR 0092](adr/0092-content-status-separate-from-hidden.md).

| Значение | Смысл | Виден ученику |
|---|---|:---:|
| `ok` | текст в порядке | да |
| `needs_fix` | текст требует доработки для правильного отображения | нет |
| `junk` | помечено к удалению | нет |

**Что сделано 03.09.2026** (команда `content_cleanup --apply --allow-delete`):

* удалено **23** записи из очереди «не задача» (1 596). Правило удаления
  конъюнктивное: строгий шаблон мусора по ВСЕМУ тексту (`fullmatch`), пустые
  `answer` и `solution`, ни одной ссылки использования, нет признаков
  родителя. Все 23 выгружены со всеми полями в
  `reports/enrich_pilot/deleted_not_a_problem.jsonl` ДО первого удаления;
* помечено `needs_fix` **3 836** задач: 1 573 из очереди «не задача»,
  3 312 из очереди дефектов, пересечение 1 044;
* задач видно ученику: **14 458 → 14 163**. Разница мала, потому что
  большинство помеченных уже были скрыты другими шлюзами;
* опечатки, не мешающие смыслу, оставлены видимыми — 24 задачи.

Раскладка дефектов по типу: утрачена часть условия 1 321, битая формула или
разметка 847, утрачена картинка или чертёж 428, утечка решения в условие
293, прочее 276, склеенные задачи 94, заглушка вместо условия 53.

⚠️ **Почему удалено так мало.** Очередь «не задача» — это вердикт модели, а
не факт. В ней глазами видны настоящие задачи подтипа «верно-неверно»
(«Алюминий добывают в шахтах.»): утверждение без вопросительного знака
модель принимает за служебный текст. Доля таких не измерена — независимого
признака нет: `problem_type` вызова 2 у всех 1 596 равен `не_задача`, а в
банке он пуст у 1 568. По источникам основная масса — не тестовые сборники:
«Листки задач» 726 и «Overleaf Archive 3» 469 против 2 у «Сборника тестов
АА».

**Фильтр `content_status='ok'` стоит в 16 местах:** `catalog/views.py`
(10 мест), `catalog/hybrid.py`, `catalog/latex_export.py`,
`catalog/semantic.py`, `problems/hw_generator.py`, `game/views.py`,
`game/management/commands/build_game_pool.py`.

⚠️ **Признаков невидимости стало пять, общей функции «видимая задача» в
проекте нет.** Шестой заводить нельзя — сначала свести пять в одну функцию.

Откат: `content_cleanup --revert` возвращает `content_status` в `ok` всем
задачам. Удалённые записи этим не возвращаются — только из выгрузки.

## Известный брак

- **Задачи без темы** — около 14 тысяч, в основном ILE.
- **Заголовки** — часть с артефактами импорта (имя автора в заголовке), часть
  обрублена по 300 символов с дефисом посреди слова; задачи без `title`
  показываются как «Задача #ID».
- **Расплющенные таблицы** — скриптом не чинятся, скрыты шлюзом.
- **Тема «Тест»** должна быть типом (`problem_type`), а не темой; ~253 задачи
  помечены ей, часть назначений ошибочна.
- **Дубли** — ~11 841 пара в `DuplicateCandidate` ждёт разметки.
- **233 поля в 195 задачах** испорчены откатом Батча 2 — починка не сделана.
- **Повисшие служебные подпункты** («Ответ:» без содержания) — ~150, баг импорта.
- **481 задача ссылается на картинку, которой нет** — скрыты и помечены тегом
  `missing-figure`, файлы не подобраны. См. раздел «Пропавшие картинки».

Каждый пункт заведён карточкой в Notion, база «Задачи».
