# Данные беты: ИИ-чат и умный поиск

Шаг 0 настройки ИИ: прежде чем менять чат и выбирать модель, заменить
допущения цифрами с копии боя. Две команды, обе **только читают** базу и пишут
файлы **вне репозитория**. Цифр по людям здесь нет — они в отчёте и в Notion
(«Результаты»).

## Где лежат данные

| Что | Где |
|---|---|
| Ночная копия боя (дамп и том media) | `C:\Users\shipu\weconomics-data\prod_dumps\` |
| Копия базы | PostgreSQL в контейнере `qls_postgres_dev`, база `weco_beta_<дата>` |

тексты школьников. Перед коммитом — `git diff --cached --stat`, в нём не
должно быть `.jsonl`, `.html`, `.gz`, `.dump`, `.csv`, `.json` с данными.

## Как поднять копию

```bash
docker exec qls_postgres_dev createdb -U qls weco_beta_20261007
gunzip -c beta.dump.gz | docker exec -i qls_postgres_dev pg_restore -U qls -d weco_beta_20261007 --no-owner --no-privileges
tar -xzf beta-media.tar.gz ./chat/        # в папке weconomics-data\beta_<дата>\media
```

Все команды к копии — с `DATABASE_URL=postgres://qls:qls_dev_password@127.0.0.1:55432/weco_beta_<дата>`
**и** `--settings=config.settings_test_pg`. Без любого из двух команда уйдёт в
домашнюю базу. Тесты запускать **без** этой переменной.

## Команды

```bash
ai_beta_report --out <папка> [--since D] [--until D] [--team-file F]
ai_beta_dialogs --out <папка> [--since D] [--until D] [--team-file F]
```

- `ai_beta_report` → `BETA_REPORT.md` (опись копии и блоки A–K) и
  `beta_numbers.json` (те же цифры целиком). Каждая цифра — в двух срезах:
  «все» и «без сотрудников». Расчёты — чистые функции
  `problems/ai_beta/metrics.py`, тесты `problems/tests/test_ai_beta_metrics.py`.
- `ai_beta_dialogs` → `dialogs.jsonl` (строка на разговор, реплики по времени,
  пути файлов относительно `media/`) и `reader.html` — читалка рядом с папкой
  `media/`. Тесты `problems/tests/test_ai_beta_dialogs.py`.
- Даты — по Москве, `--until` включительно. Файл команды по умолчанию —
  `<out>/team_user_ids.txt`, если он есть.

## Три определения

- **Сотрудник** — `is_staff` или `is_superuser`, плюс номера из файла команды
  (номер в строке, `#` — комментарий).
- **Активный за неделю** — вошедший человек хотя бы с одним событием `Event`
  за неделю (понедельник–воскресенье, МСК). В срезе «без сотрудников» это
  ровно определение задания; в срезе «все» сотрудники тоже считаются.
- **Решил задачу** — пара «человек–задача» решена, если есть хоть что-то из:
  статус `ProblemProgress` «решил сам» или «с подсказкой»; попытка
  `CatalogAttempt` с вердиктом «верно»; событие `test_answer` с `correct=true`;
  `LearningEvent` «решил» по задаче каталога. Время решения — время записи;
  у `ProblemProgress` это `updated_at` (последнее изменение, приближение).

## Правила счёта

- **Перцентиль** — ближайший ранг (элемент номер ⌈p·n/100⌉), без
  интерполяции: каждое число — значение, которое реально было.
- **Одновременность** — вызов из `AiUsageLog` занимает отрезок
  `[created_at − seconds, created_at]`; касание концами — не пересечение;
  вызовы с нулевой длительностью не считаются.
- **Вид потери** — по тексту `ChatTurn.error`: «лимит обращений» — личный
  лимит; «бюджет» — дневной потолок; «неожиданный ответ» — сбой формата;
  «Помощник не ответил» — пустой ответ; «занял больше»/«прерван» — обрыв по
  времени; «связаться» — связь, но если реплика длилась до потолка времени
  (`AI_TIMEOUT_SECONDS`, без секунды) — обрыв по времени: у GLM таймаут
  приходит тем же текстом, что и обрыв связи.
- **Испорченная формула** — в ответе символ `\x08` или `\x0c`, либо табуляция
  перед `imes`, `ext{`, `heta`, `au`, либо возврат каретки перед `ight`, `ho`,
  `angle`. Это след того, что `\frac`, `\times`, `\beta`, `\right` в JSON
  превратились в служебные символы. Обычный перенос строки — не порча. Это
  счётчик одного известного дефекта, а не проверка формул вообще: та —
  только рендером KaTeX (`problems/management/commands/CLAUDE.md`).
- **Ответ у потолка** — длина от 0,99 `REPLY_MAX` (режим check —
  `CHECK_REPLY_MAX`) из `catalog/chat.py`.
- **Пересчёт на Flash** — те же токены реплик по цене `glm-5.3-flash` из
  `settings.AI_PRICES`; зрение и так идёт на Flash.
- **«Выдал ответ» (блок K)** — грубая оценка: ключ — `propose_key` вида
  `exact` по ответу банка (задача и пункты); число, которое есть в самом
  условии, ключом не считается; совпадение — с допуском `default_tol`.
- **Воронка** — «открыл задачу» = событие `problem_open`; «открыл помощь ИИ»
  = клик по кнопке, подпись которой начинается с «Спросить ИИ» (фильтр идёт в
  базе, текст кликов в Python не читается); «написал» = реплика в `ChatTurn`.

## Ловушки

⚠️ **Реплика со сбоем формата пишется в `ChatTurn` с ценой и токенами 0**,
хотя вызов оплачен и есть в `AiUsageLog`: исключение летит из `core.run`
раньше, чем `catalog/chat.py` прибавляет цену. Поэтому деньги чата сверяются
двумя суммами, и отчёт показывает разницу отдельной строкой.

⚠️ **`SearchLog` не хранит причину `fallback`.** Отказ по потолку до 24.09
(до `rerank_gate`) тоже записан как `fallback`; отличать его приходится по
суткам, когда расход `search_rerank` дошёл до потолка.

## Читалка

`reader.html` открывается двойным щелчком: KaTeX вшит, сеть не нужна, фото —
из `media/chat/…` рядом. Слева разговоры и фильтры (режим, длина, кто, есть
фото, есть ошибка, только кандидаты), справа разговор: условие (свёрнуто),
реплики, фото с расшифровкой. У разговора — галочка «кандидат в
„Репетитор-30“», вид ситуации и заметка. Отметки хранятся в браузере
(localStorage) и выгружаются кнопкой «Скачать отметки (JSON)»:

```json
{"format": "ai_beta_marks/1",
 "rows": [{"thread": "…", "candidate": true, "kind": "stuck", "note": "…"}]}
```

Виды: `answer_request` просит готовый ответ, `stuck` застрял на шаге,
`wrong_solution` прислал неверное решение, `theory` вопрос по теории, `photo`
прислал фото, `other` другое. В выгрузку попадают разговоры, у которых есть
хоть одна отметка.
