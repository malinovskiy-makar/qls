единым блоком; подпись точки сохраняет привязку; учитываются границы холста и
кривые; числа отступают от ручек поперёк оси; близкие координаты получают второй
ряд. Область двойного щелчка следует за подписью. Шрифт измеряется без скрытого
CSS-перехода. На телефоне у графиков один поток страницы; ни в выборе, ни в
открытой модели нет нижнего юридического футера. Cookie-панель сохранена.

Production пока не содержит pdflatex. Поэтому образ дополнен TeX Live,
кириллическими CM-Super/LH и системными метриками T2A. Метрики готовятся при
сборке, а не в HOME пользователя. Ограничения PDF-компилятора (закрытый каталог,
openin/openout, запрет shell escape, таймаут) не ослаблены. Цена решения —
увеличение размера образа и времени первой сборки; ML-пакеты не добавлены.

Два консервативных решения: реальные данные из восстановленного дампа не
подключаются к просмотру или исходящим сервисам; main не обновляется до
проверки единого кандидата, поскольку таймер main автоматически обновляет dev.
Ручная приёмка владельцем не является условием завершения подготовительных работ.

На полном исходном прогоне обнаружен недостаточный запас шапки персонала:
1022,5 / 1118,5 px для ряда и 28,5 px запаса у имени вместо требуемых 35.

## Откат и main

### Дополнительные находки полного прогона

- Поле точного значения измеряет набранный текст в фактическом шрифте:
  длина в `ch` обрезала табличные цифры. Существующие допуски теста сохранены.
- Обратный перевод формулы превращает только десятичное `{,}` в точку.
  Раньше правка `10 + 0.5*L` оставляла прежнюю кривую, а восстановление
  теряло дописанное `+5`. Запятые аргументов `min(1.25,2.5)` сохраняются;
  регрессия проверяет численный результат до и после восстановления.
- У новой ссылки из каталога применяется штатный токен фокуса `--focus`.
  Активное состояние и цвет ссылки не меняются.
- WebKit Playwright отдавал старые координаты SVG через `boundingBox`.
  Прибор берёт фактический `getBoundingClientRect` и выполняет настоящий
  двойной щелчок мышью, затем проверяет открывшийся редактор. Обработчики
  приложения не вызываются напрямую, перехват событий не отключается.
- Высота главной VP ограничена сверху на большом мониторе, чтобы карточка
  не растягивалась пустым пространством. Проверяются отсутствие прокрутки,
  три действия в строке и четыре ячейки нижней панели.
- `GIT_SHA` задаётся после установки системных и Python-зависимостей:
  точная версия остаётся в образе, смена SHA не инвалидирует тяжёлый слой TeX.

До открытия записей: вернуть сохранённый образ и соответствующую статику для
всех web/ws/tgbot; сверить здоровье. Поскольку схема не меняется, восстановление
БД обычно не нужно. Если оно необходимо из-за повреждения, делать только в
закрытом окне по проверенному плану восстановления, с явной сверкой backup.

После появления новых записей: **не восстанавливать старый дамп автоматически**.
Совместимый откат кода/статики сохраняет новые ответы и регистрации. При
несовместимости — исправление вперёд либо отдельный план переноса новых записей;
удалять их ради быстрого отката нельзя. Отказ Telegram сам по себе не причина
откатывать базу.

Актуальная объединённая ветка и PR публикуются на GitHub. Слияние в main должно
сохранять проверенный SHA (fast-forward, где возможно) либо пройти CI заново
на merge-SHA. Force-push/rebase общих веток не применяются. Автовыкатка dev
из main учтена; публикация ветки не означает, что production обновлён.

## Дополнительные результаты общей приёмки

- TeX Live 2023 с `openin_any=p` отклонял абсолютное имя входного файла.
  Передаётся имя файла относительно закрытого рабочего каталога; ограничения
  чтения, записи и запрет shell escape сохранены.
- Имя функции на свободной плоскости начинается внутри поля, с местом справа
  для текста, и следует за кривой без запаздывающей анимации. Замер прежнего
  сценария `a*x^2-3*x`: 0,42 px при неизменённом допуске 2 px.
- Пресет собирает одну итоговую отрисовку; промежуточные рыночные расчёты
  сохранены, поскольку следующий регулятор использует равновесие. Проверка
  2062 значений после изменения: ноль расхождений. Пороги скорости не повышены.
- В расчётных циклах изокванты и производства используется существующий
  `evalWithParams`: известные параметры не требуют обхода полей DOM на каждой
  точке; запасное значение новой буквы осталось прежним.
- Уведомление «Вернуть» учитывает высоту окна cookie. Само окно и выбор
  согласия сохранены. Импорт слоя в приборах состояния переведён на file URL
  для запуска на Windows и Linux.
- Верхняя граница высоты VP уточнена до 700 px: проверены 44 сочетания темы,
  входа и размера. На desktop зазор перед действиями 53–161 px; три действия
  остаются в строке, проверка ответа — четвёртой ячейкой нижней панели.
- Полная проверка состояния сошлась по 46 ключам (включая синонимы моделей).
  Общий CI ещё повторяется: старые красные прогоны и пропуски по таймауту
  не считаются приёмкой. В тест дуэли добавлена ограниченная трасса событий

### Уточнение по общему CI

На `58d3f532` фаза A прошла 7942 теста (6 пропусков внешних корпусов и
отдельного сервиса поиска). В B математические 250 проверок прошли внутри
штатного лимита 180 секунд; паритет, память, PDF и интерфейс также зелёные.
Единственное падение — дуэль: трасса выявила HTTP 403 при WebSocket handshake.
При discovery соседний тест импортировал ASGI до добавления localhost в
ALLOWED_HOSTS живым сервером. На Linux дочерний процесс наследовал уже
собранный OriginValidator со старым списком. Исправлена только тестовая
оснастка: в дочернем Daphne штатный ASGI-стек пересобирается с настройками
живого сервера. Origin, Auth и согласия не обходятся; боевой код не меняется.
Минимальный воспроизводящий порядок импортов до исправления падал, после
него прошёл. Общий CI повторяется на новом кандидате; прошлый красный
прогон не засчитывается как зелёный.

Повтор истории обнаружил зависимость склейки от момента отложенной записи:
реальные нажатия через примерно 500 мс могли дать два шага, когда между
записями состояния из-за отрисовки проходило 1039 мс. Теперь интервал
считается между действиями: первым ещё не записанным и последним уже
записанным. Порог 900 мс сохранён; ровно 900 мс и смена органа дают новый
шаг, пустой ввод не приклеивает позднюю правку. Добавлены 16 детерминированных
регрессий и повтор полного браузерного сценария истории. Расчётные формулы,
отображение графиков и формат сохранённого состояния не меняются.
