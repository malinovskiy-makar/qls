# Правила раздела «Олимпиады»

Локальные правила для `olympiads/`. Общие запреты — в корневом
[CLAUDE.md](../CLAUDE.md). Правила слоя модели — [problems/ai/CLAUDE.md](../problems/ai/CLAUDE.md).
Макеты экранов (утверждены владельцем 30.10) — `claude/night_olymp_20261030/mockups/`,
журнал ночи — `claude/night_olymp_20261030/JOURNAL.md`.

## Где считаются числа: `olympiads/navigator.py` (Э1, ADR 0173)

**Единственное место**, где считаются числа экранов раздела. Вьюхи и шаблоны
чисел не считают — берут готовые словари. Повод — карточка Notion «развести
число заданий у нас и числа тура»: два места счёта однажды разошлись.

- **Основной комплект** — `navigator.base_variants()`: опубликован
  (`visibility='published'`), не повтор (`duplicate_of` пусто, ADR 0171), не
  демонстрационный, есть в последнем пакете, олимпиада опубликована и не заглушка.
  Ни один экран не фильтрует комплекты сам.
- **Олимпиады раздела** — `visible_olympiads()`: `is_published` и не `is_placeholder`.
  Вернадский и две МОШ на макете есть — это решение на будущее, в базе они скрыты.
- **Сетка «сезон × класс»** — `stage_grid()`: колонки — классы из
  `OlympiadVariantGrade`; соседние классы одного комплекта — одна клетка с
  `colspan` и подписью «10–11 классы»; комплект без классов (ВсОШ 2016/17) —
  клетка на все колонки без подписи; сезон без комплектов внутри диапазона —
  строка `empty`; комплект без сезона — последняя строка «сезон не указан».
  Пересечение классов в строке → клетка на колонку, общий вариант в каждой.
- **Тур в клетке**: число позиций, максимум (`tour_max_score`: сумма баллов
  позиций, если балл есть у КАЖДОЙ, иначе максимум этапа), время (своё у
  комплекта или этапа), сколько с решением и с критериями, залитые PDF.
- **Состояние ученика**: `tour_state` / `cell_state` — по `TrainingAttempt`
  этого решающего (вошедший — по `user`, гость — `session_key` и `user` пусто).
  «1 тур из 2» — сдано не всё, «81 из 96» — сданы все туры клетки.
- **Плашка фактов**: «Заданий у нас» — различные задачи банка в позициях
  основных комплектов; сезоны — различные непустые; этапов — все этапы олимпиады;
  ближайший этап — `nearest_stage_event`.
- **Главная**: `home_rows()` (порядок — раздел, `-manual_rank`, название;
  раздел «Финансовая грамотность и Основы бизнеса» — список `FIN_SECTION`, а не
  `display_group`: Ломоносов в базе «смежный», а на макете — в основном списке),
  `upcoming()` — лента сезона, `continue_attempt()` — блок «Продолжить».

⚠️ **Дефекты данных экран не чинит.** В турах ВсОШ 2025/26 лежат и задания
чужого тура (по 8 позиций вместо 4, у «чужих» нет балла) — экран пишет «8
заданий». Чинит сессия чистки (карточка Notion про 719 задач и 11 пар туров).

Проверки: `olympiads/tests/test_night_E1.py` (фикстуры —
`olympiads/tests/night_fixtures.py`) и на настоящей базе ночи —
`claude/night_olymp_20261030/tools/real_db_checks.py` через `manage.py shell`.

## «Мои олимпиады»: `OlympiadFollow` (Э1)

Модель `OlympiadFollow(user, olympiad, created_at)`, пара уникальна. Адрес
`POST /olympiads/<slug>/follow/` (`action=remove` — убрать; заголовок
`X-Requested-With: fetch` — ответ JSON `{"followed": …}`), CSRF обязателен.
Гость в базу не пишет: его отправляют на вход с возвратом (`next`), чужой
`next` отбрасывается. Скрытую олимпиаду отметить нельзя — 404.

## Страница олимпиады (Э2): доски Main, Empty, MainPhone

- Шаблон `olympiads/detail.html` + партиалы `_grid_row.html` (строка сезона
  и панели её клеток), `_phone_row.html` (телефон: клетка выбранного класса),
  `_tour_panel.html` (панель туров), `_detail_js.html`, иконки `_ico.html`.
- Стили по макетам — `_screens_styles.html`, перенесены программно из
  `claude/night_olymp_20261030/mockups/olymp.css` под обёртку `.om` (старые
  экраны их не видят). ⚠️ Без тега `<style>`: `extra_style` базы сам внутри
  `<style>`. Свои цвета запрещены и здесь (`test_no_hex_colors`); исключение
  одно — белый фон QR (`white`), иначе код не сканируется в тёмной теме.
- Адрес: `?stage=<код>` — этап, `?open=<ключ клетки>` — раскрытая панель
  (работает без JS), `?all=1` — все сезоны, `?grade=<класс>` — вкладка
  телефона. Ключ клетки — `c<меньший pk комплекта клетки>`. Чужой ключ —
  ничего не раскрыто, не ошибка. Логика выбора — `navigator.page_view`.
- Телефон (≤ 720 px): таблица прячется, показывается список сезонов
  выбранного класса; общий вариант («10–11») — в обеих вкладках
  (`row.by_grade`). Порядок блоков как на MainPhone — CSS `order`,
  разметка одна. Кнопки и поля ≥ 44 px. Больше 5 классов (МОШ 3–11) —
  плотная клетка с числом без слова.
- PDF: наша копия, только если файл есть в хранилище, иначе страница
  источника (`navigator.tour_pdfs`). Кнопки «На время» / «Без времени» —
  на вход тура (`?mode=timed|free`), только у тура с позициями; «На время» —
  только при известном времени.
- Скрытая олимпиада и заглушка — 404.
- С прежней страницы ушли (на макете их нет): таблица «Ключевые даты»
  (даты — в блоке «Этапы»), панели «Что за задачи» (сложность/форматы),
  полная таблица льгот (вместо неё — «Что это даёт», до 4 примеров),
  кнопка «Регистрация», плашка «чисел нет» (демонстрационные комплекты в
  сетку не попадают). Список — в журнале ночи.

Проверка глазами: `node claude/night_olymp_20261030/tools/screens_probe.mjs E2
vseros=/olympiads/vseros/ …` (сервер ночи на 8097) — 1280/390 × светлая/тёмная,
вылезания, края, кнопки < 44 px, ошибки консоли; снимки в `shots/E2/`.

## Главная раздела (Э3): доски Home, HomePhone

- `list.html` + партиалы `_home_table.html` (таблица компьютера и список
  телефона), `_star.html` (звёздочка: вошедший — POST-форма, гость — ссылка
  на вход), `_feed_row.html` (строка ленты). Ширина 1200 — блок `main_class`
  `page-wrap om-wide`.
- Фильтры — GET: `kind=vsosh|perechen|international|other`,
  `grade=le7|8|9|10|11`, `tasks=1`, `mine=1` (только вошедший; у гостя
  игнорируется). Логика — `navigator.filter_rows` / `grade_matches`:
  «≤7» — `grade_min ≤ 7`; класс N — `grade_min ≤ N ≤ grade_max`; олимпиада
  без классов под фильтр класса не попадает.
- Порядок — раздел, `-manual_rank`. Раздел «Финансовая грамотность и Основы
  бизнеса» — `navigator.FIN_SECTION` (не `display_group`, см. Э1).
- Лента «Ближайшее» — `navigator.upcoming()` → `feed_rows`: 4 сразу, остальное
  в `<details>` «Ещё N событий сезона» (без JS). У события без даты слева «—»,
  ориентир — строкой под названием.
- «Продолжить» — `navigator.home_continue(user)`: последняя незаконченная
  попытка вошедшего (не истёкшая), сводка — та же `continue_cell`, что на
  странице олимпиады. «Мои олимпиады» — чипы по `OlympiadFollow`; нет — блока нет.
- Квадрат логотипа — `navigator.logo_text`: короткое название, если ≤ 5 знаков.

## Календарь (Э4): доска Calendar

- `calendar.html` + `_calendar_js.html`. Данные — `navigator.calendar_season(year,
  today, user, only_mine)`: дорожка на олимпиаду, сетка август…май (10 месяцев).
- Три вида полосы: `ok` — подтверждённая дата (сплошная); `est` — ориентир
  «по прошлому сезону» (пунктир); `rule` — «ждём объявления» с месяцем в
  ориентире (штриховка). ⚠️ Место неподтверждённого события на сетке берётся
  ТОЛЬКО из месяца, который назван в `approx_text` (`months_in_text`:
  «19 ноября» — точка, «в марте–апреле» — месяцы целиком). Месяца нет —
  строка «без даты: …» под дорожкой; числа не выдумываем.
- Регистрация «открылась + закрылась» с датами — одна полоса.
  Проверка: полос (по событиям) + строк «без даты» = событий сезона.
- Олимпиады: у гостя — с событиями сезона; у вошедшего — ещё и «мои»
  (дорожка «пока без дат»). `?mine=1` — только мои, `?season=` — сезон,
  `?q=` — поиск «Добавить олимпиаду» (POST на `follow` с `next` на календарь).
  Гостю поле поиска — ссылка на вход.
- Подписи полос не наезжают: JS разводит их по строкам и растит дорожку;
  ширина подписи — не больше места до правого края. Прибор считает
  пересечения `.om-bl` / `.om-today-l`.
- Телефон: сетка шириной 860 в горизонтальной прокрутке (`data-scroll`).

## Решение тура (Э5, ADR 0174): доски Intro, TakeTimed, TakeFree и телефонные

- Движок `training_engine.py` расширен, не переписан: задачи — из позиций
  пакета (`package_items`), время — `navigator.tour_minutes`, проверка одной
  задачи — `grade_item` (режим «Без времени»), `grade_attempt` не трогает уже
  сданные, итог — `recount`. Развёрнутое решение без краткого ответа —
  `is_pending`, не ноль.
- Адреса тура (`/olympiads/<slug>/variant/<pk>/…`): `''` вход, `start/`,
  `take/?task=<n>`, `autosave/`, `time/`, `item/` («Сдать задание»),
  `upload/` (листы, JSON при `X-Requested-With: fetch`), `sheet/<id>/` (файл —
  только хозяину попытки), `sheet/<id>/delete/`, `finish/`, `result/`.
- `training_take.html` подчинён `platform/exam.js` (те же id узлов —
  таймер, автосохранение, «Сдать тур»). «На время» — без шапки сайта: класс
  `om-take-body` на `<body>`, полоса тура с таймером и янтарной «Сдать тур».
  Вкладки заданий и Фото|Текст работают без JS (ссылки `?task=`, радиокнопки).
- Листы: `olympiads/uploads.py` — проверка `catalog.attachments.validate_upload`,
  EXIF снимается, ≤ 10 на задание; модель `TrainingUpload`; уборка гостей
  (`cleanup_training_attempts`) удаляет файлы.
- ⚠️ До сдачи нет ни разбора, ни ответа, ни критериев (`criteria.split_solution`
  вызывается только для сданного задания режима «Без времени»; шаблон рисует
  `_take_done.html` только у него). Обещание «проверяет ИИ» на входе — только
  при `OLYMPIAD_AI_CHECK` и критериях у заданий.
- Поля краткого ответа — только у задания с эталоном (`has_answer`).

## Фото с телефона по QR (Э6, ADR 0175): доски UploadB, UploadBPhone

- `olympiads/phone.py`: `issue` (пропуск на 30 минут, переиздаётся за 5 минут
  до конца), `state` (`ok` / `gone`), `qr_svg` (`segno`; нет библиотеки — '').
- Модель `PhoneUploadToken(attempt, problem, token, expires_at, created_at, used_at)`;
  `used_at` — «телефон подключён».
- Адреса: `/olympiads/u/<токен>/` — страница телефона (GET — листы, POST — файл);
  `/olympiads/u/<токен>/sheet/<id>/` — миниатюра; `…/variant/<pk>/sheets/?item=` —
  опрос компьютера (JSON: `closed`, `connected`, `token`, `qr`, `sheets`).
  Истёкший пропуск / сданная попытка — 410, чужой лист — 404.
- Файлы листов — только `olympiads/training_files.py` (сторож
  `problems/tests/test_media_route.py`).
- Проверка двух страниц: `node claude/night_olymp_20261030/tools/phone_flow.mjs
  '<путь задания>' --login-file=<логин:пароль>` (лист с телефона на компьютере
  ≤ 5 с, опрос стоп после сдачи, 410).

## ИИ-проверка по критериям жюри (Э7, ADR 0176)

- `olympiads/ai_check.py`: `parse_criteria` (критерии с баллами / правила /
  пункт), `plan` (точный или ориентировочный режим; `None` — критериев нет),
  `build_prompt` (только условие, критерии, правила, максимум, решение и
  расшифровка листов — без эталона и без профиля), `validate`, `eligible`
  (флаг, вошедший, согласие `ai`, не тест, есть критерии), `check_item`
  («Без времени»), `enqueue` + `run_next` («На время»), `by_part` (экран).
- Модель `TrainingCheck(attempt, problem, status: queued|running|done|error|
  unavailable, score, max_score, criteria, summary, transcription, approximate,
  provider, model, cost, human_review, created_at, finished_at)`.
- Флаг `OLYMPIAD_AI_CHECK` (`config/settings.py`, по умолчанию выключен; в
  `settings_olympiads_screens` включён). Выключен — 0 вызовов, после сдачи —
  разбор и критерии жюри. Потолок денег — `AI_DAILY_COST_CAPS['olympiad_check']`.
- Адрес очереди: `POST /olympiads/<slug>/variant/<pk>/check-next/` → `{total,
  done, finished}`; одно задание за запрос.
- Площадка ночи: ключей нет; сервер для снимков — `NIGHT_AI_PROVIDER=fake`
  и `QLS_FAKE_REPLY` из `claude/night_olymp_20261030/tools/fake_reply_59997.json`
  (подставной ответ подписан в `summary`).
