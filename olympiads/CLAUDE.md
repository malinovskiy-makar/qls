# Правила раздела «Олимпиады»

Локальные правила для `olympiads/`. Общие запреты — в корневом
[CLAUDE.md](../CLAUDE.md). Правила слоя модели — [problems/ai/CLAUDE.md](../problems/ai/CLAUDE.md).
Макеты экранов (утверждены владельцем 30.10) — `claude/night_olymp_20261030/mockups/`,

## Где считаются числа: `olympiads/navigator.py` (Э1, ADR 0173)

**Единственное место**, где считаются числа экранов раздела. Вьюхи и шаблоны
чисел не считают — берут готовые словари. Повод — карточка Notion «развести
число заданий у нас и числа тура»: два места счёта однажды разошлись.

- **Основной комплект** — `navigator.base_variants()`: опубликован
  (`visibility='published'`), не повтор (`duplicate_of` пусто, ADR 0171), не
  демонстрационный, есть в последнем пакете, олимпиада опубликована и не заглушка.
  Ни один экран не фильтрует комплекты сам.
- **Олимпиады раздела** — `visible_olympiads()`: `is_published` и не `is_placeholder`.
  Вернадский и две МОШ на макете есть — это решение на будущее, в базе они скрыты.
- **Сетка «сезон × класс»** — `stage_grid()`: колонки — классы из
  `OlympiadVariantGrade`; соседние классы одного комплекта — одна клетка с
  `colspan` и подписью «10–11 классы»; комплект без классов (ВсОШ 2016/17) —
  клетка на все колонки без подписи; сезон без комплектов внутри диапазона —
  строка `empty`; комплект без сезона — последняя строка «сезон не указан».
  Пересечение классов в строке → клетка на колонку, общий вариант в каждой.
- **Тур в клетке**: число позиций, максимум (`tour_max_score`: сумма баллов
  позиций, если балл есть у КАЖДОЙ, иначе максимум этапа), время (своё у
  комплекта или этапа), сколько с решением и с критериями, залитые PDF.
- **Состояние ученика**: `tour_state` / `cell_state` — по `TrainingAttempt`
  этого решающего (вошедший — по `user`, гость — `session_key` и `user` пусто).
  «1 тур из 2» — сдано не всё, «81 из 96» — сданы все туры клетки.
- **Плашка фактов**: «Заданий у нас» — различные задачи банка в позициях
  основных комплектов; сезоны — различные непустые; этапов — все этапы олимпиады;
  ближайший этап — `nearest_stage_event`.
- **Главная**: `home_rows()` (порядок — раздел, `-manual_rank`, название;
  раздел «Финансовая грамотность и Основы бизнеса» — список `FIN_SECTION`, а не
  `display_group`: Ломоносов в базе «смежный», а на макете — в основном списке),
  `upcoming()` — лента сезона, `continue_attempt()` — блок «Продолжить».

⚠️ **Дефекты данных экран не чинит.** В турах ВсОШ 2025/26 лежат и задания
чужого тура (по 8 позиций вместо 4, у «чужих» нет балла) — экран пишет «8
заданий». Чинит сессия чистки (карточка Notion про 719 задач и 11 пар туров).

Проверки: `olympiads/tests/test_night_E1.py` (фикстуры —
`olympiads/tests/night_fixtures.py`) и на настоящей базе ночи —
`claude/night_olymp_20261030/tools/real_db_checks.py` через `manage.py shell`.

## «Мои олимпиады»: `OlympiadFollow` (Э1)

Модель `OlympiadFollow(user, olympiad, created_at)`, пара уникальна. Адрес
`POST /olympiads/<slug>/follow/` (`action=remove` — убрать; заголовок
`X-Requested-With: fetch` — ответ JSON `{"followed": …}`), CSRF обязателен.
Гость в базу не пишет: его отправляют на вход с возвратом (`next`), чужой
`next` отбрасывается. Скрытую олимпиаду отметить нельзя — 404.

## Страница олимпиады (Э2): доски Main, Empty, MainPhone

- Шаблон `olympiads/detail.html` + партиалы `_grid_row.html` (строка сезона
  и панели её клеток), `_phone_row.html` (телефон: клетка выбранного класса),
  `_tour_panel.html` (панель туров), `_detail_js.html`, иконки `_ico.html`.
- Стили по макетам — `_screens_styles.html`, перенесены программно из
  `claude/night_olymp_20261030/mockups/olymp.css` под обёртку `.om` (старые
  экраны их не видят). ⚠️ Без тега `<style>`: `extra_style` базы сам внутри
  `<style>`. Свои цвета запрещены и здесь (`test_no_hex_colors`); исключение
  одно — белый фон QR (`white`), иначе код не сканируется в тёмной теме.
- Адрес: `?stage=<код>` — этап, `?open=<ключ клетки>` — раскрытая панель
  (работает без JS), `?all=1` — все сезоны, `?grade=<класс>` — вкладка
  телефона. Ключ клетки — `c<меньший pk комплекта клетки>`. Чужой ключ —
  ничего не раскрыто, не ошибка. Логика выбора — `navigator.page_view`.
- Телефон (≤ 720 px): таблица прячется, показывается список сезонов
  выбранного класса; общий вариант («10–11») — в обеих вкладках
  (`row.by_grade`). Порядок блоков как на MainPhone — CSS `order`,
  разметка одна. Кнопки и поля ≥ 44 px. Больше 5 классов (МОШ 3–11) —
  плотная клетка с числом без слова.
- PDF: наша копия, только если файл есть в хранилище, иначе страница
  источника (`navigator.tour_pdfs`). Кнопки «На время» / «Без времени» —
  на вход тура (`?mode=timed|free`), только у тура с позициями; «На время» —
  только при известном времени.
- Скрытая олимпиада и заглушка — 404.
- С прежней страницы ушли (на макете их нет): таблица «Ключевые даты»
  (даты — в блоке «Этапы»), панели «Что за задачи» (сложность/форматы),
  полная таблица льгот (вместо неё — «Что это даёт», до 4 примеров),
  кнопка «Регистрация», плашка «чисел нет» (демонстрационные комплекты в
  сетку не попадают). Список — в журнале ночи.

Проверка глазами: `node claude/night_olymp_20261030/tools/screens_probe.mjs E2
vseros=/olympiads/vseros/ …` (сервер ночи на 8097) — 1280/390 × светлая/тёмная,
вылезания, края, кнопки < 44 px, ошибки консоли; снимки в `shots/E2/`.
