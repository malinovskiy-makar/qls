## Р0.1 Файлы протокола кладём в git принудительно

**Решение.** `reports/calc2-canon/*` и `reports/calc2-audit.md` добавляются
через `git add -f`.
**Контекст.** `reports/` целиком в `.gitignore` (строка 34). Файл прогресса,
который живёт только на диске, теряется при `git clean` и не виден владельцу
в диффе.
**Почему так.** Работа объявлена возобновляемой: следующая сессия начинается
с чтения `PROGRESS.md`. Прецедент есть — под `reports/` уже принудительно
добавлен 21 файл (замеры BGE, превью генераторов, отчёты ВсОШ).
**Статус.** Действует.
**В Notion.** ✔ занесено

## Р0.2 Старый DESIGN.md заменён целиком, содержимое не переносилось

**Решение.** Прежний `DESIGN.md` (289 строк, формат Google Stitch с YAML-шапкой,
сгенерирован скиллом `impeccable`) заменён каноном целиком.
**Контекст.** Он описывает систему вокруг чернильно-синего `#4f7cff`; на живом
сайте этого цвета нет ни в одном месте.
**Почему так.** Решение владельца от 18.08.2026
(3c0b11c9-2bc1-814c-bfed-e68a441730b3), часть 5.3 канона.
**Побочное.** Формат Stitch с машиночитаемой YAML-шапкой потерян — если он
нужен скиллу `impeccable` или живой панели, шапку придётся отдать отдельным
файлом (`.impeccable/design.json`). Сейчас на неё в коде проекта никто
не ссылается — проверено `grep`.
**Статус.** Действует.
**В Notion.** ✔ занесено

**Решение.** Таблица пунктов ведётся в семи колонках вместо шести из промпта:

## Р2.1 Округление на экране — одно место; сумма считается из округлённых слагаемых

**Решение.** `roundShown` / `fmtSum` / `shownDiff` в `20-plane.js` рядом с `fmt`.
**Почему.** «SW = CS + PS» на экране не сходилось с двумя числами над ним:
сумма считалась по сырым float и округлялась отдельно.
**Границы.** Математика не тронута: `STATE.sw` остаётся точной суммой,
из округлённого собирается только ПОКАЗ.
**В Notion.** ✔ занесено

## Р2.2 Вход в любую модель обнуляет кривые

**Решение.** `pickScene` чистит `STATE.curves` перед маршрутом карточки.
**Почему.** 19 маршрутов из 41 зовут `loadScene` и чистят сами, остальные 22
только переключали режим. Замер: 22 сцены из 41 приходили с чужим содержимым.
**В Notion.** ✔ занесено

## Р2.3 Блок результатов молчит там, где его инструмент заперт

**Почему.** Второй список «сцен с налогом» разъехался бы с маршрутами.
