  письмо `code.html` — без doctype. Блок почты в `settings.py` переехал ниже: в «блоке LEGAL» тест

## Ручная проверка для Анича (по шагам)

Команды — в окне PowerShell в папке `C:\qls`. Каждую вставляйте целиком и ждите, пока закончится.

1. Запустить сайт: `venv313\Scripts\python.exe manage.py runserver`
   → строка `Starting development server at http://127.0.0.1:8000/`. Окно не закрывать: сюда
   будут печататься письма.
2. В браузере открыть http://127.0.0.1:8000/register/ → под логином поле «Почта», внизу галочка
   «Присылать письма о новых тренажёрах…» — **не отмечена**.
3. Заполнить логин, свою почту, пароль дважды, отметить согласие, нажать «Создать аккаунт»
   → экран «Подтвердите почту», кнопка «Отправить код ещё раз через 59 с» серая и отсчитывает.
4. В окне сервера найти строки «Код для регистрации на Weconomics:» и шесть цифр под ней.
5. Ввести неверные цифры → «Неверный код. Осталось попыток: 4.»
6. Нажать «Изменить почту» → форма заполнена (кроме пароля); ввести пароль дважды, отправить
   → снова экран кода (письмо то же: «Код уже отправлен, проверьте почту»).
7. Ввести верный код (можно с пробелом посередине) → профиль с плашкой «Заполните имя…».
   Во вкладке «Аккаунт»: «Почта — … подтверждена — Изменить», ниже карточка «Письма» с переключателем.
8. Щёлкнуть переключатель → он меняет положение. Нажать «Выйти».
9. http://127.0.0.1:8000/login/ → подпись «Логин или почта». Войти почтой, набранной БОЛЬШИМИ
   буквами, и паролем → вход.
10. Выйти. На входе «Забыли пароль? Восстановить по почте» → ввести почту → «Если эта почта
    привязана к аккаунту, мы отправили на неё код.» В окне сервера — «Код для смены пароля».
    Ввести код и новый пароль дважды → «Пароль изменён. Войдите с новым паролем.» → войти новым.
11. Войдя, открыть http://127.0.0.1:8000/account/email/?next=/vp/&src=vp → сменить почту на
    другую → код из окна сервера → откроется `/vp/`.
12. Старый аккаунт без почты (например, демо): в профиле плашка «Добавьте почту, по ней можно
    будет восстановить пароль.» и кнопка «Добавить почту».
13. Выключить почту: в файле `.env` строка `MAIL_ENABLED=0`, остановить сервер (Ctrl+C) и
    запустить снова → регистрация без поля «Почта», на входе «Логин» и «Напишите нам в Telegram»,
    `/password/forgot/` и `/account/email/` отвечают «Страница не найдена».
14. Снимки для Claude: регистрация (оба шага), сброс (оба шага), «Почта», профиль с плашкой и
