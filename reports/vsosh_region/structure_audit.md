# Аудит структуры ВсОШ-регион (таблицы, списки, рисунки)

Новый класс дефекта: **потерянная структура** — таблица/список размазаны в
строку текста. Формально текст «валиден» (глифы целы, KaTeX не ругается),
поэтому обычная вычитка на битые символы его не ловила.

Детектор: `manage.py audit_vsosh_structure` — геометрия PDF (горизонтальные
линейки одинаковой ширины/x-охвата очерчивают таблицу; ячейки держатся в
колонках по строкам — формула этот тест не проходит), атрибуция к вопросу по
маркеру, сверка с `parsed_<год>.json` (таблицы вне тест-вопросов — Часть 4,
сводные сетки ответов, бланки — отсеиваются).

### Списки

Маркированные списки (маркеры «•») найдены только в **2025 №3.2** (2 пункта —
описание шкалы НДФЛ). Проверка parsed: маркеры **сохранены** при разборе —
починка не требуется.

### Рисунки

Отдельным классом уже обработаны в предыдущей сессии (пометка «в оригинале
рисунок»): **2018 №18** [10,11], **2024 №2.2**. Новых графиков, нужных для
решения и не помеченных, детектор структуры не выявил.

### Таблицы ВНЕ тест-вопросов (не чиним — не импортируются)

Сводные сетки «Правильные ответы» (2021, конец файлов), бланки ответов и
образцы заполнения (2024), таблицы внутри задач **Части 4** (не тест: 2024
курсы обмена, 2025 вклады Ох-банка). Парсер до Части 4 не доходит, сетки —
стоп-секции; в импортируемые тест-вопросы они не попадают.

**Ограничение детектора:** таблицы распознаются по горизонтальным линейкам
(booktabs). Полностью безрамочные таблицы (без единой линейки) детектор бы
пропустил — но в корпусе ВсОШ все найденные таблицы имеют линейки, и обзор
геометрии других безрамочных сеток в тест-вопросах не обнаружил.
