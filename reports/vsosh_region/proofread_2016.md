## mechanical (2)

- №12 (multi): влипший кусок — весь блок «Комментарий» (4 нумерованных пояснения жюри) приклеен
  к тексту варианта 4. В parsed вариант 4 = «работник, трудившийся полный рабочий день, переведен
  на неполный день. Комментарий 1) Человек перестал быть занятым… 4) …Ничего не изменилось.»,
  а поле solution пустое. В PDF вариант 4 заканчивается словами «…переведен на неполный день.»,
  дальше идёт отдельный заголовок «Комментарий» и пояснения по пунктам (стр. 4–5). Пояснения нужно
  перенести из options[3] в solution. Сами маркеры (рамки у 1 и 3 → correct [0, 2]) верны.
- №15 (multi): развалившаяся формула в solution — в PDF аккуратная одиночная дробь
  «(αTR₀ − βTC₀) / (TR₀ − TC₀) = 0,9» (стр. 6), в parsed она разобрана на две рядом стоящие дроби
  «$\frac{\alpha TR_{0}}{TR_{0}} \frac{-\beta TC_{0}}{-TC_{0}} = 0{,}9$» — числитель и знаменатель
  перепутаны попарно, математически это уже не та формула (читается как α·β = 0,9). Остальной текст
  решения и следствие «$(\alpha -0{,}9)TR_{0} = (\beta -0{,}9)TC_{0}$» совпадают с PDF. Условие,
  варианты и маркеры (рамки у 2, 3, 4 → correct [1, 2, 3]) верны.

## answer_mismatch (0)

- booleans №1–5: Да/Нет-логика (риск–доходность; аккордный налог усиливает неравенство по Джини;
  корреляция ≠ причинность; скрытая безработица = формальная занятость; ставка ↑ → цены облигаций ↓) —

  QE = стимулирующая монетарная; min AVC = (0,5; 2; 7; 8) и только TC = q³−2q²+3q+10 даёт убыток

  оба завода не задействуются ни при каком Q. Ключи 1, 1, 2, 1, 3 (0-based) подтверждаю.
- multi №11–15: сравнительные преимущества есть при a < 2 и a > 2, нет при a = 2 → [0, 1];
  безработица растёт в случаях 1 и 3 → [0, 2]; лотерея с EV = 50 совместима с любым 0 < P < 100,
  невозможен только P > 100 → [0, 1, 2]; ресурсное проклятье — все четыре → [0, 1, 2, 3];
  прибыль −10 % возможна в сценариях 2, 3, 4 (проверил примерами (200;100;0,8;0,7), (…;1,05;1,2),
  (…;1,2;1,5)), сценарий 1 даёт разные знаки в тождестве → [1, 2, 3].
- numeric №16–20: 264/(1,1·1,2) = 200; продать лишние 50 шт. значит произвести 100 → 50p ≥ 300 →
