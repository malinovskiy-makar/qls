# Вычитка ВсОШ-регион 2016–2025 — сводный отчёт

Дата: 2026-07-13. Ветка `feat/vsosh-region-import`. **В базу ничего не
записывалось**, в `main` не пушилось. Все изменения — в коде парсера/фиксера
и в перегенерированных `parsed_<год>.json` + превью.

**Метод.** Каждый из 257 вопросов всех 10 годов вычитан агентом-вычитчиком:
(1) визуальная сверка разобранного текста с растеризованной страницей PDF
(глифы, потери, формулы, маркеры правильных ответов); (2) смысловое чтение +
самостоятельное перерешивание numeric/single/boolean/multi. Находки разложены
по корзинам **mechanical** (артефакт разбора — чинится парсером) /
**answer_mismatch** (решение расходится с ключом жюри — на суд преподавателя) /
**ok**. Затем механические классы починены централизованно в парсере, каждый —
одним правилом с прогоном по всем годам; правильные ответы **не изменились ни у
одного вопроса** (сверка по номер+классы против базы — 0 расхождений).
