# Старт проекта в Claude Code — Этап 1 (kickoff)

Этот файл — «инструкция запуска». Положи его в папку проекта рядом с
`model-dannyh-etap-0.md`. В нём: что мы решили, какой стек, что строим первым,
и готовый первый запрос для Claude Code.

---

## Решения, зафиксированные на старте

- **Решения задач — опционально.** Основное поле — ответ (как в задачнике Бахарева).
- **Только экономика.** Отдельной сущности «Предмет» не делаем; верхняя ось — Темы.
- **Пользователи на старте: преподаватель (ты) + ученики.** Ролей `teacher` и
  `student` достаточно. Остальные роли (editor/viewer/public) закладываем в схему,
  но интерфейс под них пока не делаем. Публичного доступа на старте нет.

---

## Технологический стек (рекомендация)

- **Язык:** Python — легко читать, пока учишься.
- **Фреймворк:** Django.
- **База данных:** SQLite на старте — это просто файл на твоём компьютере, настраивать
  ничего не надо. Позже, если будем выкладывать сайт в интернет, перейдём на PostgreSQL.
- **Почему Django:** встроенная админ-панель = готовый интерфейс для управления
  10 000 задач сразу, плюс встроенные логины и права. Это экономит недели работы.
  Красивый отдельный интерфейс для учеников при желании добавим позже — не сейчас.

---

## Что строим на Этапе 1 (только ядро)

Фундамент, который сразу видно в админке:

- **Модели:** Problem (со статусами), ProblemPart (подпункты а/б/в), Source +
  SourceReference, Topic/Subtopic, Tag, FileAsset, ProblemVersion, User с ролью
  (teacher / student).
- **Django admin включён** — ты сразу сможешь создавать, искать и редактировать
  задачи через интерфейс.
- **2–3 задачи-примера** из задачника Бахарева, забитые вручную, чтобы увидеть,
  что всё работает.

Импорт всех 10 000 задач, режим решения учеником, подсказки, домашки, похожие
задачи и т.д. — это следующие этапы. Сейчас не отвлекаемся на них.

## Как физически начать (по шагам)

1. **Установи Claude Code** (десктоп-приложение, самый дружелюбный вариант):
   https://docs.claude.com/en/docs/claude-code/overview
2. **Создай папку проекта**, например `olympiad-platform`.
3. **Положи в неё:**
   - распакованный архив с задачами (в подпапку `materials/`),
   - файл `model-dannyh-etap-0.md`,
   - этот файл.
4. **Открой Claude Code в этой папке** и отправь запрос выше.
5. Дальше Claude Code сам напишет код и проведёт тебя по запуску. Твоя задача —
   выполнять его шаги и говорить, что видишь.

Когда дойдём до загрузки всех 10 000 задач и до режима решения для учеников —
это будут отдельные этапы, и мы их так же разложим по шагам.
