{% comment %} Тест как игра (этап 7, ADR 0082; вид — README §5 «Стола», снимки 17–19). Варианты — плитки-кнопки с aria-pressed в белой карточке; проверка — всё или ничего через /catalog/api/test-check/; попытки не ограничены, число верных сообщается после двух неудач. Одна главная кнопка на состояние: пока не решён — «Проверить» (неактивна без выбора) · «попытка N» · справа текстом «Показать ответ»; после — «Дальше ›» · «Ещё тест по этой теме» · справа «Пройти заново». Ошибочный вариант одиночного теста краснеет («не то») и повторно не выбирается; при верном — зелёная «верно», выбранные раньше «вы выбирали», остальные бледнеют. Подсказки к тесту — в панели помощи (README §4). Правило нуля: строка игры только при game_stat, «Почему так» только при решении, «Ещё тест» только если другой тест по теме есть, «Дальше» — если есть следующая в ленте, «Спросить ИИ, почему так» — при чате и входе. {% endcomment %}
