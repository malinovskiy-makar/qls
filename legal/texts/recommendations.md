# Правила применения рекомендательных технологий

Редакция 1 от [ДАТА]

На сайте weconomics.ai применяются рекомендательные технологии — способы автоматически подбирать и упорядочивать материалы с учётом сведений о пользователе. Правила опубликованы в соответствии со статьёй 10.2-2 Федерального закона от 27.07.2006 № 149-ФЗ.

Владелец сайта — Ленглер Андрей Викторович, ИНН 662333547172. Почта для обращений: [ПОЧТА].

## 1. Где они применяются

- **Поиск по банку задач.** Задачи упорядочиваются по близости к тексту запроса: по совпадению слов, по смыслу и, при умном поиске, моделью искусственного интеллекта.
- **Блок «Похожие задачи».** Подбирает задачи, близкие по содержанию к открытой.
- **Игра Wecon Rush и тренажёры.** Вопросы выбираются с учётом выбранных фильтров и того, какие вопросы уже были показаны.
- **Статистика и прогресс.** Показывают темы, в которых у пользователя меньше решённых задач.

## 2. Какие сведения используются

- текст поискового запроса;
- какая задача открыта, её тема, теги и сложность;
- выбранные фильтры;
- какие задачи и вопросы пользователь уже открывал и решал и с каким результатом.

## 3. Какие сведения не используются

Имя, почта, школа, город, изображение профиля, IP-адрес, сведения о местоположении, данные с других сайтов, специальные категории персональных данных и биометрические данные.

## 4. Как это работает

Для каждой задачи банка заранее рассчитано числовое описание её содержания. При поиске такое же описание рассчитывается для запроса, и задачи выстраиваются по близости к нему. При умном поиске текст запроса и краткие описания найденных задач дополнительно передаются модели искусственного интеллекта сервиса Z.ai (Сингапур), которая уточняет порядок; сведения о пользователе при этом не передаются. Блок «Похожие задачи» строится тем же сравнением описаний задач между собой и от действий пользователя не зависит.

## 5. Как не пользоваться рекомендациями

Задачи можно находить без автоматического подбора: через каталог с фильтрами по теме, тегам, источнику и сложности и через карту тем. Умный поиск можно не включать.
