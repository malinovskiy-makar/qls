Анализ рынка
Перетаскивайте точку вдоль спроса (роль D). Ed = P/(Q·dP/dQ). Единичная точка (|Ed|=1) — там, где MR = 0 и выручка TR = P·Q максимальна: левее спрос эластичный, правее — неэластичный.
Сдвиг по вертикали (свободный член кривой): + вверх, − вниз. Разложение показывает вклад спроса (E₀→E_d), предложения (E₀→E_s) и итог (E₀→E₁).
Спрос = общественная выгода MSB, предложение (роль S) = частные издержки MPC. MSC = MPC + внешние. Рынок выпускает Qрын (D = MPC), оптимум Qопт (D = MSC). Налог Пигу поднимает MPC до MSC — рынок приходит в Qопт.
Вмешательство государства
Потоварное вмешательство на стороне производителя: кривая S сдвигается (налог — вверх, субсидия — вниз) на величину ставки. Клин между ценами покупателя и продавца можно тянуть мышью.
Государство фиксирует цену. Потолок ниже равновесия даёт дефицит (продаётся меньше), пол выше равновесия — избыток. Линию цены можно тянуть мышью.
Рынок
Монополист выпускает там, где MR = MC, и берёт цену с кривой спроса (выше предельных издержек). Нужны: спрос (роль D) и предельные издержки (роль MC, либо TC, либо S как MC). Серым — потери общества (DWL) против конкуренции.
Совершенная (1-й степени) дискриминация: монополист продаёт каждую единицу по её цене спроса до точки, где спрос = MC. Весь излишек достаётся фирме: CS = 0, DWL = 0, выпуск = конкурентному. Нужны: спрос (роль D) и предельные издержки (роль MC / S / TC) в списке кривых.
Фирма распределяет выпуск так, что MR₁ = MR₂ = MC. На менее эластичном рынке цена выше. Два мини-графика рынков — бок о бок.
Рыночный спрос = горизонтальная сумма (при каждой цене складываем объёмы). Изломы — там, где очередной потребитель выходит на рынок.
Излом Q — точка стыка кусков (их пересечение). До излома — f₁, после — f₂.
MR на каждом куске — своя прямая (вдвое круче спроса), в изломах MR разрывается вниз. Оптимум выбирается по максимуму прибыли среди кандидатов (пересечения MR = MC и сами изломы), а не по первому пересечению.
Потолок ниже монопольной цены делает MR горизонтальным (= Pc) до пересечения со спросом — это «ломаный MR». Правильный потолок увеличивает выпуск (вплоть до конкурентного); слишком низкий (ниже MC) — даёт дефицит. Линию можно тянуть мышью.
Издержки фирмы
VC = TC − FC, ATC = TC/Q, AVC = VC/Q, AFC = FC/Q, MC = dTC/dQ. MC проходит через минимумы ATC и AVC.
Рынок труда
Спрос на труд (роль D) — это MRPL; предложение труда (роль S). Оси: L (труд) и W (зарплата). Формулы можно писать через L: 100 - L, L.
Профсоюз продаёт труд монопольно: его предельный доход MRL лежит ниже спроса D, предельные издержки — кривая предложения S. Занятость Lп там, где MRL = S; зарплата Wп берётся с кривой спроса (выше конкурентной). Зеркало монопсонии.
Профсоюз диктует зарплату выше конкурентной: занятость падает по кривой СПРОСА (Lп, где D = W), возникает безработица (желающие по предложению минус занятые). Это ценовой пол на рынке труда. Линию можно тянуть мышью.
В монопсонии правильный МРОТ может УВЕЛИЧИТЬ занятость (парадокс): он делает предельные издержки труда горизонтальными (= W_min) до встречи с предложением. В конкуренции МРОТ выше равновесия даёт безработицу. Линию можно тянуть мышью.
Неравенство доходов
Группы переставлены по возрастанию дохода — кривая Лоренца всегда идёт от бедных к богатым.
Доля дохода каждой группы, в %. Сумма нормируется до 100%. Узлы кривой можно тянуть мышью.
Доходы переставлены по возрастанию — кривая Лоренца всегда идёт от бедных к богатым.
Каждое число — доход одного человека. Сортируются по возрастанию, строятся накопленные доли. Узлы кривой можно тянуть мышью.
Должно быть L(0)=0, L(1)=1, неубывающая и выпуклая. Примеры: p^2, p^3, p^1.5.
Налог: доля каждой группы подтягивается к равной (1/N): новая = (1−τ)·старая + τ·(1/N), при τ=1 — полное равенство. Трансферт: T% общего дохода забирается у богатейшей группы и делится поровну между всеми.
КПВ — производственные возможности
По осям — два товара: X (горизонталь), Y (вертикаль). Точку на кривой можно тянуть мышью. Наклон |dY/dX| — альтернативные издержки X (в единицах Y).
Совместная КПВ двух стран: при каждом выпуске X производство делится так, чтобы суммарный Y был максимален (X наращивает страна с меньшими альтернативными издержками X). Это НЕ вертикальная сумма кривых.
КТВ — граница потребления при торговле по мировой цене. Линейная КПВ → полная специализация (угол). Нелинейная → точка касания, где |наклон КПВ| = Px/Py. Линия КТВ лежит выше КПВ — это выигрыш от торговли.
Линейные КПВ. Автарктическая цена X каждой страны — наклон её КПВ. Мировая цена Pw устанавливается МЕЖДУ автарктическими (эндогенно). Страна с меньшими альт. издержками X специализируется на X и экспортирует его; другая — на Y. Линии торговых возможностей обеих стран лежат вне их КПВ (выигрыш от торговли).
