ЧТО СТАВИТЬ НА WINDOWS
======================
Python 3.11.9 с python.org (НЕ из Microsoft Store).
Почему 3.11, а не 3.9: на 3.9 проект работает у Макара, но под Windows
для Python 3.9 многие библиотеки давно не выпускают готовых сборок.
На Python 3.11 уже работает боевой сервер проекта — версия проверена.
Код специально написан без синтаксиса, который появился после 3.9,
поэтому на 3.11 он идёт без правок.

Обязательно: переменная окружения PYTHONUTF8=1 (см. READ_ME_FIRST.md,
раздел «Известные грабли на Windows»).
