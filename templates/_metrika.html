{% comment %} Яндекс Метрика (ADR 0133): счётчик, цель регистрации и просмотр при смене экрана без перезагрузки. Стоит в КАЖДОГО корневого шаблона сайта; его пара `_metrika_noscript.html` — первой строкой . Номер — настройка YANDEX_METRIKA_ID через `config.context_processors.metrika`. Пусто (локально, площадка dev, тесты) — не выводится ничего. ⚠️ СЧЁТЧИК ТОЛЬКО ПО СОГЛАСИЮ (часть Б, 09.10.2026, Политика cookie, раздел 2): скрипт попадает в страницу, лишь когда кука `weco_consent` равна `all` (`analytics_allowed` из `config.context_processors.cookie_consent`). Без неё в HTML нет ни одного вхождения `mc.yandex.ru`; нажатие «Разрешить» подгружает тот же код файлом `/legal/metrika.js` (окно cookie, `static/cookie_bar.js`). Отложенная цель регистрации ЧИТАЕТСЯ ВСЕГДА, а без согласия просто пропадает: оставленная в сессии, она выстрелила бы позже, когда человек её не ждёт. Код загрузки — из справки Метрики («Инициализация счетчика»). Параметры — значения по умолчанию, выписанные явно, как их выписывает интерфейс Метрики. ⚠️ `metrika_private` передают кабинеты (репетитор, ученик, профиль и родитель, календарь, печатный листок). На их страницах два отличия: - `webvisor: false` — Вебвизор пишет ТОЛЬКО публичные страницы И ТОЛЬКО гостей (решение владельца 08.10.2026, закрывает открытый вопрос ADR 0133; вошедший не записывается нигде, в том числе на странице задачи с чатом ИИ). В кабинете на экране имена и оценки школьников, а запись — это копия экрана целиком. Карта кликов, ссылки и отказы остаются: копии экрана в них нет; - `sendTitle: false` — в заголовках страниц кабинета тоже стоят имена детей, а Метрика по умолчанию пишет заголовок каждой страницы. Справка Метрики сама велит в таком случае `sendTitle: false`. На публичных страницах Вебвизор включён, но имя вошедшего в общей шапке (`_nav.html`, блок `.nav-user`) помечено классом `ym-hide-content` — запись показывает на его месте размытый набор символов. ⚠️ `metrika_goal` — ФУНКЦИЯ: она ЗАБИРАЕТ цель из сессии. Поэтому читается ровно один раз, через `with`, — так цель и срабатывает один раз на аккаунт. Скрипт вдобавок помнит метку цели в localStorage: страницу, открытую снова из кэша кнопкой «Назад», браузер исполнит заново, а второй цели быть не должно. ⚠️ `weco.metrikaHit` зовёт `static/track.js` из `trackPage()` — в той же точке «экран сменился без перезагрузки», что и своя аналитика беты («Стол», карта тем, «назад» по ним). Смена адреса через replaceState (фильтры, период статистики, чистка `?mode=`) просмотром НЕ считается: это тот же экран. По справке тег сам History API не отслеживает — для таких сайтов она велит звать `hit` вручную. {% endcomment %}{% if metrika_id %}{% with goal=metrika_goal %}{% if analytics_allowed %}{% endif %}{% endwith %}{% endif %}
