{% comment %} Число, которое правится без поля ввода (`.k-num`). ОДИН скрипт на кабинет: подключён в трёх базовых шаблонах рядом с подсказками и краями прокрутки. ⚠️ РАБОТАЕТ ЧЕРЕЗ ДЕЛЕГИРОВАНИЕ. Числа приезжают и разметкой сервера, и скриптами шагов (состав, «Что нашлось», пункты своей задачи): навешивать слушатели на найденные при загрузке поля значило бы, что половина чисел на странице ведёт себя иначе, чем вторая. ⚠️ СТРЕЛКИ ↑/↓ СЧИТАЕТ СКРИПТ, А НЕ БРАУЗЕР. Часть чисел кабинета — текстовые поля с `inputmode="decimal"`: при русской локали Django печатает «1,5», а `input[type=number]` считает запятую недопустимой и стирает собственное начальное значение (сессия 9). Родные стрелки есть только у `type=number`, то есть у половины полей, — поэтому шаг везде наш. ⚠️ ENTER НЕ ПЕРЕХВАТЫВАЕТСЯ. «Применить» для настоящего поля означает только «отменить больше нельзя»: значение и так уже в поле. Гасить Enter значило бы поменять поведение форм проверки, где им сохраняют оценку, — а эта сессия функцию не трогает. Escape возвращает значение, каким оно было в момент прихода фокуса. {% endcomment %}
