# Данные для подсказок онбординга «Где вы учитесь?»

Подсказки работают без внешних сервисов: всё лежит у нас (`problems/school_search.py`).

## `cities_ru.json` — города России

* **Источник:** набор «Города России» HFLabs — https://github.com/hflabs/city
  (файл `city.csv`, ветка `master`, скачан 30.10.2026). Данные, кроме населения,
  получены HFLabs из DaData.ru; население — как в Википедии.
* **Лицензия:** Creative Commons Attribution-ShareAlike 4.0 International
  (https://creativecommons.org/licenses/by-sa/4.0/).
  **Указание авторства:** «Города России» © HFLabs, CC BY-SA 4.0.
* **Что изменено** (производный набор под той же лицензией CC BY-SA 4.0): оставлены
  три поля — `name` (город), `region` (регион словами: «Свердловская область»,
  «Республика Татарстан», «Москва»), `population`; список отсортирован по населению;
  восемь кривых названий регионов приведены к обычному виду. 1 116 городов.
* Код сайта лицензией CC BY-SA не затронут: она относится только к этому файлу.

Пересобрать: скачать `city.csv` и прогнать сборку из журнала
`reports/login_onboarding_20261029/JOURNAL.md` (раунд 2, фаза 4).

## Школы — таблица `School`: реестр Рособрнадзора (`sync_schools`) и CSV (`load_schools`)

Сам реестр в репозиторий **не кладётся** (он большой). Подсказки школ (раунд 3: по всей
стране, школы города из поля «Город» — первыми) берутся:
1. из таблицы `School` — заливается из реестра Рособрнадзора (ниже) или из своего CSV;
2. из названий, которые уже ввели ученики этого города — только если одно и то же
   название ввели хотя бы трое других людей, не считая спрашивающего
   (`school_search.MIN_PEOPLE`): иначе свой профиль работал бы «подсказкой».

### Реестр аккредитованных организаций (основной источник, 29.10.2026)

- **Что:** открытые данные Рособрнадзора, набор `7701537808-RAOO`, страница
  https://isga.obrnadzor.gov.ru/accredreestr/opendata/ (обновляется ежедневно).
- **Скачать:** постоянная ссылка на свежий архив
  `https://isga.obrnadzor.gov.ru/api/spa/accredreestr/opendata/filezip` — ZIP ≈ 350 МБ
  (`data-YYYYMMDD-structure-20160713.zip`: XML ≈ 1 ГБ + файл подписи). Описание полей —
  например https://isga.obrnadzor.gov.ru/xml/data-20160908-structure-20160713.xml.
- **Лицензия:** открытые данные государственного органа (портал открытых данных
  Рособрнадзора), свободное использование с указанием источника.
- **Что берём:** организации, у которых в ДЕЙСТВУЮЩЕМ свидетельстве есть ДЕЙСТВУЮЩЕЕ
  приложение с программой «… общее образование» (начальное, основное, среднее);
  филиалы — отдельными школами со своим адресом. Поля: полное и короткое название
  (короткое приводится к виду «Школа № 57»: без «ГБОУ», кавычек и хвоста «г. Москвы»),
  номер, город из почтового адреса, регион, ИНН/КПП, идентификатор в реестре.
  **ФИО директоров, телефоны и почты не читаем и не храним.**
- **Числа (выгрузка от 29.10.2026):** 42 025 школ (3 792 филиала), Москва — 759,
  Санкт-Петербург — 773, без города — 0,79 %. Поля `KindName`/`TypeName` в выгрузке
  пусты у всех организаций.

```bash
python manage.py sync_schools                       # сам скачает свежий архив и обновит
python manage.py sync_schools --dry-run             # то же, ничего не пишет
python manage.py load_schools --format raoo F.zip   # готовый файл, сухой прогон
python manage.py load_schools --format raoo F.zip --apply
```

Оба пути — один разборщик (`problems/school_registry.py`) и один движок
(`problems/school_sync.py`): идемпотентно, исчезнувшие школы выключаются
(`is_active=False`), а не удаляются. На бою — раз в неделю таймером, `docs/SERVER.md`,
«Справочник школ».

### Свой CSV (`load_schools` без `--format`)

CSV в UTF-8 с заголовком. Обязательны `name`, `city`; по желанию `short_name`,
`number`, `kind` (например «ГБОУ»), `region`. Номер, если колонки нет, команда берёт из
названия («Школа № 57» → 57).

```bash
python manage.py load_schools schools.csv            # сухой прогон: только счётчики
python manage.py load_schools schools.csv --apply    # записать
```

Идемпотентно: ключ строки — (название, город, регион); строки реестра не трогает. На бою —
из `/srv/weconomics/app/deploy`:
`docker compose exec web python manage.py load_schools /path/schools.csv --apply`
(файл положить в смонтированную папку, см. `docs/SERVER.md`).
