Создание работы: три экрана — один поток

Сейчас три способа живут по разным правилам: у одного есть конструктор с баллами и порядком, у другого корзина без баллов, третий вообще форма, после которой теряется занятие. Предлагаю оставить три способа, но сделать их вкладками первого шага, а конструктор и выдачу — общими для всех.

Что происходит сейчас

«Описать словами» → отдельный экран → конструктор подборки с баллами. «Искать самому» → свой экран, корзина без баллов → работа создаётся сразу, состав никто не видел. «Написать свою» → форма → возврат без занятия, галочка «Кому выдать» сбрасывается. Настройки работы висят справа с самого начала, хотя нужны в конце.

Шаг 1 из 3

Что кладём — три способа как вкладки, не как три экрана

Способ выбирается внутри шага и переключается свободно: часть задач из каталога, часть по описанию, одну написали сами. Корзина общая, она внизу и всегда на виду.

Шаг 2 из 3

Состав — то же самое для всех трёх способов

Тот конструктор, который сейчас есть только у пути «описать словами». Порядок, баллы, раскрытие задачи целиком и два предпросмотра — вот что репетитор должен увидеть до того, как работа уйдёт ученику.

Шаг 3 из 3

Выдача — настройки в конце, рядом с тем, что получит ученик

Название, срок и «кому» нужны один раз и в конце. Справа — лист, который уйдёт ученику, чтобы кнопка «Выдать» нажималась не вслепую.

Что это чинит попутно

Пять нынешних болячек уходят сами

Корзина одна на все способы — не теряется при переключении. Занятие живёт в адресе всех трёх шагов — крошка и «кому выдать» не сбрасываются после создания своей задачи. Состав виден до выдачи — работа не уходит вслепую. Баллы задаются в одном месте, а не в двух разных. Настройки не занимают правую треть экрана с самого начала — там, где нужен каталог.
