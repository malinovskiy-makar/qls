## Принято без вопроса владельцу
1. **Сервер приборов запускается из `.claude/launch.json`**, а не скриптом `reports/calc2_redesign/serve.sh`:
   правило среды требует поднимать серверы через панель предпросмотра. Скрипт из панели не запускается (macOS не
   даёт процессу панели читать файл в «Загрузках»), поэтому добавлена конфигурация `calc2-tex` с тем же содержимым
   (`venv313/bin/python manage.py runserver 8099 --noreload --settings=config.settings_check`). Файл
   `.claude/launch.json` в git не добавляется и в конце работы возвращается к прежнему виду. Старый сервер на 8099
   (запущен 06.10, до последних коммитов редизайна) остановлен: ловушка «сервер прошлой версии».
2. **`scripts/ensure_probe_users.py` по ошибке запущен один раз с базой владельца** (`db.sqlite3`, вызов с
   `--help`, которого скрипт не понимает). Боты там уже были, скрипт только заново поставил им тот же пароль и ту
   же роль; других записей он не трогает. Затем запущен как надо — с `DJANGO_SETTINGS_MODULE=config.settings_check`.
3. **Список задач инструментом задач не ведётся**: такого инструмента в этой сессии нет. Ход работы — в этом журнале
   (таблица фаз) и в коммитах.
4. **Второй сервер нетронутого кода** для повторного замера прототипа и зубастости приборов фазы 0, чтобы не ждать
   их с правками сайта: `git worktree` `../qls_platform_tex0` на `e165aff` (отделённая голова, ветки нет), ссылки на
   `db_check.sqlite3` и `node_modules` основной папки, конфигурация `calc2-tex-base` (порт 8094). На 8096–8098 висят
   серверы прошлой сессии редизайна (05.10) — не мои, не трогал. Рабочую копию `../qls_platform_tex0` убрать в конце
   (`git worktree remove`).
5. **Сборка `pdflatex` в приборах идёт в окружении сервера** (`compile.py`, `labels.py`: только `PATH` и запреты
   `openin_any=p`, `openout_any=p`, `shell_escape=f`, без домашней папки — как `compile_pdf_pdflatex` в
   `calc2/views.py`). Причина: в обычной оболочке TeX сам дорисовывает недостающие шрифты в `~/Library/texlive`
   (`mktextfm`), а сервер их не видит. Замер: кириллица в индексе через `\text{}` (`$33{,}33_{\text{м}}$`) требует
   T2A в 5 pt, которого в TeX Live нет готовым; через сайт PDF «Двусторонней монополии» падал с 500, а в оболочке
   собирался. Прототип в таком окружении: 39 из 44 стартов (не собираются `ext`, `labor`, `labor-bilat`,
   `labor-union`, `quota`). Новая выгрузка выносит кириллицу из математики (`$33{,}33$\textsubscript{м}`), проверка
   текста (`lint.mjs`) ловит `\text{кириллица}`. Отступление от таблицы SPEC, раздел 7 (`$35_{\text{спрос}}$`) —
   ради Т1 («собирается в любом состоянии»).
6. **Поля холста на листе считает свой замерщик подписей.** Экранный `measureText` (20-plane.js) при «меньше
   движения» читает кегль с отставанием: у `* { transition-duration: .01ms }` по умолчанию `transition-property: all`,
   и переход `font-size` замерщика не успевает до замера («100» мерится 12-м кеглем вместо 10-го, поле 60 вместо 56).
   Прототип давал поэтому разный файл при обычных переходах и при «меньше движения» (пятый вариант `stable.mjs`).
   На прогоне `measureText` получает свой элемент без переходов, экранный не трогается (иначе после выгрузки экран
   сдвигался на 4 px). Экранную особенность не чинил — в отчёт.
7. **Гашение переходов — только на `#chart`**, а не на всём `#graph-wrap`: снятие перехода на экранном замерщике
   завершало его, и поля экрана после выгрузки менялись (замер: «Налоги», 60 → 56).
8. **Счётчики окна «Скачать» и сборки доступны тестам** (`buildTex._tally`, `buildTex._stats`): «Кривых», «Областей»,
   «Точек», «Линий», «Подписей» — по нарисованным предметам (у кривой с кусками строк в файле несколько, предмет один).
9. **`buildTex` всегда зовёт новый конвейер**, переключатель `?texState=1` больше ничего не включает (функция
   `texWantState` и старые сборщики лежат в коде до фазы 4 только для сравнения).
