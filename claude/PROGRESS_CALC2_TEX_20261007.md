## Принято без вопроса владельцу
1. **Сервер приборов запускается из `.claude/launch.json`**, а не скриптом `reports/calc2_redesign/serve.sh`:
   правило среды требует поднимать серверы через панель предпросмотра. Скрипт из панели не запускается (macOS не
   даёт процессу панели читать файл в «Загрузках»), поэтому добавлена конфигурация `calc2-tex` с тем же содержимым
   (`venv313/bin/python manage.py runserver 8099 --noreload --settings=config.settings_check`). Файл
   `.claude/launch.json` в git не добавляется и в конце работы возвращается к прежнему виду. Старый сервер на 8099
   (запущен 06.10, до последних коммитов редизайна) остановлен: ловушка «сервер прошлой версии».
2. **`scripts/ensure_probe_users.py` по ошибке запущен один раз с базой владельца** (`db.sqlite3`, вызов с
   `--help`, которого скрипт не понимает). Боты там уже были, скрипт только заново поставил им тот же пароль и ту
   же роль; других записей он не трогает. Затем запущен как надо — с `DJANGO_SETTINGS_MODULE=config.settings_check`.
3. **Список задач инструментом задач не ведётся**: такого инструмента в этой сессии нет. Ход работы — в этом журнале
   (таблица фаз) и в коммитах.
