## Эталоны, которые пришлось переписать (и почему)

- `redesign/answer_baseline_20261009.json` — `smallopen`, `labor`, `labor-mono`, `ext`, `quota` (скрипт
  `rewrite_answer_baseline.mjs`, закрытый список). Причина: старт «Ответа» этих моделей сменили решения сессии —
  главные строки по состоянию (старт труда уже с МРОТ 45), старт «Внешних эффектов», цена квоты по умолчанию.

  `qt`, `quotaPos` и `start.answer` (скрипт `rewrite_start_baselines.mjs`: поле вне своей модели — останов).
  Других моделей не тронуто ни одного поля: `quotaPos` = 0,5 остаётся у всех остальных стартов
  (`loadScene` сбрасывает его, цена спроса ставится маршрутом «Квот» и `setType('quota')`).
- `redesign/PARITY.md` — строки раздела 2 у `ext` и `quota` (пересобраны `parity.mjs` и вставлены точечно: полная
  пересборка стёрла бы ручные разделы сессий 6–7).
- `previews.json` — `ext` (видна MSC) и `quota` (цена 60): `make_previews.mjs`, остальные 40 моделей побайтно прежние.
- Приборы с прежним стартом «Внешних эффектов» (MSC выключена): `calc2_math.mjs` случай (л) переписан на новый старт,
  положительный случай MSB = 120 − Q в `calc2_math.mjs` и `control_numbers.mjs` гасит MSC сам (числа ожиданий прежние).
