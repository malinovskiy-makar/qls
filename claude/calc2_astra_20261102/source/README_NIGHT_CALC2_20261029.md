# Ночь 29→30.10 · «Графики» — как запустить на Маке

Одна сессия Claude Code делает 13 этапов подряд. Её держит команда `/goal`: после каждого хода отдельная модель проверяет, выполнена ли цель, и если нет — сессия работает дальше сама.

**Порядок этапов:**
1. Б (вид);
2. А3 (расчёты и края);
3. «Числа»;
4. новые функции от мелких к крупным: два инструмента, дискриминация 3°, заводы, неравенство, IS–LM, AD–AS, функция предложения, «Рынок и фирма в СК», дерево торговли, большие экономики.

## Вечером

### 1. Скачать три файла из чата
Они лягут в «Загрузки»:
- `NIGHT_CALC2_20261029.md`;
- `CALC2_FEATURES_SPEC_20261024.md`;
- `CALC2_FEATURES_SPEC_PART2_20261029.md`.

### 2. Остановить лишнее
- Локальный сайт: Ctrl+C в его окне.
- Другие окна Claude Code в `qls_platform`: закрыть.

### 3. Положить файлы в проект
Открой Терминал и вставь одну строку:
```
cd ~/Downloads/qls_platform && mkdir -p claude/night_calc2_20261029 && for f in NIGHT_CALC2_20261029 CALC2_FEATURES_SPEC_20261024 CALC2_FEATURES_SPEC_PART2_20261029; do cp "$(ls -t ~/Downloads/$f*.md | head -1)" claude/night_calc2_20261029/$f.md; done && ls claude/night_calc2_20261029
```
Должны напечататься три имени файла. Если Safari сохранил копию как «… 2.md», строка сама возьмёт самую новую.

### 4. Обновить Claude Code
```
claude update
```

### 5. Запустить
```
caffeinate -dimsu -t 50400 & claude --permission-mode auto --model opus
```
- `caffeinate` не даёт Маку уснуть 14 часов.
- Если Claude Code спросит, доверяешь ли папке, — ответь «да». Без этого `/goal` не работает.

### 6. В окне Claude Code
1. Набери `/effort high` и нажми Enter.
2. Вставь строку цели целиком и нажми Enter:

```
/goal Выполни ночной план из файла claude/night_calc2_20261029/NIGHT_CALC2_20261029.md: прочитай его целиком и работай строго по нему; после каждого сжатия контекста перечитывай его и журнал claude/night_calc2_20261029/JOURNAL.md. Цель достигнута, когда в разговоре выведена итоговая таблица журнала, где у каждого из этапов Э1–Э13 статус «сделан» (коммит есть, итоги приборов этапа выведены в разговор и зелёные), «откатан» или «пропущен» с причиной, и выполнен раздел «Финал» плана — отчёт выведен в разговор. Цель также достигнута, если фаза −1 плана остановила ночь и причина выведена в разговор, или если со времени старта в первой строке журнала прошло 11 часов и «Финал» выполнен по сделанному. Нельзя: git push, слияние в main, правка db.sqlite3, вопросы владельцу. В конце каждого хода выводи таблицу этапов и время с начала ночи.
```

### 7. Проверить, что пошло
- Внизу окна видно `auto mode on` и `◎ /goal active`.
- Через 5–10 минут в Notion, в «Задачах», появится карточка «Ночь 29→30.10 · Графики».

### 8. На ночь
- Зарядка подключена.
- Крышка открыта.
- Терминал не закрывать.

## Утром

1. **Отчёт** — последнее сообщение в окне. Пришли его мне целиком. Можно вместо него файл `claude/night_calc2_20261029/JOURNAL.md`.
2. **Если в окне «Goal paused» или сообщение о лимите** — напиши в том же окне «продолжай». Цель продолжит работу.
3. **Если ночь не успела все этапы** — следующей ночью повтори шаги 4–6. Файлы уже на месте, строка цели та же: сессия продолжит с журнала.
4. **Пуш** — сессия не пушит. Команда будет в отчёте. Пушим после того, как разберём отчёт; в `main` ничего не идёт.

## Честно

- **13 этапов — много.** Я жду 6–9 за ночь. Остальное доделает следующая ночь тем же запуском.
- **Max 20x.** Одной сессии Opus на ночь обычно хватает. Если упрётся в пятичасовой лимит, цель встанет на паузу до утра — пункт 2.
- **Режим auto сам по себе разрешает push.** Его запрещают план и строка цели. Утром в отчёте будет список коммитов: по нему видно, что ушло, а что нет.
