## Сохранность

Этапные комплекты:
`/Users/makarmalinovskiy/Documents/ChatGPT/Weconomics/calc2-astra-checkpoints`.
Каждый содержит bundle, документы, логи/снимки этапа и SHA256_MANIFEST.json.
Этапные bundle требуют исходный A2. Комплект `final-<SHA>` содержит полную
историю HEAD и восстанавливается без прежнего репозитория. Он создаётся
после итогового локального коммита и проверяется настоящим клонированием,
`git fsck`, совпадением HEAD и чистотой новой рабочей копии. Протокол
сохраняется в `RESTORE_VERIFICATION.json` и `.log`. SHA-256 проверяются
повторным чтением всех сохранённых файлов.

В полном комплекте `PDF/` содержит все 48 файлов, `TeX/` — их исходники,
`PDF_QA/` — восемь обзорных листов и протоколы. `evidence.tar.gz` содержит
логи всех этапов, мутации, снимки и промежуточные сборки (включая красные).
`source/` и `ADR/` доступны отдельно; весь код и история находятся в
`work.bundle`. Runtime, реальные .env и базы туда не включаются.

Папка `/private/tmp` не долговременное хранилище. Если её больше нет,
восстановить **в новую отдельную папку** из финального полного bundle,
проверить HEAD по manifest. Для будущей работы убрать remote, который
`git clone <bundle>` может назвать origin. Не запускать сервер на реальной
базе и не переносить .env из прежних копий. Пример команд для нового пути:

```sh
git clone /absolute/path/to/final-<SHA>/work.bundle /new/isolated/path
git -C /new/isolated/path remote remove origin
git -C /new/isolated/path switch -c codex/calc2-review
```

После восстановления `run_local.py` вычисляет ROOT по своему файлу;
окружение и синтетическую SQLite при необходимости нужно воссоздать.
`checkpoint.py` намеренно допускает только исходный активный путь:
при переезде сначала согласованно обновить его защиту и AGENTS.md.
