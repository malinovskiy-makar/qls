# Исправления после аудита графиков

03.11.2026. Статус: **на проверке у Макара**.

Исправлены три подтверждённые ошибки расчёта M01–M03 и восемь групп экономических пояснений E01–E08. Основание: аудит версии `15bd4a4b` и разрешение Макара исправить расчёты и пояснения автономно. Дизайн, тренажёр, GitHub и продакшен не менялись. Внешний вид ещё требует обсуждения: V01–V05 остаются открытыми.

## Три расчётные ошибки

| Ошибка | Что теперь происходит | Проверка |
| --- | --- | --- |
| M01. Нелинейная КПВ в модели двух стран | Модель явно принимает только линейные убывающие КПВ. Для нелинейной формы вместо неверной специализации выводится понятное ограничение модели. | Три нелинейных примера отклонены; линейные примеры, границы допустимой цены и невозможный обмен проверены. |
| M02. Пропадала верхняя половина окружности | Поиск учитывает отдельные обнаруженные ветви ограничения и уточняет кандидатов. Для `f=y`, `(x−2)²+(y−2)²=1`: максимум `(2;3)`, значение 3; минимум `(2;1)`, значение 1. | Окружности, эллипс, две компоненты, отрицательные координаты, вертикальное ограничение и разрыв функции. Зум не меняет ответ. |
| M03. Максимум Лаффера зависел от границы оси | Расчёт использует экономическую область, а граница оси задаёт только видимый участок. | При `D=300−Q`, `S=Q`: ставка 150, объём 75, сбор 11250 при разных пределах оси. Если вершина вне кадра, это объясняется в ответе. |

**M01 не означает, что реализована новая нелинейная модель двух стран.** Ошибка устранена явным запретом неподдерживаемой постановки, как допускал аудит. Для полноценной нелинейной торговли нужен отдельный согласованный объём работ.

Поиск M02 остаётся численным: конечная сетка может пропускать очень мелкие компоненты и изолированные точки. При выходе допустимой кривой за область поиска ответ предупреждает, что глобальный оптимум не установлен. Для произвольной функции на всей плоскости доказательство глобального оптимума не заявляется.

Модель Лаффера требует положительного рынка без налога, конечной запретительной ставки и однозначно убывающего налогового клина `D(Q)−S(Q)`. Для неподходящих кривых выводится ограничение постановки. Линейный максимум аналитический, нелинейный поиск численный.
