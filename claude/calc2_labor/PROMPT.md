## Правила, которые нельзя нарушать
- **Главный инвариант: вне труда ничего не меняется.** У 38 моделей вне блока «Рынок труда» ни одного расхождения:
  «Ответ», старт, `.tex`, превью, паритет. Доказательство в финале: `git diff bfb74cc3 -- calc2/static calc2/templates`
  касается только мест из «Как устроено сейчас» и нового; `control_numbers` 516; `git diff previews.json` — только
  строки четырёх моделей труда; `session_probe` и `parity_quick` — вне труда 0 расхождений; `answer_rows_probe` по всем
  моделям — вне труда расхождений с замером «до» 0.

  чинится код, а не ожидание. Сравнение для остальных моделей не ослабляй, число проверок не уменьшай.

## Этап А. Профсоюз максимизирует фонд оплаты (решения …81ac…, …813c…, …81e9…)
**А1. Расчёт.** `laborUnionMonopoly()` переписать: профсоюз выбирает занятость Lп на кривой спроса, при которой фонд
оплаты W·L = L·D(L) максимален, а занятость не больше желающих работать при этой ставке (при W ≥ Wk это L ≤ Lk).
Кандидаты: L₀ — корень MRL = `marginalRevenue(D, L)` = 0, если он в (0; Lk − 1e-6); иначе угол Lk (порог — в «Правилах»);
для нелинейного спроса сравнивай фонд L·D(L) кандидатов, а не только положение корня. Wп = D(Lп); фонд = Wп·Lп;
желающих = S⁻¹(Wп) (`invCurve`); безработица = желающих − Lп (не меньше 0); угол — флаг; DWL — между D и S от Lп до Lk.
Возврат: прежние поля `Lu, Wu, Lk, Wk, dwl` (их читают двусторонняя монополия, `.tex` и приборы) плюс `fund, Qs,
unemployment, L0, corner`. Нет равновесия D = S — «Ответ» как сейчас пишет «не найдено» (:631); расчёт не падает
(возвращает `null`).
**А2. Холст** («Монополист», эскиз выше): точку «MRL = S» (:479–480) убрать; точка «MRL = 0» на оси L при L₀ (если L₀ в
