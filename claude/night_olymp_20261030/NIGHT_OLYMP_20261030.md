### Э7. ИИ-проверка по критериям жюри

Модуль `olympiads/ai_check.py`, профиль `olympiad_check` в `problems/ai/prompts.py`, по образцу `catalog/attempts.py`.
- **Критерии:** раздел после `## Критерии оценивания` в `Problem.solution`. Разбери строки вида «K1 … → 1 балл» в список `{код, текст, максимум}`; строки без баллов (K7–K9 «если…, то…») — это правила, передаются модели целиком.
  - Сумма максимумов разобранных критериев ≠ максимуму задания в комплекте → проверка целиком по критериям одним баллом, с пометкой «оценка ориентировочная».
  - Критериев нет, но есть решение → проверка по эталонному решению, «оценка ориентировочная».
  - Нет ни того ни другого → ИИ не зовём: «проверить нечем», показываем только условие.
- **Фото:** сначала расшифровка тем же путём, что `catalog.attachments.recognise`, потом проверка по тексту.
- **Схема ответа:** по каждому критерию `{код, балл, вердикт, почему}`, общий комментарий. Валидация на своей стороне: коды только из списка, балл не больше максимума критерия (шаг 0,5), сумма не больше максимума задания. Вне схемы → статус «ошибка проверки», страница не падает.
- **Модель хранения:** `TrainingCheck(attempt, problem, status: queued|running|done|error|unavailable, score, max_score, criteria JSON, summary, transcription, approximate, provider, model, cost, created_at, finished_at)`. Итог пишется и в `TrainingItemResult`.
- **Без времени:** «Сдать задание» → проверка синхронно, с потолком времени из `core`; на экране — ожидание, потом балл и разбор по критериям (доска TakeFree).
- **На время:** при сдаче тура все открытые задания встают в очередь `queued`. Страница результата опрашивает адрес «проверь следующее», который за один запрос проверяет одно задание. Без Celery и Redis.
- **Флаг** `OLYMPIAD_AI_CHECK` в `settings.py`: по умолчанию выключен (на проде проверка ждёт правовой части), в `settings_olympiads_screens.py` включён. Флаг выключен → ИИ не зовём, после сдачи — разбор и критерии жюри для самопроверки.
- **Кто:** только вошедшие, дневной лимит и денежный потолок — как у `catalog_check`. Гость после сдачи видит разбор и «Войдите, чтобы ИИ проверил решение».

**Результат** (тесты с подставным поставщиком):
- верный ответ модели → баллы по критериям сохранены, сумма = итогу;
- код не из списка, балл больше максимума, сумма больше максимума → «ошибка проверки», 0 падений;
- критериев нет → «ориентировочная»; нет ничего → модель не вызвана;
- флаг выключен → 0 вызовов; гость → 0 вызовов;
- в запросе наружу нет имени, почты, логина, класса пользователя (тест читает собранный запрос);
- разбор критериев 59997: 9 критериев с баллами (K1–K6, K10–K12) и 6 правил (K7–K9, K13–K15); сумма максимумов = 12.
