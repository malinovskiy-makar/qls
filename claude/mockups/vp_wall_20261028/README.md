## Как читать

1. Данные примерные (ученик `ivan_econ`, демоверсия 10 класса). На сайте всё — из базы.
2. Классы `k-*` — из дизайн-системы-ориентира, собранной по сайту. На сайте — существующие токены и компоненты (`DESIGN.md`, `vp/templates/vp/_styles.html`); `bundle.css` в проект не копировать. Шрифт, цвета, шапка сайта не меняются; с макетов берутся композиция, тексты и поведение.
3. Тёмная тема — по токенам сайта, как остальной раздел.
4. На страницах — только короткое тире «–».

## Решения владельца поверх макетов (28.10.2026, Notion «Решения» 407b11c9-2bc1-818b-94a4-fdd405a18614)

* **Telegram — главный путь для всех.** Цель стены — чтобы на канал подписались все. Почта — запасной путь: только мелкая ссылка «Telegram не открывается? Подтвердить почтой» (экраны 01, 02, 03, 07).
* **Подтверждённая почта сама стену НЕ открывает.** После включения почты она есть у каждого нового ученика. Человек с подтверждённой почтой проходит через почтовый путь в один клик (`04b`), но только если сам выбрал почту.
* **Галочка рассылки — по желанию** и никогда не отмечена заранее. Без неё стена тоже пускает; на почту тогда приходят только коды. Подпись галочки — общая с сайтом (`legal/templates/legal/_mail_label.html`).
* **Почта и код вводятся в окне стены**, а не на странице «Почта».
* **Код — одно поле**, как на сайте (вставка из письма целиком, подсказка кода на телефоне).
* **Анкету спрашиваем один раз.** «Instagram*» — со сноской про Meta. Оставить ли Instagram и сноску — решат Анич и Андрей; пока как на макете.
* **Тексты сносок о персональных данных — черновики**; финальные даёт Анич (задача 199-ФЗ 404b11c9-2bc1-81ea-b487-ce0aef5cb20f).
* **Вход на сайт через Telegram запрещён (199-ФЗ):** бот только привязывает Telegram к уже вошедшему аккаунту и проверяет подписку. Войти по Telegram нельзя.
