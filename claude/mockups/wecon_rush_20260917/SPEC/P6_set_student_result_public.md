`SetPage.dc.html` (props `who`: student/anon, `state`: fresh/played), `ResultPublicMobile.dc.html`

подписан „время вышло“, в превью „201 очков“, кнопка ведёт на главную без режима»**.

# Часть A — страница набора `/game/s/<код>/`

Сейчас `set_page` отдаёт главную игры (`game.html`) с карточкой `#set-intro` под сгибом, а доска
живёт отдельно на `/game/s/<код>/board/` (`set_board`, шаблон `set_board.html`). Делаем **одну
страницу набора**: приглашение сверху, доска ниже. Касается `kind` учительских наборов (и любых
будущих, кроме `duel` и `daily`): у дуэли своя страница-лобби (P3), у вызова дня — доска дня (P4);
для `daily` без `?auto=1` — редирект на `/game/daily/`.

## Сверка с кодом перед правками
Базовый прогон: `manage.py test game.tests.test_sets game.tests.test_game` — числа в журнал. Сверь:
`set_page` (контекст `auto_set`, `autostart`), `set_run_allowed` (четыре причины отказа),
`attempts_used`, `set_board`, `set_question_stats`, `my_result_for`, `remember_my_result`,
`api_session_start_set`; JS `AUTO_SET` и `#set-intro` в `game.html`.

## A.1 — разметка (по `SetPage.dc.html`)
Отдельный шаблон `game/templates/game/set_page.html` (шапка сайта есть), а не `game.html`:
1. «← Wecon Rush». **Карточка-приглашение**, grid `minmax(0,1fr) 340px`: слева надпись «НАБОР
   УЧИТЕЛЯ» (`get_kind_display`), название 28px 800 (нет названия — «Набор <код>»), «автор
   malinovskii · код `K7M2X9QD`» (код моноширинным), плашки: «Блиц · один верный ответ» (акцентная),
   «**12** вопросов», «**2** минуты · 3 жизни», «попыток: **1**», «открыт до **20 сентября, 23:59**»
   (только если задан `closes_at`; время московское); строка правил: «Вопросы и их порядок одинаковы
   у всех. Результат идёт на доску этого набора, в общий лидерборд не идёт. Брошенный раунд попытку не
   тратит.» Справа действия:
   - можно играть: «▶ Играть [Enter]» 58px `--btn-bg` → `/game/s/<код>/?auto=1` (страница игры сразу
     в отсчёт и раунд, без стартового экрана; у набора учителя автостарт разрешён), под ней «осталась
     1 попытка из 1»; анониму ниже плашка: «Вы не вошли: на доске будете записаны как „аноним“,
     учитель вас не узнает.» + «Войти» (amber; после входа — обратно на эту страницу);
   - играть нельзя — вместо кнопки причина человеческими словами из `set_run_allowed`: «Попытки
     закончились», «Набор откроется <дата>», «Набор закрыт <дата>»;
   - уже играл (есть `my_result_for`): «ВАШ РЕЗУЛЬТАТ **186** · 3-е место из 15 · точность 83 %»,
     кнопка «Страница результата», мелко «попытки закончились · набор сыгран 17 сентября» (или
     «Сыграть ещё раз», если попытки остались);
   - всегда внизу «В обычную игру».
2. **Доска** под приглашением, две колонки (`minmax(0,1fr) 540px`) — те же компоненты, что у доски
   дня (P4): «Кто прошёл · N» (место с медалями · Игрок · Счёт · Точность · Макс. комбо · Чем
   кончилось; анонимные раунды в таблице **есть**, имя «аноним» серым курсивом; моя строка в рамке;
   первые 10 + «и ещё N · анонимные раунды в таблице есть, но без имени» + моя строка отдельно) и
   **«Где ошиблись»** (правило текстов прежнее: автор, персонал и уже сыгравшие видят тексты,
   остальным «🔒 текст откроется после вашей попытки»; подпись под блоком: «Тексты видят автор набора
   и те, кто его уже сыграл, — иначе контрольную можно прочитать заранее.»).
3. `/game/s/<код>/board/` → 302 на `/game/s/<код>/` (шаблон `set_board.html` удаляется после
   переноса; дуэль — по-прежнему редирект на свою страницу).
4. Итог раунда по набору ведёт обратно на эту страницу («К набору и доске», P3 дополнение 2).
5. **Неверный код.** `/game/s/<несуществующий>/` (и `/board/`) отдаёт не общий 404 сайта, а страницу
   в оформлении игры со статусом 404: «Набора с кодом **QQQQ1111** нет» / «Проверьте код — он из 8
   букв и цифр, регистр и пробелы не важны.» / поле «код набора» (та же проверка, что на главной,
   P1 дополнение 2) и «В игру». Ввод неверного кода на главной вообще не уводит со страницы (P1).
6. Телефон: приглашение столбиком (кнопка «Играть» на всю ширину сразу под плашками), затем таблица
   (колонки: место · игрок · счёт · точность), затем «Где ошиблись».

## A.2 — тесты (`game/tests/test_sets.py`) и зубастость
- `/game/s/<код>/` — отдельный шаблон: в HTML нет `#mode-grid`/стартового экрана; есть приглашение и
  обе части доски; «Играть» ведёт на `?auto=1`; анониму показано предупреждение и «Войти»; при
  исчерпанных попытках нет кнопки «Играть» и есть «Попытки закончились»; при `closes_at` в прошлом —
  «Набор закрыт»; плашка срока есть только при заданном `closes_at`.
- `/board/` → 302 на страницу набора; `kind='duel'` → как раньше; `kind='daily'` без `auto` → 302 на
  `/game/daily/`.
- Неверный код → статус 404 и в теле «Набора с кодом»; нет текста «занятие или работа удалены».
- Тексты вопросов: не игравшему скрыты, игравшему и автору видны; анонимный результат в таблице есть
  с именем «аноним».
- Зубастость: вернуть рендер `game.html` — тест «нет стартового экрана» краснеет; показать тексты
  всем — краснеет; вернуть общий 404 — краснеет.

# Часть B — публичная страница результата `/game/r/<код>/`

Шаблон `game/templates/game/result.html` (самостоятельная страница без шапки сайта, без JS для самой
сводки, мета-теги Open Graph — всё это **сохраняется**), вьюха `result_page`.

## B.1 — разметка (по `ResultPublicMobile.dc.html`, десктоп — `ResultPublic.dc.html`)
1. Сверху словесный логотип «WECON ⚡ RUSH» (на десктопе + «· игра на скорость по олимпиадной
   экономике» и кнопка «Что это за игра» → `/game/`).
2. **Кто и что**: кружок с инициалами, **ник игрока** 18px 700 (`result.user.username`; у анонимного
   раунда — «Игрок», кружок со значком), строка «Блиц · один верный ответ · 7 сентября 2026»; счёт
   64px (десктоп 88px) 800 + «очков» со склонением; плашка места: для зачётного — «🏆 **N-е место** в
   таблице <режима>» (место в таблице «всё время · очки» на момент открытия; считать той же функцией,
   что лидерборд; если дорого — кэшировать на минуту), для незачётного — серая плашка «не в таблице:
   <причина из `UNRANKED_TEXT`>»; для результата по набору — «набор „<название>“» / «вызов дня ·
   <дата>».
3. Три плитки: «ВЕРНЫХ **11 из 14** · точность 79 %», «МАКС. КОМБО **×1,5**», «ЧЕМ КОНЧИЛОСЬ» —
   **для всех исходов**: `lives` → «жизни кончились», `time` → «время вышло», `set_done` → «прошёл
   набор до конца», `pool_empty` → «вопросы кончились», `quit` → «вышел из раунда» (сейчас всё, кроме
   `lives`, подписано «время вышло» — это баг); вторая строка плитки — «жизней осталось N из 3», если
   это можно вычислить из сохранённого (`wrong_count` и правила режима), иначе не показывать.
4. **Действия сразу под счётом** (на десктопе — правая колонка): основная 58px `--btn-bg`
   **«▶ Сыграть в Блиц · обогнать 225»** → `/game/?mode=<режим>` (P1 дополнение 3); если результат
   из набора учителя или вызова дня — **«Сыграть этот же набор»** → `/game/s/<код>/` (для вызова
   прошедшего дня — «Сегодняшний вызов дня» → `/game/daily/`); вторая — **«⚔ Вызвать <ник> на дуэль»**
   (на телефоне «Вызвать на дуэль») → для вошедшего открывает создание дуэли в том же режиме
   (`/game/?duel=<режим>` — главная с открытым окном «Создать дуэль» и выбранным режимом), для
   анонима — вход с возвратом туда же; мелко «Дуэль — те же вопросы у обоих, старт одновременно.
   Нужен аккаунт.»; у анонимного результата вместо ника — «Вызвать на дуэль» (соперник не определён —
   это просто создание дуэли); третья — «Поделиться» (существующая логика шеринга).
5. «Счёт по ходу раунда» — существующая `<polyline>` из `_curve_points`; «Точность по темам» —
   существующие полоски (верно/ошибка/пропуск). Нет данных — блока нет.
6. Низ: «Wecon Rush — игра на скорость по олимпиадной экономике: N вопросов из реальных олимпиад,
   четыре режима, три жизни. Играть можно без регистрации.» (N — то же число, что на главной).
7. Мета-теги: `og:title` — «**Sonya_kitty: 225 очков** в Wecon Rush — обгонишь?» со **склонением**
   (1 очко, 2–4 очка, 5+ очков, 11–14 очков; сейчас «201 очков»); у анонимного — без ника.
   `og:description` — как сейчас. Остальное не трогать.

## B.2 — тесты (`game/tests/test_game.py` или отдельный `test_result_page.py`) и зубастость
- Ник в HTML для результата пользователя; «Игрок» для анонимного; пять исходов → пять разных
  подписей; склонение: 1, 2, 5, 11, 21, 22, 25, 101, 111, 201 → «очко/очка/очков» верно; главная
  кнопка: обычный раунд → `?mode=<режим>`, набор учителя → `/game/s/<код>/`, вызов дня → `/game/daily/`
  или набор дня, если он сегодняшний; страница открывается без входа (200) и на HEAD отвечает 200;
  плашка места есть только у зачётного.
- Зубастость: вернуть `{% else %}время вышло` — тест исходов краснеет; вернуть «очков» без
  склонения — краснеет; убрать ник — краснеет.

## Числовые инварианты
- У набора адресов с содержимым: 1 (`/board/` — редирект).
- Неверный код: статус 404, 0 вхождений «занятие или работа».
- Склонение: 10 проверочных чисел из теста — 10 верных форм.
- Страница результата: 0 запросов на запись; число запросов не зависит от числа игроков в таблице
  сверх вычисления места (потолок зафиксировать в тесте).
