# Фаза P4 — Вызов дня: страница с серией и лидерами, одна доска дня

> Спецификация одной фазы единого прогона. Ветка, Notion, коммиты, отчёт, стоп-гейты — в лаунчере.

## Макеты
`Daily.dc.html` (props `who`: student/anon, `state`: fresh/partial, `theme`), `DailyBoard.dc.html`
(props `played`, `mode`, `theme`; внутри переключаются режим и день), `DailyMobile.dc.html`; живая
ячейка на главной — `Main.dc.html` (поля `dailyLine`, `dailyLeft`). Игроки, очки и тексты вопросов на
макетах условные (на бою вызов дня пока никто не играл) — бери из макетов вид, а не данные.

## Что делаем и почему
Решение владельца в Notion → «Решения»: **«Вызов дня: четыре вызова в день остаются; мотивация —
серия дней и лидеры на карточке; страница отдельная + живая ячейка на главной»** (17.09.2026) —
прочитай карточку целиком, включая дополнение внизу (тексты вопросов закрытых дней открыты всем;
блок называется «Где ошиблись»). Баги — в «Задачах»: **«Вызов дня: „Вчерашняя доска“ ведёт на 404,
архивная доска пишет „Сегодня… будь первым“, у одного вызова две разные доски»**.

Что не так сейчас (проверено на бою 17.09): «Играть» на карточке вызова ведёт не в раунд, а на
главную игры `/game/s/<код>/`, где карточка набора лежит под сгибом (прокрутка + второй «Играть»);
у вызова две разные доски (`/game/daily/<режим>/` и `/game/s/<код>/board/`), итог раунда ведёт на
вторую; «Вчерашняя доска» отдаёт 404, если накануне никто не заходил (наборы создаются лениво);
карточки показывают ненужный код набора и не показывают ни числа сыгравших, ни лидера, ни серии.

Механика НЕ меняется: четыре набора в сутки, ленивое детерминированное создание, отсечка по
московской полуночи, одна попытка, на доске только вошедшие, результат вызова не идёт в общий
лидерборд (`set_run`). Модуль `game/daily.py`, вьюхи `daily_page`, `daily_board` в `game/views.py`,
шаблоны `game/templates/game/daily.html`, `daily_board.html`, тесты `game/tests/test_daily.py`.

## Сверка с кодом перед правками
Базовый прогон: `manage.py test game.tests.test_daily game.tests.test_sets` — числа в журнал; красное
до правок — СТОП. Сверь: `daily.today()`, `next_reset()`, `get_daily_set(mode, day, create)`,
`board_rows(gset, me, limit=50)`; `set_question_stats(gset, show_text)`; параметр `?auto=1` в
`set_page` (автостарт без карточки-заставки, у дуэли запрещён); `played_set_codes`,
`my_result_for`; что `_save_result` кладёт в `share.set.board_url`.

## P4.1 — серия дней (сервер)
`game/daily.py`:
- `played_days(user)` → множество московских дат, в которые у пользователя есть `GameResult` с
  `game_set.kind='daily'` (дата — `game_set.day`, а не `created_at`: раунд, начатый в 23:59, относится
  к дню своего набора).
- `streak_for(user, today=None)` → `{'current': K, 'best': B, 'week': [7 × {'day', 'label', 'hit',
  'is_today'}]}`. День засчитан, если сыгран **хотя бы один** из четырёх вызовов. `current` — длина
  цепочки подряд идущих дней, кончающейся сегодня, а если сегодня ещё не сыграно — вчера (серия не
  «сгорает» до полуночи: на странице тогда текст «сыграйте сегодня любой вызов, чтобы не прервать»).
  `best` — самая длинная цепочка за всё время. `week` — текущая неделя пн–вс.
- Аноним: серии нет (функция не вызывается). Новых моделей и миграций не заводить — всё считается
  из `GameResult`. Одним запросом на пользователя, без запроса на день.

## P4.2 — страница `/game/daily/`
Шапка сайта остаётся. Ширина как у главной игры (padding 20px 40px). По макету `Daily.dc.html`:
1. **Верх**, grid `minmax(0,1fr) 640px`: слева ссылка «← Wecon Rush», заголовок «Вызов дня» 32px 800
   и, для вошедшего, пилюля «сыграно N из 4»; строка «17 сентября · вопросы одинаковы у всех · одна
   попытка на режим». Справа карточка-«счётчик»: для вошедшего — «СЕРИЯ» + число дней со значком
   огня (amber), рядом текст («сегодняшний день засчитан» / «сыграйте сегодня любой вызов, чтобы не
   прервать») и «лучшая серия — B дней»; под ними неделя из семи кружков (сыгранный день — залит
   `--accent` с галочкой, сегодня — кольцо `--accent-ring`); через разделитель — «НОВЫЙ ВЫЗОВ ЧЕРЕЗ»
   и отсчёт `ч:мм:сс` 30px 800 tabular + «в полночь по Москве» (момент считает сервер, клиент
   рисует — как сейчас). Для анонима вместо серии: «**Играть можно и без входа.** Результат покажем,
   но на доску попадают только вошедшие — и серия дней копится только у них.» + кнопка «Войти» (amber).
2. **Четыре карточки** в ряд (grid 4, gap 16), одна анатомия: плитка-иконка режима 38px
   (`--accent-tint`), название 20px 700, под ним человеческая строка «15 данеток · 1 мин» / «12
   вопросов · 2 мин» / «10 вопросов · 5 мин» / «8 числовых ответов · 10 мин» (число — `gset.size`,
   длительность — из `config.MODES`); **кода набора на карточке нет**; строка «СЕГОДНЯ СЫГРАЛИ **N**»;
   топ-5 доски (строки 38px: медали 1–3 как в лидерборде главной, с 4-го — номер; имя; счёт 15px 800;
   моя строка — рамка `1.5px solid var(--accent)`, имя «Вы · <имя>»); под списком ссылка-строка
   «Вчера: 1-е место — <ник> · <счёт> →» на вчерашнюю доску этого режима (в макете написано
   «Вчера победил/победила» — пол игрока мы не знаем, поэтому формулировка нейтральная); если вчера
   никто не играл — «Вчера никто не играл →», ссылка ведёт на пустую доску, см. P4.3. Нет сыгравших — пунктирная
   плашка «**Ещё никто не сыграл** · Первый результат сразу станет первым местом.»
   Низ карточки: не сыграно — «▶ Играть» (`--btn-bg`, 46px) + «Доска» (ghost); сыграно — карточка
   приглушена (`--surface-2`), пилюля «✓ сыгран» в шапке, «**186** ваш счёт · 3-е место из 10» и
   одна кнопка «Доска и разбор вопросов». Аноним, сыгравший вызов (есть в `played_set_codes`), —
   «сыгран», счёт из `remember_my_result`, без места.
3. **Строка правил** под карточками 12.5px `--text3`: «Результат вызова идёт на доску дня, в общий
   лидерборд не идёт.» · «Брошенный раунд попытку не тратит.» · «Серия растёт, если за день сыгран
   хотя бы один вызов.»
4. **«Играть» стартует раунд сразу**: ссылка `/game/s/<код>/?auto=1` → страница игры сразу в отсчёт
   3-2-1 (фаза P2) и раунд; карточка-заставка и главная игры не показываются. Проверь, что автостарт
   действительно не рисует стартовый экран даже на долю секунды (если рисует — прячь `#screen-start`
   до решения об автостарте).
5. Телефон (`DailyMobile.dc.html`): всё столбиком; счётчик — две колонки (серия | отсчёт) + неделя;
   карточка компактная: одна строка лидера («🥇 lengler 640 · сыграли 14») вместо топ-5, кнопки в ряд.
6. Запросы: четыре топ-5 и четыре «вчера» — без N+1 (одна выборка результатов по восьми наборам).

## P4.3 — одна доска дня `/game/daily/<режим>/[<день>/]`
По макету `DailyBoard.dc.html`. Адреса сохраняются; страница серверная (переключатели — обычные
ссылки, без SPA).
1. Ссылка «← Вызов дня»; заголовок «Доска дня»; сегмент из четырёх режимов (ссылки на тот же день
   другого режима); справа листалка дней: «‹» · «Сегодня · 17 сентября / четверг» · «›» («›» у
   сегодняшнего дня неактивна; «Вчера · 16 сентября» для вчера, дальше — просто дата). Листать можно
   на любую прошедшую дату не раньше первого в базе набора вызова дня.
2. **Дня без набора не бывает в виде 404.** Если на запрошенную прошедшую дату набора нет (никто не
   заходил — ленивое создание) — отдаём ту же страницу с пустой доской: «**В этот день вызов никто
   не сыграл**». Задним числом наборы по-прежнему НЕ создаём. 404 — только для неизвестного режима,
   кривой даты и даты в будущем.
3. Карточка-сводка: «НАБОР — Блиц · 12 вопросов · 2 мин», «СЫГРАЛИ — N», для сегодняшнего —
   «ДО КОНЦА ВЫЗОВА — ч:мм:сс»; справа по состоянию: не играл сегодня — «Вы ещё не играли этот вызов»
   + «▶ Играть» (автостарт); играл — «ВАШ РЕЗУЛЬТАТ **186 · 3-е место из 10**» + ссылка «Страница
   результата» (`/game/r/<код>/`); прошедший день без моего результата — пилюля «вызов закрыт».
4. Две колонки (`minmax(0,1fr) 560px`):
   - **«Таблица»** — подпись «по счёту; при равенстве выше тот, кто закончил раньше»; колонки: место
     (медали 1–3) · Игрок · Счёт · Точность · Макс. комбо · Чем кончилось («прошёл все вопросы» /
     «кончились жизни» / «вышло время»); первые 10 строк, под ними «и ещё N — показаны первые 10; своя
     строка видна всегда, даже если вы ниже» и моя строка отдельно, если я ниже десятого; моя строка —
     рамка `--accent`. Пустая сегодняшняя: «**Сегодня этот вызов ещё никто не прошёл** · Первый
     результат сразу станет первым местом.»; пустая прошедшая: «**В этот день вызов никто не
     сыграл**» (слов «сегодня» и «будь первым» на прошедшем дне быть не может). Низ: «На доске только
     вошедшие в аккаунт: у анонимного игрока нет имени.»
   - **«Где ошиблись»** (название — правка владельца, НЕ «На чём посыпались») — подпись «доля верных
     среди сыгравших этот вызов»; строка на вопрос: номер · текст в одну строку с обрезкой · полоска
     доли верных · процент; вопросы с долей < 40 % — красным. **Кто видит тексты:** пока вызов открыт
     (сегодня) — автор/персонал и тот, кто его уже сыграл, остальным вместо текста «🔒 текст откроется
     после вашей попытки»; **после закрытия дня — все** (решение 17.09). Нет сыгравших — «Пока нечего
     считать» + «Разбор появится после первого сыгранного раунда.» / «В этот день никто не играл.»
     Данные — существующая `set_question_stats`.
5. **Вторая доска исчезает:** `/game/s/<код>/board/` для `kind='daily'` → редирект на
   `/game/daily/<режим>/<день>/`; `_save_result` для `daily` отдаёт в `board_url` доску дня.
   (Для наборов учителя доска переезжает на страницу набора — фаза P6.)

## P4.4 — связь с главной и итогом
- Живая ячейка на главной (P1, дополнение 1): наполни `N` (сколько из четырёх сыграно сегодня) и `K`
  (`streak_for(...).current`).
- Итог раунда вызова дня — P3, дополнение 1 (место на доске дня, серия, «Доска дня», «Следующий
  вызов»). Если P3 уже пройдена — доделай здесь то, что ждало `streak_for`.

## Тесты (дописать в `game/tests/test_daily.py`) и зубастость
- `streak_for`: пусто → 0/0; дни подряд по вчера включительно, сегодня не сыграно → current = длина
  цепочки (не 0); сыграно сегодня → +1; разрыв в один день обнуляет; два вызова в один день = один
  день; раунд, сохранённый в 00:01 следующего дня по набору вчерашнего дня, засчитан во вчера; аноним
  не вызывает ошибок; `best` ≥ `current`.
- Страница: в HTML нет кодов наборов; у каждой карточки ссылка «Играть» с `?auto=1`; сыгранная
  карточка без «Играть»; у анонима нет слова «серия» в блоке счётчика и есть «Войти».
- Доска: прошедший день без набора → 200 и «никто не сыграл», набор при этом не создан
  (`GameSet.objects.filter(kind='daily', day=...)` пуст); будущая дата → 404; на прошедшем дне нет
  строк «Сегодня» и «будь первым»; тексты вопросов: сегодня не игравшему — скрыты, игравшему —
  видны, вчерашние — видны всем (в том числе анониму); блок называется «Где ошиблись»;
  `/game/s/<код дня>/board/` → 302 на доску дня; моя строка есть в HTML, когда я на 11-м месте.
- Число запросов страницы `/game/daily/` не растёт с числом игроков (assertNumQueries с потолком).
- Зубастость (после коммита зелёного): вернуть `Http404` при отсутствии набора — тест «200 на пустой
  день» краснеет; считать серию по `created_at` вместо `game_set.day` — тест про 00:01 краснеет;
  открыть тексты всем сегодня — тест про скрытые тексты краснеет; вернуть код набора в шаблон — краснеет.

## Числовые инварианты
- Серия: для цепочки дат {D−3, D−2, D−1} и сегодня D без игры → `current = 3`; после игры сегодня → 4.
- `/game/daily/<режим>/<любая прошедшая дата>/` → 200; наборов в базе после запроса не прибавилось.
- В HTML `/game/daily/` 0 вхождений кодов наборов дня; ссылок с `?auto=1` = числу несыгранных вызовов.
- Досок у вызова дня: 1 (второй адрес — редирект).
