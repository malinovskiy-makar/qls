Источник: холст «Тренажёр ВП — редизайн 2 тура» (claude.ai, Design). Здесь — выгрузка для Claude Code.

## Что где

* `screens/*.png` — картинки экранов. Смотреть в первую очередь.
* `html/*.html` — статичные снимки тех же экранов: разметка и стили без логики. Открываются в браузере из этой папки (рядом лежат `vp.css` и `ds/`).
* `source/*.dc.html` — исходники макетов: разметка с привязками `{{…}}` и класс `Component` с данными и логикой (какие строки раскрываются, как работают фильтры, проверка записи числа). Сами по себе в браузере не открываются — их надо читать.

## Как читать макеты

1. Данные на макетах — примерные (попытка masha_econ на демоверсии 10 класса). На сайте всё — из базы.
2. Классы макета (`k-btn`, `k-card`, `k-chip`, `k-info`, `k-state` …) — из дизайн-системы-ориентира, собранной по сайту. На сайте используй существующие компоненты и токены (`DESIGN.md`, `vp/templates/vp/_styles.html`); `bundle.css` в проект не копировать.
3. Шрифт, цвета и шапка сайта не меняются. С макетов берётся композиция экранов, тексты и поведение.
4. На макетах местами стоит длинное тире «—». На страницах сайта — только «–» (`scripts/check_em_dash.py`).

## Решения владельца поверх макетов

* Подсказок о записи числа внутри варианта нет ни в одном режиме (ни с таймером, ни без). Под полем — только статичная подпись «Только число: запятая, до сотых.»
* Кнопка «±» у поля числа — только на сенсорных экранах. На ноутбуке её нет (06 — верно).
* Текст с пропусками: номера пропусков в тексте и списки под абзацем — на всех ширинах, не только на телефоне (07 показывает это для телефона).
* Карточка «Закрытая консультация перед туром» в «Что дальше» — только когда появятся приглашения друзей (отдельная сессия). Сейчас её нет.
* Тренировка записи ответа (08) открыта всем, без входа и без стены.
* Ответ, который нужно вписать, всегда с обычным минусом «-» (например, «-0,12»). Длинный минус «−» — только в тексте условий и решений.
