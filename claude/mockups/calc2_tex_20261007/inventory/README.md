# Опись мест рисования по файлам сцен

Семь конспектов разведки: кто что рисует, в каком порядке, какими шкалами, откуда берёт геометрию (строка
формулы, функция без строки, массив точек модели, отдельные числа) и где трудные случаи для записи.

Написаны чтением кода на коммите `e165aff`, ничего не запускалось. Это **подсказки с адресами, а не истина**:
номера строк и выводы проверяй по коду. Читать целиком не нужно (около 550 тысяч знаков): открывай конспект
своей семьи перед тем, как ставить в ней записи, и пользуйся поиском.

| Файл | Про что | Когда читать |
|---|---|---|
| `01_plane_curves_modes.md` | размеры и шкалы, панели, оси, сетка, деления, кривые из `STATE.curves`, общие помощники | перед переносом сборщика в код (фаза 1) |
| `02_market.md` | `40-scenes-market.js`: спрос и предложение, налоги, потолок, квота, эластичность, внешние эффекты, открытая экономика, сложение | фаза 2, рынок |
| `03_mono_labor.md` | `42-scenes-mono.js` и `46-scenes-labor.js`: монополия во всех видах, рынок труда | фаза 2, монополия и труд |
| `04_firm_consumer_macro_ineq.md` | `44-scenes-firm.js`, `48-scenes-consumer.js`, `50-scenes-macro.js`, `56-scenes-inequality.js` | фаза 2, фирма, потребитель, макро, неравенство |
| `05_ppf_trade.md` | `54-scenes-ppf.js`: КПВ, сложение КПВ, торговля, мировая цена | фаза 2, КПВ и торговля |
| `06_overlays_self.md` | `60-overlays.js` и `96-self.js`: порядок перерисовки, легенда, ключевые и свои точки, инструмент «Площадь», «Сначала сам» | фазы 1 и 3 |
| `07_math_and_export.md` | `70-scenes-math.js`: сцены «Математики» и устройство нынешних сборщиков `.tex` | фаза 2 (математика) и фаза 4 (удаление старого) |

Где конспект расходится с `RECON.md`, верен `RECON.md`: его числа получены запуском.
