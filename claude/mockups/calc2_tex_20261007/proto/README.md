# Прототип новой выгрузки и его приборы

Здесь лежит рабочий образец способа из `SPEC.md` и приборы, которыми он проверен. Всё запускается на
нетронутом коде ветки: прототип подключается к странице `/calc2/` снаружи (`addScriptTag`) и файлов сайта не
меняет.

## Что есть что

| Файл | Что это |
|---|---|
| `texproto.js` | прототип: бумажный прогон (`enterPaper`), опись (`capture`), сборка (`emit`); в странице доступен как `window.TXP` |
| `lib.mjs` | общая часть приборов: корень репозитория, адрес сервера, открытие страницы и модели |
| `run.mjs` | модели и состояния по рецептам → `.tex`, опись `.list.json`, снимок холста на листе `.paper.png`, счётчики |
| `build.py` | собирает `.tex` настоящим `pdflatex`, считает «собралось N из N», складывает листы «холст \| файл» |
| `formulas.py` | считает каждую напечатанную формулу настоящим `pgfmath` и сверяет со значением движка |
| `checks.mjs` | один и тот же файл при четырёх окнах и двух темах; холст и состояние после выгрузки те же; время |
| `replay.mjs` | широкий прогон: 44 старта и шаги базового снимка редизайна, меняющие холст (823 задачи на `e165aff`) |
| `replay_sum.py` | сводка широкого прогона |
| `one.mjs` | воспроизвести отдельную задачу широкого прогона и показать, что не сошлось |
| `paths.mjs` | сторож «запись не меняет рисунок»: отпечаток атрибута `d` всех путей холста по 44 стартам и 111 рецептам (155 состояний); сравнение со снятым раньше; два съёма подряд на одном коде совпадают (замер) |
| `recipes.json` | 27 состояний: вмешательства, свои точки, заголовок, «Сначала сам», кусочная запись, параметр, Q(P) |
| `recipes_nonlinear.json` | 47 состояний с непрямыми формулами во всех семьях моделей: границы областей становятся кривыми |
| `recipes_window.json` | 37 состояний своего окна: колесо, сдвиг листа, снятая «только первая четверть» |
| `pilot.patch` | пилот записей на десяти моделях: словарь (`markArea`, `markNumeric`, `markPoly`, `curveFormula`), 22 места `markArea` (18 путей-областей рынка и 4 области монополии), предельные кривые |

## Как запускать

Нужны: сервер калькулятора, `node` с `playwright` из `node_modules` репозитория, `pdflatex`. Команды — из корня
репозитория.

```bash
./venv313/bin/python manage.py runserver 8099 --noreload      # в отдельном терминале или фоном
export CALC2_BASE_URL=http://127.0.0.1:8099                   # это значение по умолчанию
P=claude/mockups/calc2_tex_20261007/proto
R=reports/calc2_tex/proto                                     # сюда приборы пишут по умолчанию

node $P/run.mjs                                               # 44 модели на старте → $R/run
./venv313/bin/python $P/build.py $R/run                       # сборка и листы → $R/run/sheet_NN.png
./venv313/bin/python $P/formulas.py $R/run                    # формулы настоящим pgfmath

OUT=$R/states SETUP=recipes.json ALL=1 node $P/run.mjs
OUT=$R/nl SETUP=recipes_nonlinear.json ALL=1 node $P/run.mjs
OUT=$R/win SETUP=recipes_window.json ALL=1 node $P/run.mjs
KEYS=taxes,mono node $P/run.mjs                               # только названные модели
SETUP=recipes.json KEYS=taxes@subsidy,sd@qp node $P/run.mjs   # отдельные состояния: «ключ@вариант»
SETUP=recipes_nonlinear.json ALL=1 KEYS=taxes,mono node $P/run.mjs   # все варианты названных моделей

KEYS=all node $P/checks.mjs                                   # 44 модели × 4 окна, около пяти минут
JOBS=3 node $P/replay.mjs                                     # широкий прогон, 25–40 минут; продолжается с места
python3 $P/replay_sum.py $R/replay
IDS='costs#123' node $P/one.mjs                               # разобрать одну задачу; MODE=all — все пути

OUT=$R/paths0 node $P/paths.mjs                               # отпечаток путей холста ДО правок сцен
OUT=$R/paths1 WITH=$R/paths0/paths.json node $P/paths.mjs     # после правок: код 1, если хоть один путь сдвинулся
```

Переменные: `OUT` — куда писать; `CALC2_BASE_URL` — сервер; `VW`, `VH`, `THEME` — окно и тема у `run.mjs`;
`JOBS`, `KEYS`, `LIMIT`, `TASK_MS` — у `replay.mjs`; `KEYS`, `WITH` — у `paths.mjs`; `PROTO` — другой файл прототипа.

Чтобы посмотреть пилот записей: снять `paths.mjs` на нетронутом коде, затем
`git apply claude/mockups/calc2_tex_20261007/proto/pilot.patch`, прогнать `run.mjs` по
`sd,taxes,tax,tax-adv,ceil,quota,elast,ext,smallopen,mono` (старты и все варианты рецептов: `ALL=1` вместе с
`KEYS`), сравнить `paths.mjs` со снятым (пути обязаны остаться теми же), затем
`git checkout -- calc2/static/calc2` (пилот — образец, а не готовая правка). Числа пилота — `RECON.md`, раздел 4.

## Как читать вывод `run.mjs`

Строка на состояние. Столбцы:

| Столбец | Что считает | Дефект? |
|---|---|---|
| `панели`, `осей` | панелей на холсте и найденных линий осей (у обычной панели две) | нет |
| `форм` | кривых, ушедших формулой (кусок кусочной кривой считается отдельно) | нет |
| `числ` | кривых узлами расчёта с причиной; в скобках — сколько взято у самой модели (`__data__`) | нет |
| `лом+` | ломаных с названной причиной | нет |
| `БЕЗ:лом` | кривых без записи, упростившихся до точной ломаной | да |
| `БЕЗ:отсч` | кривых без записи, ушедших отсчётами | да |
| `НЕСОШ` | кривых, чья запись не прошла сверку | да |
| `обл:гран` | областей, ушедших границами по записи | нет |
| `обл:мн` | областей-многоугольников с точными вершинами, без записи | нет |
| `обл:числ` | областей узлами с причиной | нет |
| `обл:БЕЗ` | областей без записи, ушедших отсчётами | да |
| `обл:НЕСОШ` | областей, чья запись не прошла сверку | да |
| `пар` | пар координат в файле | нет |
| `⚠` | предупреждения описи (нечисловая координата в пути и подобное) | дефект сцены |

Итоговая строка — суммы. На нетронутом коде дефекты есть: записей у большинства мест рисования пока нет, в
этом и состоит работа. Числа, которые должны получиться, — в `RECON.md`, раздел 2.

## Что в прототипе сделано иначе, чем должно быть на сайте

- Размер листа подменяется подменой глобальной `computeSize`. На сайте — признак бумажного размера в самой
  `computeSize()`.
- История и автосохранение на время прогона не заглушаются: прототип зовётся приборами, а не кнопкой. На сайте —
  `_histMute` (`91-session.js`).
- Шрифтов прототип не ждёт: это делает `lib.mjs` при открытии страницы. На сайте — перед прогоном.
- Заголовок и метка окна «Скачать» принимаются настройками `emit(list, { title, label })`; опись для окна
  («Кривых», «Точек»…) прототип не считает.
- В режиме «Сначала сам» прототип читает видимый текст узла вместо `data-raw` (SPEC, раздел 10): на сайте лечить
  надо в `selfCanvas()`.
- Плавающие блоки над холстом (полоса режима `#cv-mode`) прототип на время прогона не гасит. На 44 стартах при
  показанной полосе файл тот же; на сайте список `floatRects()` на время прогона пуст (SPEC, раздел 2.1, п. 12).
- Записей у мест рисования прототип не добавляет (кроме пилота): он показывает, что получается из того, что уже
  есть, и считает, чего не хватает.

Переносить прототип в код можно целиком или частями; обязательны требования `SPEC.md` и инварианты задания, а
не устройство прототипа. Комментарии в коде сайта — по-русски и с причиной, как принято в проекте.
