Здесь всё, что нужно, чтобы перенести утверждённый владельцем макет в `calc2/`. Папка в репозитории:
`claude/mockups/calc2_redesign_20261004/`. Задание целиком — в `PROMPT.md` (тот же текст владелец вставляет в Claude Code).

## Как посмотреть макет вживую

Макет открывается в браузере, если отдан по http. Ему нужна сеть: `mockup/support.js` берёт React с
`cdn.jsdelivr.net`, доски берут шрифты с `fonts.googleapis.com`. Если сети нет, макет не откроется: это не препятствие,
работайте по снимкам `reference/` и исходникам `mockup/`.

```
node claude/mockups/calc2_redesign_20261004/tools/shoot_mockup.mjs --serve
# затем http://127.0.0.1:8790/Main.dc.html — полный прототип: выбор модели → рабочий экран
# http://127.0.0.1:8790/Work.dc.html, Dark.dc.html, Phone.dc.html, Kit.dc.html … — отдельные доски
```

Снять состояние в файл (свойства `Main` и `Phone` — `README.md`, раздел 1; примеры рецептов — `reference/INDEX.md`):

```
node …/tools/shoot_mockup.mjs --main 'screen="work" model="islm" theme="dark"' --out /tmp/islm_dark.png
node …/tools/shoot_mockup.mjs --board Kit --out /tmp/kit.png
node …/tools/shoot_mockup.mjs --all        # пересобрать весь набор reference/ (около 6 минут)
```

Скрипт берёт `playwright` из `node_modules` репозитория, поэтому запускать его надо из корня репозитория. Макет можно
мерить так же, как сайт: открыть страницу макета в Playwright и снять `getBoundingClientRect` и вычисленные стили.

## Что в макете настоящее, а что нет

- Живые модели (считает движок макета): `sd`, `taxes`, `ceil`, `mono`, `costs`, `m-tangent`. У остальных 36 на холсте
  схема, а колонки собраны по таблице `E.SPECS` (`mockup/calc-data.js`).
- Движок макета, его схемы, демо-данные («вчера, 21:40»), формат ссылки и тексты разборов **не переносятся**
  (`README.md`, раздел 2).
- В исходниках остались ветки отклонённых вариантов (`kp=a`, `kp=c`, `pw=inline`): не читать и не переносить.
- Оформление в макете записано инлайновыми стилями: на сайте это классы и токены.
- Картинки не во всём равны результату. Отличия, принятые заранее (статус без заливки, галочки без заливки, скругления
  канона, шрифты холста, телефон с полным составом функций и другие), перечислены в `COVERAGE.md`, раздел 7.
