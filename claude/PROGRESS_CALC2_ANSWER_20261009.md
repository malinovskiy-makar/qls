## Фаза 0. Разведка (только чтение)

### Как устроено сейчас

- `94-answer.js` `buildAnswer()`: строки табло из `HERO` → плитки `.ans-cell` (`.ans-lab`; `.ans-line` = `.ans-not`
  «=» `.ans-val`; `.ans-was`) в сетке `#ans-hero` в две колонки; кегль числа классами `.ans-val--l/m/s/x`
  (28/24/20/17). Над плитками один `#ans-title` — копия `#sec-eq .section-title`. Подпись режется `heroLabel` на
  слова и обозначение — и у математики тоже («Пересекает ось» + «x = −2; 2»). `ANSWER_GROUP` объявлена, не
  используется. Пересборка — по подписи текста табло, раз в кадр.
- Остальные строки табло (`#sb-body .stat`) — подпись 14/400, число 14/700 (`calc2.css` ≈2887); численные значения
  набирает KaTeX (`typesetStats` → `statToTex`), фразы и смешанные («L = 10, MP = 300») — текстом.
- `96-self.js`: поле в ячейке `.self-box` = `.self-inp` + строка `.self-acts` («Проверить», «Показать», вердикт
  `.self-pill` справа). Ось величины для холста и «(?; ?)» читается из `.ans-not` (`selfCanvas`, `selfOpenValues`).
- `70-scenes-math.js` `updateGraphPanel`: «Кривая = f» (не главная) + 4 главные с хвостом «, кривая f» (если кривых
  > 1) + одна строка «Пересечения кривых» на ВСЕ пары (точки сведены вместе). `openExport` ставит заголовок, только
  если поле пустое; поле живёт в окне, окна — не форма модели (`formNodes`).
