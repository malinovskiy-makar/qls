## Причина «ошибки нет» после Enter

Мост MathLive `toInput` (82-input.js) на каждое событие поля стирал сообщение под ним, а обработчик поля ставил его
заново только при изменившемся тексте. Enter шлёт событие с тем же текстом — сообщение исчезало, рамка оставалась.
