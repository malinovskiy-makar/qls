**Решение владельца 18.09 (дневное):** делаем как в README – **один шаблон и один сценарий на три адреса** `/catalog/`, `/catalog/problem/<id>/`, `/catalog/map/`; клик со входа в задачу и любая смена задачи – без перезагрузки. Это отменяет подход «поверх нынешней страницы» из ADR 0120: ночную работу не выбрасываем, а переносим внутрь нового шаблона (новый ADR, см. S7). **Критерий готовности:** README §1–§9 выполнены целиком, все одиннадцать решений от 17.09 соблюдены, ничего из нынешнего функционала не потеряно (список в ночном промпте, раздел 0), полный прогон и пять джобов CI зелёные, владелец прошёл сценарии приёмки и сказал «принято». 2. **Остановки.** Три вида, все с явным ожиданием ответа владельца:

## S1. Вход E3 в новом шаблоне (README §2, фон §6; снимки 01–04, 08)

Зачем: это первое, что видит каждый ученик. С этой фазы рождается единый шаблон.

**S1.1 Шаблон и адрес.** Новый `catalog/templates/catalog/stol.html` с `main_class` на всю ширину окна и слотом «вид»; `problem_list` рендерит его с `view='entry'`. Контекст – нынешний `_catalog_context` (контракт с `api_filter_state` и окном «Все фильтры» не менять, `test_filter_state_api.py` зелёный). Старый `problem_list.html` остаётся в репозитории до S7, но с этой подфазы не используется ни одним адресом.

**S1.2 Карточка поиска и заголовок.** По README §2: карточка в центре с воздухом, заголовок «Это умный каталог.» только без запроса и без фильтров, сжатие шапки при первом фильтре (анимация по README, `prefers-reduced-motion` – без движения), бегущие фразы ожидания и «Ищем по смыслу» – из нынешних констант (`CATALOG_PHRASES`, `CATALOG_STOP_TEXT`), Enter/кнопка – поиск с `log=1`.

**S1.3 Чипы.** Ряд «Все фильтры / Тема ▾ / Сложность ▾ / Задачи и тесты ▾ / С решением / Сбросить». Выпадашки привязаны к чипу, содержимое и числа – из `api_filter_state` (тот же ответ, что кормит окно «Все фильтры»); чип «Все фильтры» открывает нынешнее окно (`_catalog_modal.html` + `catalog_filters.js`), окно и чипы работают с ОДНИМ состоянием (после «Готово» в окне чипы обновляются, и наоборот). Ряд чипов выбранных тегов с крестиками. Пилюля «Карта тем: …» – пока ведёт на `/catalog/map/` обычной ссылкой (S4 сделает переход на месте). Адреса строит только `filters.query()`.

**S1.4 Лента входа.** «Продолжить» (уже есть – перенести) и «Случайная задача» (`random_problem` с фильтрами) в одной строке; блок результатов широкими строками из общего партиала строки ленты (широкая плотность): статус слева у вошедшего, название, сосед-подсказка, тема, звёзды, метки «тест»/«решение» только при данных; `data-search-log` сохраняется; «Показать ещё 20» (`show=`); скелет строк на время запроса; «не меньше N», подсказка `relief`, «под эти фильтры ни одной задачи» – сохранить. Строки – настоящие ссылки на `/catalog/problem/<id>/` (без скрипта всё работает; перехват клика появится в S2).

## S2. Один экран: задача без перезагрузки (README §1, §3; снимки 09–15, 20)

**S2.3 Переключение видов и адреса.** Состояние `weco.stol.state = {view, problemId, panels, focus, tab, filters, results, scroll}`.
