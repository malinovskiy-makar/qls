## Правила

* Логотипы — только для обозначения олимпиады (номинативно). Без слов «партнёр»,
  «официальный»; цвета и пропорции не менять.
* С раунда 3 (решение владельца 29.10.2026) у всех пяти целей — логотип БЕЗ плашки:
  область 104×64 без фона и рамки, знак вписан (`object-fit: contain`). Кружки
  РАНХиГС и РЭШ на «Перечневых» — на `var(--surface)`.
* Тёмная тема: только под логотипами олимпиад (ВсОШ, «Перечневые», «Международные»)
  светлая подложка `var(--brand-cream)` со скруглением 10 и полями 6 px — иначе
  чёрные буквы ВсОШ не видны.
* «Разобраться в экономике» — знак W (`weconomics_w.svg`, ≈76×56); «Пока не решил» —
  веер из четырёх бледных логотипов (ВсОШ, «Высшая проба», IEO, РАНХиГС):
  чёрно-белые, прозрачность 0,5, при наведении 0,75. Те же файлы, что выше.
